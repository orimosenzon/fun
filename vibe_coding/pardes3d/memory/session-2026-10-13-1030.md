# סשן 13/10/2026: פתיחת הפרויקט

## מה נעשה
- הותקן Godot 4.7.2 (`~/.local/bin/godot`), נבנתה סביבת פייתון.
- צינור נתונים: OSM (Overpass) + DEM (Terrarium) + סקר העצים → glTF ונכסים ב-`game/world`.
- אפליקציית Godot: כל שטח המועצה, רחפן והליכה, מפה קטנה, 232 מקומות לקפיצה, G פותח סטריט ויו.
- README עם ההחלטות (Godot במקום Unreal; סטריט ויו רק כרפרנס בגלל תנאי השימוש) ותוכנית של 5 שלבים.
- `fetch_mapillary.py` מוכן אבל לא הורץ: חסר מפתח.

## צעדים הבאים
1. **לאשר עם אורי** את שתי ההחלטות (Godot, לא להוריד מסטריט ויו).
2. מפתח Mapillary מאורי → `make` של fetch_mapillary → לבדוק כמה כיסוי יש במושבה.
3. גובה בניינים ממקור אמיתי (המרכז למיפוי ישראל / DSM), והשלמת בניינים חסרים מ-Microsoft footprints.
4. גגות רעפים, גדרות בין מגרשים, דודי שמש: מה שהכי ישנה את התחושה ברחוב.
5. ניסוי ראשון של שלב 3 על רחוב אחד: Claude Vision קורא חזיתות ומחזיר תכונות.
