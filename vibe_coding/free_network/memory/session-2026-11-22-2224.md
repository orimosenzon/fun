# סשן 2026-11-22

## מה נעשה
- **מסנג'ר**: שיחות אחד על אחד בין חברים, עם טקסט, קישורים ותמונה. רשימת שיחות עם מונה הודעות שלא נקראו (גם בכותרת הלשונית), ופריט "הודעות" בתפריט. בטלפון השיחה ממלאת את כל המסך. אין חיבור חי: שיחה פתוחה שואלת את השרת כל 3 שניות, והמונה מתעדכן כל 30 שניות. "נקרא" לא מוצג לצד השני, ורק הכותב מוחק הודעה (גם התמונה נמחקת באמת). מיגרציה 0015.
- בטלפון "למה אנחנו" עבר לסמל בסרגל העליון. תוקן מרוץ בנתב: דף שנטען לאט כבר לא דורס דף שעברו אליו אחריו.
- **רשת אחת**: לבקשת אורי הדמו נמחק (ה-Worker והמסד ב-Cloudflare, מצב הדמו בקוד, התוכן הבדוי והבדיקות שלו). לא אומרים עוד "פיילוט", והפריסה היא `npm run deploy` (סביבת `live`). דף הפרויקטים מקשר לסרטון ב-`/intro`. הטענות על פייסבוק ב-`/why`, שעוד לא עברו עורך דין, מוצגות רק למחוברים.
- **עריכת פוסט ותגובה**: רק הכותב, ורק המילים (הקהל והתמונות לא משתנים). מסומן "נערך", ונוסחים קודמים לא נשמרים. מיגרציה 0016.
- **השלמת כתובות במסך ההזמנה** מאנשי הקשר של אורי בגוגל (שמורים, ומי שהתכתב איתם). החיבור ל-Gmail מבקש עכשיו גם קריאת אנשי קשר. אנשי הקשר נקראים בזמן אמת ולא נשמרים. מיגרציה 0017.
- הכול נפרס לרשת החיה. 72 בדיקות שרת עוברות, והממשק נבדק בדפדפן אוטומטי במחשב ובאמולציית טלפון.

## מצב נוכחי
- רשת אחת חיה בהזמנה: free-network.orimosenzon.workers.dev.
- ההשלמה מאנשי הקשר עוד לא פעילה: מחכה שאורי יפעיל את People API ויחבר את ה-Gmail מחדש. היא לא נבדקה מול גוגל האמיתי.
- המסנג'ר והעריכה לא נבדקו בטלפון אמיתי (המקלדת).

## צעדים הבאים
1. אורי: להפעיל את People API בפרויקט `free-network-514020` ולחבר את ה-Gmail מחדש ב-`/admin`. אחר כך לבדוק שההצעות מופיעות.
2. לבדוק את המסנג'ר בטלפון אמיתי: שהשדה והכפתור נשארים מעל המקלדת.
3. החלטות פתוחות: התראות במייל (דורש שירות מיילים), לייק, חברים מזמינים חברים, דיווח וחסימה, גיבוי, דף פרטיות, פרסום אפליקציית הגוגל.
