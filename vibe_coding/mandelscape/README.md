# מנדלברוט: מפה ונוף

חוקר של קבוצת מנדלברוט בדפדפן, בשני מבטים על אותו מקום.

**מפה.** זום עד 10^32, חד ונקי: כשהתמונה עומדת היא ממשיכה להתחדד (עד שמונה דגימות לפיקסל), הסיבים מצוירים כקו של פיקסל אחד, ומספר האיטרציות מתאים את עצמו למקום. מקומות מרשימים, שמונה פלטות, מחזור צבעים, סרטון צלילה, קישור למקום.

**טיסה.** הקבוצה היא אגם, והקרקע עולה ממנו לפי המרחק. כל פס צבע הוא גם מדרגה בשטח. טסים מעל זה על ה-F-5 של [FÖHN](../jetbikes/foehn/). כדי לרדת לפרטים פשוט יורדים: מתחת ל-40 מטר מעל המים האופנוע מתכווץ במקום להתקרב, והעולם גדל סביבו, עד פי 10^31.

## הרצה

```
cd vibe_coding && python3 -m http.server 8941
# http://localhost:8941/mandelscape/          המפה
# http://localhost:8941/mandelscape/?fly      ישר לטיסה
```

השרת חייב לרוץ מהתיקייה שמעל, כי הדף מייבא את האופנוע מ-`../jetbikes/foehn`.
