How to play: Use your arrow keys to move the tiles. Tiles with the same number merge into one when they touch. Add them up to reach 2048!

Watch the AI play: pick a trained agent (from the Python/PyTorch part of this project) and let it drive the board. Press P to play or pause.

The bars show what the agent thinks of each direction: for DQN the estimated future score (Q-value), for Actor-Critic and PPO the probability it assigns, for the n-tuple agent the immediate score plus the learned value of the board after the slide. × marks a move that would not change the board. The strongest agent in the reports, the n-tuple network with four 6-cell windows, is a 268MB table and cannot be downloaded into a web page; it appears here in two forms: a browser-sized version (five 4-cell windows, 1.3MB, the 2014 network of Szubert and Jaśkowski) that really decides every move in the browser, and recorded games of the full table, replayed move by move with the game's own rules.

Note: This is a faithful re-implementation of the original 2048 by Gabriele Cirulli, built as the playground for a reinforcement-learning project.
