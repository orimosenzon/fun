# השרתון של דרך קיצור

הוא קיים מסיבה אחת: **האפליקציה היא דף סטטי, ולדף סטטי אין איפה להחזיק סוד.**

כדי לכתוב לריפו הנתונים צריך הזדהות מול גיטהאב. כל דבר שנשלח לדפדפן ניתן לקריאה
בידי כל אחד, ולכן אי אפשר להטמיע מפתח בקוד האפליקציה. עד עכשיו הפתרון היה שכל עורך
מדביק מפתח fine-grained משלו. זה עבד, וזה גם אמר שכל עורך צריך חשבון גיטהאב וריקוד
של חמישה שלבים, מה שבפועל הגביל את מספר העורכים לאחד.

השרתון מחזיק את המפתח במקומם. האפליקציה פונה אליו **בלי שום הזדהות**.

## מה זה אומר, בלי לייפות

**ריפו הנתונים הופך לניתן לכתיבה בידי כל מי שמוצא את הכתובת של השרתון.** לא רק דרך
האפליקציה, גם דרך `curl`. זו ההחלטה שהתקבלה במודע, בתמורה לכך שתושב יכול להוסיף שביל
בלי שום התקנה. ההגנות הן מה שהופך את זה לשריד, לא לבטוח:

| הגנה | מה היא עוצרת |
|---|---|
| רשימת נתיבים | אפשר לכתוב רק לשלושה קובצי נתונים ולתמונות webp ששמן hash של תוכנן. לא לקוד, לא ל-workflows |
| בדיקת מבנה | מסמך חייב להישאר מסוג עצמו ובגודל סביר. אי אפשר לרוקן את המפה או לנפח אותה |
| תקרת גודל | 6MB לבקשה |
| הגבלת קצב | 40 כתיבות ל-5 דקות לכל IP, ב-KV |
| git | כל כתיבה היא commit. `git revert` מחזיר יום רע |

**מה זה לא עוצר:** אדם אחד שמחליט להשחית בקצב סביר. התשובה לזה היא היסטוריית git,
ואם זה יקרה, מתג הכיבוי למטה.

## פריסה

```bash
cd worker
npx wrangler login                       # פותח דפדפן, פעם אחת
npx wrangler secret put GITHUB_TOKEN     # מדביקים מפתח עם Contents: Read and write
npx wrangler deploy
```

הפקודה האחרונה מדפיסה כתובת בסגנון `https://derech-kitzur.<שם>.workers.dev`.
מעדכנים אותה ב-`WORKER` בראש `web/store.js`, ודוחפים. זהו.

חשבון Cloudflare הוא חינם ולא דורש כרטיס אשראי. המכסה החינמית היא 100,000 בקשות
ביום, בערך פי אלף ממה שהפרויקט הזה יראה.

### הגבלת קצב (מומלץ, לא חובה)

```bash
npx wrangler kv namespace create RATE
```

מדביקים את ה-id ב-`wrangler.toml` ומבטלים את ההערה. בלי זה השרתון עובד, פשוט בלי
מגבלת קצב.

## מתג כיבוי

אם מישהו משחית ואין חשק להתעסק:

```bash
npx wrangler deploy --var READ_ONLY:true
```

הכתיבה נסגרת לכולם מיד. הקריאה, המפה, התמונות והניווט ממשיכים לעבוד כרגיל, כי הם
לא עוברים דרך כאן בכלל. לשחזור מה שנמחק: `git revert` בריפו הנתונים.

## המפתח שהשרתון מחזיק

מפתח fine-grained, מוגבל ל-`derech-kitzur-data` בלבד, `Contents: Read and write`.
הוא יושב כ-secret ב-Cloudflare ולא ב-git, ולא בקוד האפליקציה. להחלפה:

```bash
npx wrangler secret put GITHUB_TOKEN
```

אף מכשיר של אף עורך לא צריך לדעת עליו, ולכן החלפה שלו לא מחייבת לעדכן אף אחד.

## נקודות קצה

| | |
|---|---|
| `GET /health` | בדיקת חיים, מחזיר לאיזה ריפו הוא מחובר ואם הוא במצב קריאה בלבד |
| `GET /file?path=…` | קריאת קובץ מהריפו, מחזיר `{sha, content}` בבסיס 64 |
| `PUT /file` | כתיבה. גוף: `{path, content, message, sha}`. מחזיר 409 בהתנגשות |

השרתון הוא **פרוקסי מצומצם לגיטהאב** ולא API של המוצר, בכוונה: כל לוגיקת המיזוג,
ה-retry וההעלאה נשארה באפליקציה, במקום שבו היא כבר נבדקה.
