# השרתון של דרך קיצור

הוא קיים מסיבה אחת: **האפליקציה היא דף סטטי, ולדף סטטי אין איפה להחזיק סוד.**

כדי לכתוב לריפו הנתונים צריך הזדהות מול גיטהאב. כל דבר שנשלח לדפדפן ניתן לקריאה
בידי כל אחד, ולכן אי אפשר להטמיע מפתח בקוד האפליקציה. עד עכשיו הפתרון היה שכל עורך
מדביק מפתח fine-grained משלו. זה עבד, וזה גם אמר שכל עורך צריך חשבון גיטהאב וריקוד
של חמישה שלבים, מה שבפועל הגביל את מספר העורכים לאחד.

השרתון מחזיק את המפתח במקומם.

## שתי דרגות, ולא אחת

עד 28/8/2026 השרתון לא ביקש שום הזדהות מאף אחד, וזה אמר שכל מי שמצא את הכתובת יכול
היה לשנות את המפה. מאז יש הפרדה:

| מה עושים | מה צריך | לאיזה קובץ זה נכתב |
|---|---|---|
| להוסיף שביל, לשלוח אותו ליוזמה | כלום | `data/pending.json`, `img/*.webp` |
| לאשר שביל, לפרסם, למחוק, לסדר מיקומים | סיסמת עריכה | `data/trails.json`, `data/places.json` |

**ההפרדה הזאת היא כל העניין.** הצד הפתוח הוא מה שמאפשר לתושב להקליט שביל בטלפון
ולשלוח אותו בלי חשבון ובלי התקנה. הצד הסגור הוא מה שמבטיח שרק מי שמחזיק את הסיסמה
מחליט מה בסוף מופיע על המפה.

הסיסמה נשלחת בכותרת `X-DK-Key` ונשמרת כ-secret בשם `EDITOR_KEY`. **שרתון שנפרס בלי
הסוד הזה דוחה כל עריכה** ולא מקבל את כולן; זה הכיוון הבטוח מבין השניים.

## מה זה אומר, בלי לייפות

**התור ותיקיית התמונות ניתנים לכתיבה בידי כל מי שמוצא את הכתובת של השרתון.** לא רק
דרך האפליקציה, גם דרך `curl`. מי שיטרח יכול להציף את תור האישורים או לרוקן אותו. שום
דבר מזה לא מגיע למפה, הכול גלוי, וכל שינוי הוא commit. ההגנות:

| הגנה | מה היא עוצרת |
|---|---|
| סיסמת עריכה | כתיבה ל-`trails.json` ול-`places.json`, כלומר למפה עצמה |
| רשימת נתיבים | אפשר לכתוב רק לשלושה קובצי נתונים ולתמונות webp ששמן hash של תוכנן. לא לקוד, לא ל-workflows |
| בדיקת מבנה | מסמך חייב להישאר מסוג עצמו ובגודל סביר. אי אפשר לרוקן את המפה או לנפח אותה |
| תקרת גודל | 6MB לבקשה |
| הגבלת קצב | 40 כתיבות ל-5 דקות לכל IP, ב-KV |
| git | כל כתיבה היא commit. `git revert` מחזיר יום רע |

**מה זה לא עוצר:** אדם אחד שמחליט להציף את התור בקצב סביר. התשובה לזה היא היסטוריית
git, ואם זה יקרה, מתג הכיבוי למטה.

## פריסה

```bash
cd worker
npx wrangler login                       # פותח דפדפן, פעם אחת
npx wrangler secret put GITHUB_TOKEN     # מדביקים מפתח עם Contents: Read and write
npx wrangler secret put EDITOR_KEY       # סיסמת העריכה. בלעדיה אי אפשר לערוך בכלל
npx wrangler deploy
```

הפקודה האחרונה מדפיסה כתובת בסגנון `https://derech-kitzur.<שם>.workers.dev`.
מעדכנים אותה ב-`WORKER` בראש `web/store.js`, ודוחפים. זהו.

חשבון Cloudflare הוא חינם ולא דורש כרטיס אשראי. המכסה החינמית היא 100,000 בקשות
ביום, בערך פי אלף ממה שהפרויקט הזה יראה.

### הגבלת קצב (מומלץ, לא חובה)

```bash
npx wrangler kv namespace create RATE
```

מדביקים את ה-id ב-`wrangler.toml` ומבטלים את ההערה. בלי זה השרתון עובד, פשוט בלי
מגבלת קצב.

## מתג כיבוי

אם מישהו משחית ואין חשק להתעסק:

```bash
npx wrangler deploy --var READ_ONLY:true
```

הכתיבה נסגרת לכולם מיד. הקריאה, המפה, התמונות והניווט ממשיכים לעבוד כרגיל, כי הם
לא עוברים דרך כאן בכלל. לשחזור מה שנמחק: `git revert` בריפו הנתונים.

## המפתח שהשרתון מחזיק

מפתח fine-grained, מוגבל ל-`derech-kitzur-data` בלבד, `Contents: Read and write`.
הוא יושב כ-secret ב-Cloudflare ולא ב-git, ולא בקוד האפליקציה. להחלפה:

```bash
npx wrangler secret put GITHUB_TOKEN
```

אף מכשיר של אף עורך לא צריך לדעת עליו, ולכן החלפה שלו לא מחייבת לעדכן אף אחד.

## סיסמת העריכה

זה הסוד השני, ובניגוד לראשון **העורכים כן צריכים לדעת אותו.** להחלפה:

```bash
npx wrangler secret put EDITOR_KEY
```

החלפה מנתקת מיד כל מכשיר שמחזיק את הישנה: האפליקציה שואלת את `/health` בכל טעינה,
מקבלת `editor: false`, ומכבה אצלה את מצב העריכה. זו הדרך להוציא מכשיר שאבד.

לצירוף עורך נוסף מוסרים לו את אותה סיסמה. היא לא מזהה מי הוא, ולכן השם שנרשם ב-`by`
ובקומיט נשאר מה שהוא הקליד על עצמו ולא משהו מאומת.

## נקודות קצה

| | |
|---|---|
| `GET /health` | בדיקת חיים. מחזיר לאיזה ריפו הוא מחובר, אם הוא במצב קריאה בלבד, ו-`editor` שאומר אם ה-`X-DK-Key` שנשלח נכון |
| `GET /file?path=…` | קריאת קובץ מהריפו, מחזיר `{sha, content}` בבסיס 64 |
| `PUT /file` | כתיבה. גוף: `{path, content, message, sha}`. מחזיר 409 בהתנגשות, 401 בלי סיסמה על נתיב מוגן |

השרתון הוא **פרוקסי מצומצם לגיטהאב** ולא API של המוצר, בכוונה: כל לוגיקת המיזוג,
ה-retry וההעלאה נשארה באפליקציה, במקום שבו היא כבר נבדקה.
