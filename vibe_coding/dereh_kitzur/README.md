# דרך קיצור

אפליקציית ווב ליוזמת שבילי ההליכה של פרדס חנה-כרכור, מעל שכבת ה-Google My Maps של היוזמה.

המפה נשארת מקום העריכה. האפליקציה היא שכבת התצוגה מעליה: רשימה שאפשר לסרוק ולחפש בה,
תמונות שנפתחות בגודל מלא, וסטריט ויו לכל כניסה לשביל.

## מבנה

```
build_data.py        שולף את המפה החיה, ממרר תמונות, וכותב web/data/trails.json
kitzur_sheet.py      מפיק גיליון עבודה (xlsx) מאותה מפה
web/                 האפליקציה. סטטית לגמרי, בלי build ובלי שרת
  index.html
  app.css
  app.js
  data/trails.json   נוצר, לא נערך ידנית
  img/               תמונות ממוררות, נוצרות
```

## הפעלה

```bash
pip install requests openpyxl pillow

python3 build_data.py          # רענון נתונים ותמונות מהמפה
cd web && python3 -m http.server 8000
```

ואז לפתוח `http://localhost:8000`. חייבים שרת ולא פתיחת קובץ ישירות, כי האפליקציה
טוענת את הנתונים ב-fetch.

`build_data.py --no-photos` מרענן רק את הנתונים ומדלג על התמונות, וזה מהיר בהרבה
כשמשנים קוד.

## שלושה דברים שכדאי לדעת לפני שנוגעים בקוד

**התמונות ממוררות, ולא במקרה.** גוגל מגישה את תמונות ה-My Maps עם
`cross-origin-resource-policy: same-site`, ולכן דפדפן מסרב להציג אותן מכל דומיין אחר.
`curl` דווקא מוריד אותן בהצלחה, וזו בדיוק המלכודת.

**שמות הקבצים הם hash של תוכן התמונה.** גוגל חותמת מחדש כל כתובת תמונה בכל שליפת KML,
כך ששתי בניות רצופות לא רואות אף כתובת משותפת. מיפוי לפי URL היה מכפיל את התיקייה בכל
הרצה. המחיר הוא שכל בנייה מורידה הכל מחדש, בערך שלוש דקות.

**אין מפתח API בשום מקום.** רקע המפה מגיע מ-OpenStreetMap ומ-Esri, סטריט ויו נפתח
בקישור לגוגל מפות במקום ווידג'ט בתשלום, ומיקומי המצלמה מחושבים מנתוני כבישים של
OpenStreetMap דרך Overpass.

## מה האפליקציה נותנת מעבר ל-My Maps

- רשימה ממוינת (לפי אורך, קרבה אליך, או כמות תמונות) עם חיפוש חופשי
- תמונות בגודל מלא עם החלקה בין תמונות, ולא תצוגה מוקטנת בתוך בועית
- **סטריט ויו לשתי הכניסות של כל שביל.** המצלמה לא עומדת על השביל אלא על הכביש הקרוב
  ביותר, ומביטה אל פתח השביל. זה החלק שבאמת קשה במפה המקורית: לזהות את הפתח בשטח.
  כניסות שרחוקות מכל כביש מסומנות בקו מקווקו, כי ייתכן שאין להן צילום 360
- מיקום נוכחי ומיון "הקרובים אליי"
- החלפה בין תצוגת רחובות ללוויין
