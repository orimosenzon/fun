# סשן 2026-10-20

## מה נעשה
- שכבה חדשה **"בעלות קרקע"**: כל 9,126 החלקות במושבה צבועות לפי סוג הבעלים הרשום בטאבו (המועצה המקומית, מקרקעי ישראל, פרטית, מעורבת, אחרת, לא ידוע), ויער פרדס חנה של קק"ל בקו ירוק מקווקו.
- המקור: שכבת govmap "סוג בעלות בחלקות רשומות" (layer 6, הרשות לרישום והסדר זכויות במקרקעין). WFS סגור ו-API הלחיצה מוגבל ל-429, אז `build_ownership.py` מבקש תמונות WMS עם SLD שצובע כל סוג בצבע טהור, דוגם נקודות בתוך כל חלקה, ופותר חלקות מפוצלות דרך API הלחיצה. אימות מול תשובות הלחיצה: 1,374/1,375.
- יערות קק"ל מ-ArcGIS הפתוח של קק"ל (`yaar_VIEW_OD`), חתוכים בגבול המועצה.
- באפליקציה: מקרא, ריחוף שמראה בעלים, לחיצה פותחת כרטיס עם גוש/חלקה/שטח/בעלים וקישור להזמנת נסח טאבו. כשגם שכבת החלקות דלוקה, כרטיס החלקה מקבל שורת בעלות.
- בדיקה חדשה `tests/test_ownership.py` (עוברת), ובדיקות החלקות, המצבים, הבחירה, המסומנים וההתנגדויות עוברות.
- README וקובץ הידע עודכנו.

## מצב נוכחי
- השכבה כבויה כברירת מחדל ולא חלק ממצב מתכנן.
- מגבלה: אי אפשר להפריד קק"ל מהמדינה בתוך "מקרקעי ישראל" עם נתונים פתוחים; זה כתוב בהערת השכבה.
- חלקה אחת לא תואמת (גוש 10109 חלקה 172), כנראה רשומות חופפות ב-govmap.

## צעדים הבאים
1. להחליט אם להכניס את שכבת הבעלות למצב מתכנן.
2. שכבות רמ"י נוספות מ-govmap: מכרזי מקרקעין (id 363) ותוכניות לשיווק (id 359).
3. רענון תקופתי של `build_ownership.py --refresh` (אולי בקרון הלילי).
4. מהסשן הקודם: פיצול ארבעת הסיורים עם שחר, שתי בדיקות נכשלות ב-test_route.py, כיוון שביל ישראל, אורך שביל גולני, שבילים מסומנים בחיפוש שם.
