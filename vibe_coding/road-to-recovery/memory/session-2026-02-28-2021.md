# סשן 2026-02-28 — בדרך להחלמה MVP

## מה נעשה
בנינו את ה-MVP המלא של מערכת תיאום נסיעות מאפס.
Build עובר. 65 קבצים, 21 routes.

## Stack שנבחר
- Next.js 14 (App Router) + Supabase + Tailwind CSS
- Google Maps Distance Matrix API (server-side)
- Supabase Realtime
- i18n מקומי — עברית + ערבית

## מה קיים

### תשתית
- `supabase/schema.sql` — 5 טבלאות + enums + triggers + RLS + seed (8 בתי חולים)
- `middleware.ts` — auth guard + redirect לפי role
- `lib/types/index.ts` — TypeScript interfaces + state machine
- `lib/supabase/client.ts` + `server.ts`
- `lib/i18n/` — he.json + ar.json + hook
- `lib/utils/` — rideStatus, reimbursement, formatters
- `lib/hooks/` — useCurrentUser, useNotifications (Realtime)
- `lib/maps.ts` — Google Maps wrapper (server-only)
- `.env.local` — template ריק (ממתין לפרטי Supabase)
