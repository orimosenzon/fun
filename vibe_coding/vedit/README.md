# vedit: עורך וידאו בדפדפן

עורך וידאו לא-לינארי (NLE) שרץ כולו בדפדפן. בלי התקנה, בלי שרת, בלי העלאת קבצים
לשום מקום: הווידאו נשאר על המחשב שלכם, וכל העיבוד קורה מקומית.

**[▶ פתיחת האפליקציה](https://orimosenzon.github.io/fun/vibe_coding/vedit/)**

הממשק בנוי בסגנון של תוכנות העריכה המובילות (Premiere / DaVinci / CapCut), כדי
שמי שכבר ערך פעם וידאו ידע מיד איפה הכול נמצא: מאגר מדיה משמאל, מוניטור תצוגה
במרכז, פאנל מאפיינים מימין וטיימליין רב-ערוצי למטה.

---

## מה אפשר לעשות

**מדיה**
- ייבוא של וידאו, אודיו ותמונות, בגרירה לחלון או דרך כפתור הייבוא
- מאגר מדיה עם תמונה ממוזערת, אורך וגודל של כל פריט
- הפרויקט נשמר אוטומטית בדפדפן (IndexedDB) וממשיך מאיפה שהפסקתם

**טיימליין**
- מספר בלתי מוגבל של ערוצי וידאו ואודיו, עם השתקה, הסתרה ונעילה לכל ערוץ
- פילמסטריפ (תמונות מהסרטון) וצורת גל של האודיו בתוך כל קליפ
- גרירת קליפים בזמן ובין ערוצים, חיתוך קצוות בגרירת הידיות
- הצמדה חכמה לקצוות של קליפים אחרים ולסמן הזמן
- זום מ-2 עד 900 פיקסלים לשנייה, גלילה, וכלי יד

**עריכה**
- סכין חיתוך (C) וחיתוך בנקודת הסמן (S)
- מחיקה רגילה, ומחיקה שסוגרת את החור (ripple)
- סימון קטע בין נקודת כניסה ליציאה (I / O) והוצאתו מהסרט
- העתקה, הדבקה ושכפול, ביטול ובצע-שוב ללא הגבלה
- בחירה מרובה בגרירת מלבן

**מעברים בין סצנות**
12 מעברים: מעבר הדרגתי, דרך שחור, דרך לבן, מחיקה (3 כיוונים), החלקה (2),
דחיפה, זום, עיגול ותריסים. גוררים מהפאנל אל הגבול בין שני קליפים,
ומכווננים את המשך בגרירה או באינספקטור.

**מאפייני קליפ**
- שקיפות, גודל, מיקום, סיבוב, היפוך אופקי ומצב התאמה למסגרת
- בהירות, ניגודיות, רוויה וטשטוש
- דעיכת וידאו מ/אל שחור, דעיכת אודיו בכניסה וביציאה
- עוצמת אודיו והשתקה
- מהירות ניגון (0.25× עד 4×)

**כותרות**
טקסט מעל הווידאו בארבעה סגנונות (רגיל, עם צל, על רקע כהה, כותרת תחתונה),
עם שליטה בגודל, בצבע ובמיקום.

**ייצוא**
- ייצוא הסרט לקובץ MP4 או WebM, ברזולוציה ובאיכות לבחירתכם
- אפשר לייצא רק את הקטע שבין הסימונים
- שמירת הפריים הנוכחי כתמונת PNG

## קיצורי מקלדת

| | |
|---|---|
| `רווח` | נגן / עצור |
| `K` / `L` | עצירה / ניגון מהיר (לחיצות חוזרות = מהר יותר) |
| `←` `→` | פריים אחורה / קדימה (עם `Shift`, קפיצה של שנייה) |
| `Home` / `End` | לתחילת / סוף הסרט |
| `S` | חיתוך בנקודת הסמן |
| `V` / `C` / `H` | כלי בחירה / סכין / יד |
| `Delete` | מחיקה (עם `Shift`, מחיקה וסגירת החור) |
| `I` / `O` | סימון כניסה / יציאה |
| `Shift`+`X` | הוצאת הקטע המסומן |
| `Ctrl`+`C` / `V` / `X` / `D` | העתקה / הדבקה / גזירה / שכפול |
| `Ctrl`+`Z` | בטל (עם `Shift`, בצע שוב) |
| `+` / `−` / `Shift`+`Z` | זום פנימה / החוצה / התאמה למסך |
| `?` | רשימת הקיצורים |
| `Ctrl`+`Shift`+`D` | דוח אבחון |

## כשמשהו לא עובד

בסרגל העליון יש כפתור 🩺. הוא פותח דוח אבחון שכולל את פרטי הדפדפן, מצב מנוע
הניגון (כולל `readyState` של כל אלמנט וידאו, שגיאות פענוח ומצב גרף האודיו),
רשימת המדיה והקליפים, ויומן אירועים עם חותמות זמן. אפשר להעתיק אותו ללוח או
להוריד כקובץ טקסט.

בראש הדוח מופיעה מסקנה אוטומטית, למשל "הקודק כנראה לא נתמך בדפדפן הזה".
היומן נשמר גם ב-localStorage, כך שגם אחרי רענון או קריסה אפשר לראות מה קרה
בהרצה הקודמת.

אם המסך הגדול נשאר שחור בזמן שהקליפ נראה בטיימליין, תופיע עליו הודעה שמסבירה
למה, במקום פשוט להישאר שחור. הסיבה הנפוצה היא קודק שהדפדפן לא יודע לפענח
(HEVC/H.265 ממכשירי אפל, ProRes) למרות שהוא כן מצליח לחלץ ממנו תמונות ממוזערות.

## איך זה בנוי

אין תלויות ואין שלב build. HTML, CSS ו-JavaScript מודולרי בלבד. פותחים את
`index.html` וזהו.

```
vedit/
├── index.html          שלד הממשק
├── css/style.css       ערכת נושא כהה
└── js/
    ├── app.js          חיבור הכול: ממשק, קיצורים, שמירה אוטומטית
    ├── state.js        מודל הפרויקט, עריכה, היסטוריית בטל/בצע-שוב
    ├── media.js        ייבוא, מטא-דאטה, פילמסטריפ, צורת גל, IndexedDB
    ├── engine.js       מנוע הניגון: סנכרון וידאו, הרכבה על קנבס, מיקס אודיו
    ├── timeline.js     ציור הטיימליין וכל אינטראקציות העריכה
    ├── transitions.js  ציור 12 המעברים
    ├── inspector.js    פאנל המאפיינים
    ├── export.js       ייצוא הסרט
    ├── logger.js       יומן אבחון ודוח תקלות
    └── util.js         עזרים
```

**מנוע הניגון** מקצה אלמנט `<video>` לכל קליפ שנמצא בזמן הנוכחי (ומכין מראש את
הבא בתור), מסנכרן אותם לשעון אחד של הטיימליין (תיקון גס בקפיצה, תיקון עדין
בשינוי מהירות הניגון), ומצייר את הפריים המורכב על קנבס. האודיו עובר דרך גרף
WebAudio: לכל קליפ יש GainNode משלו, שמחשב עוצמה, דעיכות וקרוספייד של מעברים.

**המעברים** מקבלים שתי פונקציות ציור (הקליפ היוצא והנכנס) ומרכיבים ביניהן לפי
התקדמות המעבר, עם `clip` ו-`globalAlpha` של הקנבס. הקליפ היוצא ממשיך לשאוב
פריימים מהמקור שלו גם אחרי נקודת היציאה, כך שהמעבר מציג וידאו אמיתי ולא פריים קפוא.

**הייצוא** מריץ את הטיימליין בזמן אמת, מצלם את הקנבס עם `captureStream` יחד עם
מיקס האודיו, ומקליט ב-`MediaRecorder`. היתרון: אפס תלויות ותאימות רחבה.
המחיר: הרינדור אורך בערך כאורך הסרט, וצריך להשאיר את הלשונית פתוחה.

## דרישות ומגבלות

- **דפדפן:** Chrome או Edge עדכניים (מומלץ). Firefox עובד, אבל הייצוא יהיה
  ב-WebM בלבד. ב-Safari התמיכה חלקית.
- הפורמטים הנתמכים לייבוא הם אלה שהדפדפן יודע לנגן: בדרך כלל MP4/H.264,
  WebM, MOV (H.264). קובצי ProRes או HEVC אקזוטיים עלולים לא להיפתח.
- הכול רץ בזיכרון של הלשונית. לפרויקטים כבדים מאוד (שעות של 4K) זה לא הכלי.
- בקבצים ארוכים מ-12 דקות לא מצוירת צורת גל, כדי לא להעמיס על הזיכרון.
  האודיו עצמו מתנגן כרגיל.
- קובץ הפרויקט (`.vedit.json`) שומר את העריכה בלבד, לא את הווידאו. בפתיחה
  במחשב אחר צריך לקשר מחדש את הקבצים (לוחצים על פריט מסומן במאגר).

## הרצה מקומית

```bash
cd vedit
python3 -m http.server 8000
# ואז: http://localhost:8000
```

(פתיחה ישירה של `index.html` מהדיסק לא תעבוד, כי מודולי JavaScript דורשים
פרוטוקול http.)
