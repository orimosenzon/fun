# בדיקות

בדיקות דפדפן אמיתיות עם Playwright. הן מריצות את האפליקציה בכרום, מייבאות
קובצי וידאו אמיתיים, ובודקות את התוצאה על הקנבס עצמו.

## הרצה

```bash
pip install playwright                 # פעם אחת
./make_media.sh                        # יוצר קובצי בדיקה עם ffmpeg
cd .. && python3 -m http.server 8777 & # שרת מקומי
cd tests && python3 test_tracks.py
```

כדי לבדוק מול הגרסה החיה במקום המקומית:

```bash
VEDIT_URL=https://orimosenzon.github.io/fun/vibe_coding/vedit/ python3 test_motion.py
```

**חובה `channel="chrome"`** ולא chromium של Playwright, כי לזה האחרון אין
קודק H.264 והוא לא יפתח קובצי MP4.

## מה כל בדיקה מכסה

| קובץ | מה נבדק |
|---|---|
| `test_tracks.py` | כפתורי הערוץ: עין, השתקה, נעילה. **בודק את האפקט, לא רק שאין שגיאה** |
| `test_motion.py` | שהתמונה באמת משתנה בזמן ניגון (hash של הקנבס כל 220ms) |
| `test_scrub.py` | שגרירת הסמן אף פעם לא מייצרת פריים שחור |
| `test_edit.py` | ייבוא, הוספה, חיתוך, ripple delete, מעבר, ניגון, בטל |
| `test_overwrite.py` | שדריסת קליפ בגרירה מתריעה ונרשמת, ושבטל מחזיר |
| `test_ui.py` | לוחץ על כל כפתור, כלי, טאב, מחוון וקיצור, ומחפש שגיאות ריצה |
| `test_e2e.py` | עריכה מלאה של שלושה סרטונים, ייצוא, ואימות הפריימים המיוצאים |
| `test_trans.py` | מונטאז' של 12 המעברים באמצע המעבר |
| `test_mixed.py` | תמונות וקובצי אודיו לצד וידאו |
| `test_diag.py` | שדוח האבחון נבנה ומכיל את מה שצריך |

## לקח שנצרב כאן

`test_ui.py` דיווח "track header ok" בזמן שהעין, ההשתקה והנעילה **לא עבדו
בכלל**, כי הוא רק לחץ ובדק שאין שגיאת JavaScript. באותו אופן, ארבע חבילות
בדיקה עברו בזמן שהתמונה במוניטור הייתה קפואה, כי הן בדקו בהירות ממוצעת
ותמונה קפואה בהירה בדיוק כמו תמונה נעה.

**בדיקה שלא מאמתת את התוצאה עוברת תמיד.** לכן `test_tracks.py` בודק את הדגל
במודל *ואת* מה שקרה על הקנבס, ו-`test_motion.py` בודק שינוי בין פריימים.
