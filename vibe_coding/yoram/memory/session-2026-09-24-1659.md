# סשן 2026-09-24

## מה נעשה
סשן קצר של הכנה להרצה הראשונה בסביבת Apps Script אמיתית. לא נכתב קוד חדש; הקוד נקרא
במלואו והורכב ממנו נוהל התקנה ובדיקה על חשבון גוגל פרטי של אורי, כולל המכשולים
הצפויים בדרך.

**נוהל ההתקנה הידני** (בלי clasp, זו הדרך המהירה וגם הדרך שהעוזרת תשתמש בה):
1. עותק של הגיליון בדרייב הפרטי דרך `File → Make a copy`. העותק שומר נוסחאות וצבעי רקע,
   ולכן זיהוי השורות הצהובות (מטלות המדריך) עובד גם בו.
2. אזור הזמן של העותק ב-`File → Settings` קובע מתי בפועל נשלחות התזכורות, כי היומן נוצר
   באזור הזמן של הגיליון.
3. `Extensions → Apps Script`, הדבקת `Code.gs`.
4. המניפסט מוסתר כברירת מחדל: צריך `Project Settings` וסימון
   `Show "appsscript.json" manifest file in editor` לפני שאפשר להדביק אותו.
5. אחרי הדבקת המניפסט לוודא ש-`Services` בצד שמאל מציג `Calendar` ו-`Tasks`; אם לא,
   להוסיף ידנית ב-`+` עם אותם מזהים בדיוק.
6. רענון הגיליון מוסיף את תפריט `Course tools`.
7. בהרצה הראשונה יופיע מסך "Google hasn't verified this app". זה תקין לסקריפט לא מפורסם
   שרץ בחשבון של מי שכתב אותו: `Advanced` ואז `Go to ... (unsafe)` ואז `Allow`.

**שני מכשולים שזוהו לבדיקת התזכורות:**
- תאריכי הקורסים בגיליון הם מהעבר, ואירוע בעבר לא שולח תזכורת. לכן בטאב הבדיקה צריך
  להזיז את `Course start` ב-B1 לתאריך בעוד כ-9 ימים, כך שדד ליין אחד לפחות (הנוסחה `=B1-7`)
  ייפול בעוד יומיים, ואז התזכורת "יום לפני ב-9:00" מגיעה למחרת בבוקר.
- הבירור האמיתי, אם תזכורת ביומן משותף מגיעה גם לצד השני, דורש חשבון גוגל שני כ-trainer
  email. אם אין חשבון שני, אפשר לדלג על הבירור ולהדליק `INVITE_TRAINER_AS_GUEST: true`,
  שמזמין את המדריך כאורח לכל אירוע ולכן התזכורות שלו חלות בוודאות. המחיר: מייל הזמנה לכל אירוע.

## מצב נוכחי
ללא שינוי בקוד מאז 18/9. `Code.gs` ו-`appsscript.json` מוכנים להדבקה (שניהם הועברו ללוח
ההעתקה של אורי בסשן הזה). **הסקריפט עדיין לא הורץ ב-Apps Script אמיתי**: יצירת Tasks,
יצירת יומן, שיתוף ותזכורות לא נבדקו. צד הקריאה של הגיליון בדוק מקומית בלבד
(`tools/harness.js`).

## צעדים הבאים
1. להשלים את נוהל ההתקנה למעלה על עותק פרטי, עד `Course tools → Preview` שרץ בלי שגיאה.
2. `Create both` ולוודא: רשימה ב-tasks.google.com בשם הטאב, ויומן חדש עם אירוע יומי
   לכל דד ליין של המדריך.
3. בדיקת התזכורות לפי שני המכשולים שלמעלה, ולסגור את שאלת `INVITE_TRAINER_AS_GUEST`.
4. לברר מול העוזרת אם רשימת ה-Tasks היא למעקב שלה (כל השורות) או רק למטלות המדריך
   (`CONFIG.TASKS_ROWS`).
5. אחרי שהכל עובד: README באנגלית לעוזרת, שבנוי על נוהל ההתקנה שלמעלה.
