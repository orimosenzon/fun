# סשן 2026-09-18

## מה נעשה
- פתיחת הפרויקט: אוטומציה ל-PA של יורם. לכל קורס היא יוצרת ידנית רשימת Google Tasks עם
  תאריכי יעד ויומן משותף עם המדריך עם תזכורות (מייל + popup). כ-8 קורסים בסבב.
- ניתוח הגיליון של העוזרת: טאב לכל קורס עם `Course start`/`Course end` ב-B1/B2, ועמודת
  `Exact Date` שכבר מכילה נוסחאות יחסיות. צהוב = 8 מטלות של המדריך, 13 של העוזרת, אחת בלי
  תאריך. יש גם טאב `Assistants Procedure` עם מבנה דומה ועמודות שונות.
- החלטה: **Google Apps Script צמוד לגיליון הקיים**, בלי גיליון תבנית חדש ובלי שרת. תפריט
  `Course tools` שפועל על הטאב הפתוח: Tasks / Calendar / both / Preview. זיהוי עמודות לפי כותרת.
- נכתב `apps_script/Code.gs` + `appsscript.json` (Tasks v1 + Calendar v3, scopes מפורשים).
  הרצה חוזרת בונה מחדש רק אירועים שהסקריפט תייג. מייל המדריך נשמר ב-H1/I1, קישור ליומן ב-H2/I2.
- כלי פיתוח: `tools/export_sheet.py` (גיליון → JSON עם צבעי רקע) ו-`tools/harness.js` (mock של
  SpreadsheetApp, מריץ את `readCourseSheet` על הייצוא). 13 טאבי קורסים מתפענחים נכון, 2 טאבים
  שאינם קורסים נדחים עם הודעה.
- החלטת פרטיות: הריפו ציבורי, לכן קישור הגיליון ושמות המדריכים לא בריפו (הקישור בזיכרון
  הפרטי של אורי; `tools/out/` ב-.gitignore).
- כרטיס לפרויקט בדף הפרויקטים.

## מצב נוכחי
הקוד כתוב ונבדק מקומית רק בצד הקריאה של הגיליון. **עדיין לא הורץ ב-Apps Script אמיתי**:
יצירת Tasks, יומן, שיתוף ותזכורות לא נבדקו. לא הותקן clasp.

## צעדים הבאים
1. אורי: `File → Make a copy` לגיליון של העוזרת בדרייב שלו; להדביק את Code.gs ו-appsscript.json
   ב-Extensions → Apps Script (או `npm i -g @google/clasp` + `clasp login` ואז דחיפה מהטרמינל).
2. בטאב של קורס: `Course tools → Preview`, ואז `Create both` עם מייל בדיקה כמדריך.
3. לבדוק עם שני חשבונות אם תזכורות ביומן משותף מגיעות למדריך; אם לא,
   `INVITE_TRAINER_AS_GUEST: true`.
4. לברר מול העוזרת: רשימת ה-Tasks היא למעקב שלה (כל השורות) או רק למטלות המדריך?
   (`CONFIG.TASKS_ROWS`).
5. אחרי שעובד: README באנגלית לעוזרת עם הוראות התקנה (הדבקה ב-Apps Script + אישור הרשאות).
