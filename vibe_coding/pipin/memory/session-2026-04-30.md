# סשן 2026-04-30

## נושא הסשן
פיבוט אסטרטגי: מפרילנס לבניית מוצר עצמאי. בחירה בפיפין כפרויקט הליבה.

## ההחלטות שהתקבלו

### כיוון כללי
- **לא** פרילנס — **כן** מוצר עצמאי
- פיפין הוא הפרויקט — המרגש ביותר ומתאים ל"עבודה בתשלומים" (עצור בימים קשים, המשך בימים טובים)
- **מודל עסקי:** להתחיל בחינם, לבנות קהילה ועולם עשיר. מונטיזציה — אחרי הצלחה
- **IP טולקין:** לא בעיה כרגע (non-commercial fan project). הטולקין אסטייט בעיקר תוקף פרויקטים מסחריים

### החזון החדש של הפרויקט
**לא** single-player offline — **כן** shared world שנבנה ע"י הקהילה:
- משתמשים רבים חוקרים את אותו עולם
- הביקור הראשון במקום יוצר נרטיב + תמונה עם המפתח של אותו משתמש — ונשמר לכולם
- כל משתמש מביא את **מפתח ה-API שלו** (Gemini) — אפס עלות LLM מצד המפתח
- המוטיבציה: "יצירה משותפת של עולם ע"י הרבה אנשים והרבה מודלים גדולים"
- עולם טולקין — אבל סיפורים **חדשים שלא היו בספרים**

## השאלה הפתוחה — עדיין לא הוחלט

**מה "משותף" בעולם?**

**גרסה A — Location Canon (פשוטה יותר):**
הראשון שמגיע לברי יוצר אותה לכולם. כולם שאחריו רואים אותה.

**גרסה B — World Log (עשירה יותר):**
לכל שחקן יש הברי שלו, אבל יש "לוח עולם" עם אירועים משמעותיים מכל השחקנים.
מי שנכנס לברי רואה: *"לפני שלושה ימים, Elendur מצא את חרב ה-Westernesse בחצר האחורית."*

**הסשן הבא מתחיל כאן — לקבל החלטה זו ולהתחיל לבנות.**

## מה צריך לבנות (ברמה גבוהה)

המעבר מ-single-player → shared world דורש:
1. **שרת + DB** — לא localStorage. כל location שנוצר נשמר centrally
2. **Player identity** — לפחות anonymous session
3. **World state שיתופי** — מה שאחד יוצר, כולם רואים
4. **API key model** — כבר קיים בקוד, כל user מביא את המפתח שלו

## מצב הקוד הנוכחי
- המנוע single-player עובד (נרטיב + תמונות + מפה)
- `world.js` — 30 מקומות, דמויות, חפצים (טולקין)
- `server.py` — Flask קיים (רק endpoint /log כרגע)
- localStorage cache לתמונות ו-save game
- בעיית quota Gemini (429) — נפתרת עם billing או המתנה
