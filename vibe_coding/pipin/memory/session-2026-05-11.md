`/<path:path>` תפס בקשות API בחלק מהמקרים והחזיר 404.
**תיקון:** הוסף בדיקת prefix:
```python

    return jsonify({'error': 'not found'}), 404
```

התוצאה: alt text "תמונת המקום" הוצג במקום התמונה.
**תיקון:** החלפה ל-`onload`/`onerror` — ה-placeholder נשאר עד שהתמונה נטענת בפועל.
