# סשן 2026-06-14 — בדיקת מצב + איך לבדוק סטטוס בקשת הקווטה

## מה נעשה
סשן קצר. פתחנו את פיפין, סקרנו את המצב מהסשן הקודם (2026-06-08): ממתינים לאישור קווטה ל-`gpt-image-2` ב-Azure (East US 2, Global Standard, 50 RPM) כדי להוסיף יצירת תמונות מקומות.

## איך בודקים אם בקשת הקווטה נענתה (לסשן הבא)
1. **Azure AI Foundry** ([ai.azure.com](https://ai.azure.com)) → פרויקט haskala-foundry → Management center → Quota → region East US 2 → מודל gpt-image-2. אם ה-Limit קפץ ל-50 RPM — אושר.
2. **Azure Portal** → Help + support → All support requests — סטטוס הבקשה הרשמית.
3. הסימן החד-משמעי: ניסיון לפרוס deployment של gpt-image-2 שלא זורק "Insufficient quota".

## הערה טכנית
- `az` CLI **לא מותקן** במכונה. אם רוצים בדיקות Azure אוטומטיות בעתיד — להתקין (`pip install azure-cli` או apt). הוצע למשתמש, נשאר פתוח.

## פעולות פתוחות (ללא שינוי מ-06-08)
1. לבדוק אם הקווטה אושרה (כבר חלפו >5 ימים מהבקשה).
2. לפרוס deployment של gpt-image-2 ב-Foundry.
3. לכתוב קוד בפיפין לייצור תמונות מקומות (דפוס haskala: `OpenAI(base_url=..., api_key=...)` + `images.generate`).
4. להוסיף ל-.env: `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_ENDPOINT`, `AZURE_IMAGE_DEPLOYMENT=gpt-image-2`.
