## הבאג שנמצא
ה-catch-all route ב-server.py:
```python
@app.route('/<path:path>')
def serve_static(path):
    return send_from_directory('.', path)
```
תופס בקשות API (`/api/world/location/hobbiton`) לפני ה-route הספציפי בחלק מהמקרים. `send_from_directory` לא מוצא קובץ ומחזיר 404 — הנרטיב הcanon לא מציג לאורח.

**תיקון מוצע**: להוסיף prefix `/api/` לכל API routes ולהגן על הcatch-all:
```python
@app.route('/<path:path>')
def serve_static(path):
    if path.startswith('api/'):
        return jsonify({'error': 'not found'}), 404
    return send_from_directory('.', path)
```
