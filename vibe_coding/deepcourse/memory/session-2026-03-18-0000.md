### תיקונים בתצוגה
1. **שינוי שם נקודה**: "פרמטרים אמיתיים" → "פרמטרי יצירת הדאטה (a*, b*)" — מדויק יותר כי GD מוצא את מינימום ה-Loss, לא את פרמטרי היצירה
2. **הוספת הסבר ב-markdown**: הסברנו שפרמטרי יצירת הדאטה אינם בהכרח במינימום ה-Loss בגלל הרעש
3. **z_offset**: כל הנקודות מרחפות מעל המשטח (3% מטווח ה-Loss) כדי שלא יתמזגו איתו
4. **נקודת סיום (ציאן)**: opacity כפול + render אחרון = גלויה
5. **נקודת פרמטרי הדאטה (שחור)**: opacity=0.4 כדי שלא תסתיר

### הרחבת המסלול
- Surface מורחב: `a ± [-2, +4]`, `b ± [-8, +4]`
- נקודת פתיחה: `a_true + 3.5, b_true - 7.5` — גבוהה מאוד על המשטח
- n_steps: 500 → 5000
- דגימה לתצוגה: כל 5 → כל 10 צעדים
