#### תוכן השיעור
1. **מגבלות FC לתמונות** — פיצוץ פרמטרים, איבוד מרחביות, אין weight sharing, לא אינווריאנטי
2. **היסטוריה של CNN** — Hubel-Wiesel 1959 → Fukushima 1980 → LeCun/LeNet 1989 → AlexNet 2012
3. **ארכיטקטורת CNN** — forward pass מתמטי (קונבולוציה, MaxPool, ReLU)
4. **גזירה מתמטית מלאה:**
   - dL/db = Σ δ[i,j]
   - dL/dW[m,n] = Σ δ[i,j] · X[i+m, j+n]  (cross-correlation)
   - dL/dX[p,q] = full convolution של δ עם W הפוך
   - פישוט im2col: הכל הופך לכפל מטריצות (dW = dZ_col.T @ X_col)
   - MaxPool backward: גרדיאנט רק דרך argmax
   - Sigmoid + BCE: dL/dz = (a - y)/N
5. **מימוש NumPy מלא:** im2col, col2im, ConvLayer, MaxPoolLayer, ReLU, Dropout, FlattenLayer, FCLayer, CNN
6. **ארכיטקטורה:** Conv(32,3×3)→ReLU→MaxPool → Conv(64,3×3)→ReLU→MaxPool → FC(256)→Dropout → FC(1)→Sigmoid
7. **Adam** בכל השכבות, He initialization
8. לולאת אימון + גרפי loss/accuracy + confusion matrix + ווידג'ט אינטראקטיבי

#### החלטות עיצוב
- raw pixels (NCHW format) — ללא HOG, CNN לומד פיצ'רים אוטומטית
- padding=1 לשמירת גודל מרחבי דרך Conv
- Dropout(0.5) לפני FC האחרון
- דיוק צפוי: **~83-87%** (לעומת ~80% עם HOG+FC)
