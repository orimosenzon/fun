# Session 2026-03-22

## מה עשינו

### שיעור חדש: cat_vs_dog
- יצירת תיקייה `cat_vs_dog/` ונוטבוק `cat_vs_dog.ipynb`
- נוטבוק מלא עם 18 תאים, כולל:

#### Dataset
- CIFAR-10 — חתולים (class 3) וכלבים (class 5)
- 10,000 תמונות train + 2,000 test
- רזולוציה נייטיבית: 32×32 RGB

#### תוכן השיעור
1. הורדת CIFAR-10 ישירות מהאינטרנט עם progress
2. חקירת הנתונים: דוגמאות ויזואליות + התפלגות RGB
3. HOG — מימוש מ-scratch בנאמפי עם ויזואליזציה של גרדיאנטים
4. חילוץ פיצ'רים (1764 per image) + נרמול
5. FCNet — רשת Fully Connected מלאה בנאמפי: forward, backprop, Adam
6. אימון עם best-model saving (יעד: ~80%)
7. גרפי loss + accuracy
8. Confusion matrix + Precision/Recall/F1
9. דוגמאות נכונות ושגויות
10. ווידג'ט אינטראקטיבי: סליידר + כפתורי ניווט + "שגיאה הבאה"

#### החלטות עיצוב
- FC בלבד (ללא CNN) — בכוונה, כדי להדגים מגבלות ולהניע שיעורי CNN עתידיים
- HOG כ-preprocessing (numpy טהור) — מאפשר להגיע ל-~80% דיוק
- Adam optimizer — מימוש numpy
- שאלה על גרייסקייל + רזולוציה גבוהה: הובהר שHOG כבר ממיר לגרייסקייל פנימית, ו-CIFAR-10 הוא נייטיבית 32×32
