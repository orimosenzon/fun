# מחשבות על סוכן קולי — סיכום שיחה

## 1. הגדרות Claude Code

שיפרנו את `~/.claude/settings.json` כך שיאשר אוטומטית:
- **קריאה** — `Read`, `Grep`, `Glob`
- **חיפוש באינטרנט** — `WebSearch`, `WebFetch`
- **עריכת קבצים** — `Edit`, `Write`, `NotebookEdit`
- **פקודות git אינפורמטיביות** — `diff`, `log`, `show`, `branch`

רשת הביטחון: git מאפשר לראות ולבטל כל שינוי.

---

## 2. המצב בשוק — שיחה קולית מתמשכת עם AI

**קיים היום:**
- ChatGPT Advanced Voice Mode — הכי טבעי, דו-כיווני
- Gemini Live — כולל שיתוף מסך
- Claude — אין voice native, אבל יש API

**האתגרים הטכניים:**
- Latency — חייב להיות מתחת ל-500ms
- עבודה offline
- Wake word — הבחנה בין דיבור לסוכן לדיבור לאחרים
- אינטגרציה עם מערכות הרכב (Android Auto, CarPlay)

---

## 3. הזדמנות למפתח בודד

**היתרון של מפתח בודד:** זריזות — חברות גדולות איטיות ומפוחדות מסיכון.

**כיוונים אפשריים:**
1. **Integration layer** — לחבר Whisper + Claude/GPT לפלטפורמה ספציפית
2. **Vertical niche** — מוצר קולי לאוכלוסייה ספציפית (לא "קולי כללי")
3. **Open source infrastructure** — כלי שאחרים יבנו עליו
4. **Demo משכנע** — מספיק כדי לגייס שותפים

---

## 4. מה יהפוך מוצר לאהוב

לא הטכנולוגיה — אלא שהמוצר **מרגיש שהוא מבין אותך**.

מה חסר בפתרונות הקיימים:
- אין אישיות עקבית
- אין זיכרון לטווח ארוך
- לא מתאים את עצמו למשתמש ספציפי

**מוצר שמכיר את המשתמש לאורך זמן** — זה מה שאנשים יאהבו.

| אוכלוסייה | הצורך |

| אנשים עם מוגבלויות | שוק מוזנח עם צורך אמיתי |
