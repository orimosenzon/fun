# לאן היום? — מעיינות שקטים בעמק המעיינות

דף HTML יחיד (בלי build, בלי שרת) שממליץ על מעיין רגוע בעמק המעיינות (עמק בית שאן/חרוד) לפי היום הנוכחי. נבנה מפרומפט בודד — ראו [PROMPT.md](PROMPT.md).

## איך זה עובד

הפרומפט המקורי ביקש להתחשב בתאריך כדי למצוא מעיין שלא יהיה עמוס. הפתרון: ציון "עומס משוער" לכל אתר, שמחושב מחדש בכל טעינה מ-`new Date()` של הדפדפן (כלומר תמיד לפי היום האמיתי בו נפתח הדף):

- **ליבה (baseline 1–5):** כמה האתר פופולרי מטבעו (מגן השלושה המוכר ועד עין הבזק החבוי בתוך העיר).
- **יום בשבוע:** שישי/שבת מוסיפים לציון.
- **עונה:** יוני–אוגוסט (חופש גדול) מוסיפים לציון.
- **שעת היציאה:** בחירה של בוקר מוקדם / צהריים / אחר הצהריים מזיזה את הציון בהתאם.

האתר עם הציון הכי נמוך מוצג כ"המומלץ להיום" בכרטיס מודגש למעלה. חמשת האתרים במאגר הם אתרים אמיתיים בעמק המעיינות — כולל גם את הקלאסיקות העמוסות (גן השלושה, גן גורדון) וגם אפשרויות פחות מוכרות (עין הבזק, נחל עמל, מעיין חרוד).

## חשוב לדעת

זו הערכה היוריסטית בלבד, לא נתון תפוסה חי מהשטח. שעות פתיחה, מחירים ותנאים בפועל עלולים להשתנות — לכל אתר יש כפתור "שעות פתיחה ומחיר עדכני" שמפנה לחיפוש מהיר, וכפתור ניווט ישיר לגוגל מפות.

## הרצה

פתחו את `index.html` בדפדפן. דורש אינטרנט כדי לטעון את מפות גוגל המוטמעות בכל כרטיס (embed ללא API key, בפורמט `google.com/maps?q=...&output=embed`).

## בדיקה

נבדק עם Playwright (headless): חישוב הציון לפי תאריך אמיתי, מיון האתרים, כל 4 הפילטרים, ומעבר בין שלוש שעות היציאה. אפס שגיאות קונסולה.
