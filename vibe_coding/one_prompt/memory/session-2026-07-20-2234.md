הוקמה דוגמה חמישית באוסף **one_prompt**: `emek_hamaayanot_springs` — מתכנן טיול למעיינות עמק המעיינות, מפרומפט בודד ("בוקר טוב, אני רוצה לנסוע היום לעמק מהעיינות ולטבול במעיין סודי...").
