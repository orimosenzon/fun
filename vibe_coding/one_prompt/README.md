# one_prompt

אוסף דוגמאות של תוכנה שנוצרה על ידי Claude Code מפרומפט בודד.

## מבנה

כל דוגמה מקבלת תת-תיקייה משלה, בשם תיאורי קצר (למשל `snake_game/`, `expense_tracker/`).
בתוך כל תת-תיקייה:

- `PROMPT.md` — הפרומפט המקורי, כפי שנכתב, בלי עריכה
- שאר הקבצים — התוכנה שנוצרה מהפרומפט

## הוספת דוגמה חדשה

1. `one_prompt/<שם-תיאורי>/PROMPT.md` — שמור את הפרומפט המקורי
2. תן ל-Claude Code לייצר את התוכנה בתוך אותה תיקייה, מהפרומפט הזה בלבד
