# עליית הנאציזם בגרמניה — שיעור אינטראקטיבי

מחברת Jupyter בעברית (RTL מלא), שמלמדת את עליית המשטר הנאצי בגרמניה 1930–1939 דרך גרפים אינטראקטיביים, ציר זמן ניתן לגלילה, ושאלוני בדיקה עצמית. נבנתה כולה מפרומפט בודד — ראו [PROMPT.md](PROMPT.md).

צפייה באונליין (ללא הרצה): https://drive.google.com/file/d/1vEaQNq_N6zq7Bnt1PHqP9a6ODja6VBss/view?usp=drive_link

## תוכן

- רקע: מפרובליקת ויימאר ועד המשבר הכלכלי
- הבחירות הדמוקרטיות ומינוי היטלר לקנצלר — גרף אינטראקטיבי עם סליידר
- שריפת הרייכסטג — שאלת הבנה עם משוב מיידי
- חוק ההסמכה — תרשים עוגה של ההצבעה בפועל
- החולצות החומות (SA) וההחרם על עסקים יהודיים
- ליל הסכינים הארוכות — שאלת הבנה
- ליל הבדולח — תרשים נתונים
- ציר זמן אינטראקטיבי לכל האירועים המרכזיים
- בוחן סיכום עם ציון

## הרצה

```bash
pip install jupyter ipywidgets matplotlib numpy python-bidi
jupyter notebook lesson.ipynb
```

הריצו את כל התאים לפי הסדר (Shift+Enter). כל האינטראקציות (סליידרים, שאלונים) דורשות ליבת Jupyter פעילה.

## הערה טכנית: עברית בגרפים

בניגוד לתאי Markdown/HTML (שהדפדפן מיישם עליהם BiDi אוטומטית), **matplotlib לא מיישם אלגוריתם BiDi** — טקסט עברי בכותרות/תוויות של גרפים היה מוצג הפוך בלי טיפול. לכן כל טקסט שמוזן לגרפים עובר דרך `he()` ב-[build_notebook.py](build_notebook.py), שמשתמש ב-`python-bidi` כדי לסדר אותו נכון.

## מבנה

- `build_notebook.py` — הסקריפט שיוצר את `lesson.ipynb` (מקור לעריכה עתידית)
- `lesson.ipynb` — המחברת הסופית, עם הפלטים כבר מורצים
