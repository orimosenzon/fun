# סשן 2026-07-05 — פיזיקה מתקדמת וחוויית טיסה

## מה נעשה
1. **תיקוני UX מפידבק חיצוני**: חיסכון CPU במסך פתיחה (רינדור כל פריים רביעי), i18n עברית/אנגלית מלא (מודול חדש `i18n.js`, מתג L/כפתור), תיקון באג חצי RTL בעזרה (`<span dir="ltr">`).
2. **היגוי fly-by-wire**: הסטיק מפקד על קצב פנייה (לא בנק קבוע) — הבקר גוזר בנק לפי פנייה מתואמת φ=atan(V·ω/g). הטיית נחיר אחורי (thrust vectoring, ±15°, מד"ר אקטואטור) מאפשרת סבסוב בריחוף. עלרוד הורחב מ-±33° ל-±60°.
3. **פיצוץ התרסקות מרשים** (`explosion.js` חדש): כדור-אש, רסיסים בליסטיים, עשן, גיצים, אור, רעידת מצלמה, סאונד boom.
4. **פולסי RCS** (Z/X/Shift): מנת דחף קצובה במקום כוח מתמשך — בהשראת מנועי בקרת-מצב חלליות אמיתיים (מחקר: Shuttle RCS, ESA).
5. **ספול טורבינה**: מד"ר מסדר ראשון על המצערת/עילוי (מחקר: JT9D~1.5s, F/A-18~0.6s). פסי HUD דו-שכבתיים (בפועל+פקודה).
6. **צימוד ג'ירוסקופי**: הרוטור המסתובב מצמיד עלרוד↔סבסוב (מחקר: gyroscopic precession באוויונים).
7. **רוח Dryden אמיתית** (`wind.js` חדש, node-safe): מסנני MIL-F-8785C אמיתיים + רוח שוררת + עילוי רכסים. כל האווירודינמיקה עברה למהירות-אוויר יחסית.
8. **הגברת דחף אחורי** (בבקשת המשתמש אחרי שראה את התוצאה): maxRear 3000→4600N, boostRear 2600→3800N. מהירות שיוט קפצה ל-~111 m/s.

כל שינוי אושר מראש בתוכנית מפורטת (plan mode) עם מחקר רשת ומקורות. 34 בדיקות פיזיקה headless עוברות (היו 18). קומיטים: fe28f2b (מגע), e30f574 (הפיזיקה המתקדמת) + תיקון מהירות הדחף.
