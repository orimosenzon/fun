# סשן 2026-07-02 — יצירת המשחק מאפס

## מה נעשה
- נוצר פרויקט **fable**: משחק תלת־ממד של אופנוע סילון מעופף (Three.js 0.160 מ-CDN, ללא build).
- מודל פיזיקלי מלא של גוף קשיח: כוחות בנקודות הצינורות (τ=r×F), משוואות אוילר עם איבר ג'ירוסקופי, גרר ריבועי לכל ציר, מומנט שבשבת (weathervane), אפקט קרקע, אוויר דליל, קפיץ־משכך בקרקע, התרסקות וריספון. פירוט ב-project-knowledge.md.
- עולם פרוצדורלי דטרמיניסטי: הרים/עמקים/יערות/כפרים/אגמים/עננים, משטח המראה, מסלול 16 טבעות עם טיימר ושיא.
- שליטה לפי המפרט: רווח=בוסט אחורי, Z/X=בוסט צינור שמאלי/ימני (גלגול), S=בוסט מרכזי; בנוסף ↑/↓ מצערת, E/D עילוי, ←/→ היגוי, T מייצב, C מצלמה.
- חבילת 15 בדיקות פיזיקה headless ב-Node (`tests/simtest.js` + README) — כולן עוברות.
- אומת בדפדפן headless: הדף נטען ומרנדר בלי שגיאות (מרקר `data-ok` + צילומי מסך).

## החלטות ובאגים שתוקנו
1. מרכז העילוי חייב לעבור דרך מרכז המסה — אחרת מומנט קבוע הופך את האופנוע (הצינורות הוזזו ל-z=0).
2. תוקן היפוך סימן בערוץ ה-pitch של מייצב הטיסה (משוב חיובי → התהפכות בריחוף).
3. נוסף `findSpawn()` — חיפוש עמק פתוח עם מסדרון המראה פנוי (ספון קודם פנה אל קיר הר).
4. מצב `?demo` ב-URL להמראה אוטומטית לצורכי בדיקה/צילום.

## הרצה
`python3 -m http.server 8791` בתיקיית fable → http://localhost:8791/

## צעדים הבאים (רעיונות)
- התנגשות בעצים/בתים (כרגע עוברים דרכם).
- שמירת שיא ב-localStorage; מסלולי טבעות נוספים/קשים.
- אפקט חלקיקים לאבק/עשן, סאונד עשיר יותר.
