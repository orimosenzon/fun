# fable — אופנוע סילון מעופף (משחק תלת־ממד)

## מה זה
משחק דפדפן תלת־ממדי: השחקן טס על אופנוע סילון מרחף בעולם פרוצדורלי (הרים, עמקים, יערות, כפרים, אגמים) ועובר דרך 16 טבעות כתומות במהירות מרבית. דגש על **פיזיקה ריאליסטית** של גוף קשיח.

## סטאק
- Three.js 0.160 מ-CDN (jsdelivr, import map) — אין build, אין תלויות מקומיות.
- קבצים: `index.html` + `js/{main,physics,world,bike,hud,audio,noise}.js`
- הרצה: `python3 -m http.server 8791` בתיקיית הפרויקט → http://localhost:8791/
- `?demo` ב-URL = המראה אוטומטית (לצילומי מסך/בדיקות headless).

## מודל פיזיקלי (physics.js)
- גוף קשיח: מיקום+מהירות, קווטרניון+מהירות זוויתית בפריים הגוף, משוואות אוילר כולל איבר ג'ירוסקופי ω×(Iω). אינטגרציה semi-implicit Euler ב-120Hz.
- צירים בגוף: X=ימינה, Y=למעלה, Z=קדימה. **מוסכמת סימנים קריטית:** מומנט חיובי סביב X מוריד את האף; roll חיובי סביב Z מרים את צד ימין (בנק שמאלה).
- כל סילון = כוח בנקודת הצינור → מומנט מהגאומטריה (τ=r×F). שלושת צינורות העילוי ממוקמים כך שהשקול עובר דרך מרכז המסה (אחרת נוצר מומנט קבוע והאופנוע מתהפך — באג שתוקן).
- אווירודינמיקה: גרר ריבועי לכל ציר גוף (מהירות שיא ~87m/s בטיסה מאוזנת), weathervane (האף מתיישר עם הזרימה) → פניות מתואמות בבנק, דעיכת סיבוב.
- מייצב טיסה (FBW): ערוץ roll מכוון לזווית בנק לפי החצים, ערוץ pitch מיישר. כבוי בזמן בוסט Z/X (גלגולים חופשיים) או ב-T.
- אפקט קרקע (+35% עילוי מתחת ל-5מ'), אוויר דליל מעל 500מ'.
- קרקע: קפיץ-משכך + חיכוך; התרסקות אם vn<-11m/s / התהפכות / נגיעה במים. ריספון אוטומטי אחרי 2.6ש'.
- כיוונון: אובייקט `TUNE` בראש physics.js.

## שליטה
↑/↓ מצערת אחורית · E/D עילוי קולקטיבי · ←/→ בנק/היגוי · Space בוסט אחורי · Z/X בוסט צינור שמאלי/ימני (גלגול) · S בוסט צינור מרכזי (עילוי בכיוון הגוף) · C מצלמה · R איפוס · T מייצב · M שקט · H עזרה

## עולם (world.js)
- `terrainHeight(x,z)` — פונקציה אחת משותפת לרינדור ולפיזיקה (simplex fbm: גבעות + רכסי ridge + שפה גבוהה בקצה העולם). זרעים קבועים → עולם דטרמיניסטי.
- `findSpawn()` מחפש עמק פתוח עם מסדרון המראה פנוי לכיוון +Z (לקח: ספון אקראי מול קיר הר = התרסקות מיידית).
- מים ב-y=2 (נחיתה במים = התרסקות), ~900 עצים ו-6 כפרים ב-InstancedMesh, עננים, כיפת שמיים בשיידר.

## בדיקות
- `simtest.js` (בסקראצ'פד של הסשן, שווה להעתיק לפרויקט אם ממשיכים) — 15 בדיקות פיזיקה headless ב-Node: מנוחה על המשטח, ריחוף, מהירות שיא, פניות בבנק, גלגולי Z/X, עילוי S, התרסקות, ריספון, יציבות 60ש'. דורש `npm i three@0.160.0` + package.json עם type:module + עותקי physics/world/noise.
- בדיקת דפדפן: headless chrome עם `--enable-unsafe-swiftshader`, מחפשים `data-ok="1"` ב-DOM (מוצב אחרי הפריים הראשון) ו-div#err ריק. רינדור תוכנה איטי מדי לבדיקת gameplay ארוכה — לזה יש את בדיקות ה-Node.
