# jetbikes — אופנועי סילון מעופפים

כל פרויקטי האופנוע המעופף במקום אחד, תיקייה לכל פרויקט:

| תיקייה | מה זה | בדף הפרויקטים |
|---|---|---|
| `fable/` | משחק טיסה: מנוע סילון אחורי, שלושה צינורות עילוי, 16 טבעות | כן |
| `jetbike_game/` | MJ-5, מסלול העמק: 12 טבעות ונחיתה מדויקת, על המנוע של הסרט (Opus 5.5, 9/2026) | כן |
| `jetbike_film/` | MJ-5, סרט טיסת ניסוי: סימולציה 6DOF, רינדור אופליין וסאונד מסונתז | לא |
| `opus5/` | אופנוע סילון מעל עמק אלפיני, קובץ HTML יחיד (7/2026) | לא |
| `motorcycle_3d/` | 3D Flying Motorcycle, הניסיון הראשון (6/2025). הכתובת הישנה `vibe_coding/t.html` היא קישור סימבולי לכאן | לא |
| `codex_motojet/` | MOTOJET / VECTOR, משחק טבעות בעולם פרוצדורלי (לא ב-git) | לא |

## קישורים ישנים

עד 4.10.2026 הפרויקטים ישבו ישר תחת `vibe_coding/`, וקישורים אליהם פורסמו בפייסבוק.
כדי שימשיכו לעבוד, בכתובות הישנות (`vibe_coding/fable`, `opus5`, `jetbike_film`, `jetbike_game`)
נשארו קישורים סימבוליים לתיקיות כאן. הפריסה ל-GitHub Pages אורזת את האתר עם
`tar --dereference` (בתוך `actions/upload-pages-artifact`), ולכן כל קישור כזה מתפרסם כעותק מלא
והכתובת הישנה עונה בדיוק כמו החדשה. **אסור למחוק את הקישורים האלה.**
