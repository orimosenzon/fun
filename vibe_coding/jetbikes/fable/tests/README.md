# בדיקות פיזיקה headless

הרצה (מתוך תיקיית tests):
```bash
echo '{"type":"module"}' > package.json
npm install three@0.160.0
cp ../js/{physics,world,noise,wind}.js .
node simtest.js
```
34 בדיקות: מנוחה על המשטח, ריחוף, מהירות שיא בטיסה מאוזנת, פניות בבנק,
היגוי fly-by-wire (קצב פנייה בלתי-תלוי במהירות), סבסוב ריחוף בהטיית נחיר (thrust
vectoring), פולסי RCS (מנת דחף מדויקת, אי-תלות ב-framerate, הגבלת קצב), עלרוד
מוגדל (±60°), ספול טורבינה (מד"ר מסדר ראשון — 63% אחרי τ), צימוד ג'ירוסקופי של
הרוטור (עלרוד→סבסוב) ושימור תנע כולל שלדה+רוטור, מערבולת Dryden (סופיות,
ממוצע אפס, עוצמה שפויה) וסחיפה ברוח שוררת, התרסקות בנפילה חופשית, ריספון,
יציבות נומרית ב-60 שניות טיסה, ושימור תנע זוויתי (כיוון וגודל) בסחרור חופשי.

הערה: הבדיקות מאפסות `TUNE.windSpeed = 0` לאווירה רגועה ודטרמיניסטית;
בדיקות הרוח מדליקות אותה מקומית.
