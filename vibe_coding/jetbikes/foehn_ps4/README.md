# FÖHN ל-PlayStation 4

פורט native של FÖHN (האופנוע הסילוני בעמק האלפיני) לפלייסטיישן 4 פרוצה, שנהנה מה-GPU של
הקונסולה במקום לרוץ בדפדפן. נבנה ב-++C עם רנדרר GLES2, בדיוק מה שה-PS4 מריץ דרך Piglet.

המקור של המשחק הוא אפליקציית הרשת ב-`../foehn/` (Three.js). כאן מתורגמים ה**סימולציה**
במלואה וה**רנדר** מחדש מול ה-GPU.

## מצב נוכחי
- **מודל הטיסה המלא מתורגם ל-++C ומאומת**: גוף קשיח 6-DOF ב-600Hz, מנוע ההיתוך וחמשת
  הנחירים, האווירודינמיקה, מחשב הטיסה (FCS) עם הקצאת 12 מפעילים ב-least squares, ומודל הרוח
  ההרים. `src/sim/` הוא תרגום שורה-מול-שורה של `../foehn/js/sim/`.
- **הטרמין האמיתי**: אותו `terrain.bin` + `meta.json` + `backdrop.bin` של המשחק המקורי. כל
  הריבוע של 12 ק"מ ב-256 חלקות עם ארבע רמות פירוט, וההרים הרחוקים שמעבר לו.
- **שמיים ואוויר** (`render/env.cpp`): אטמוספרה מחושבת (Rayleigh + Mie + אוזון) לטבלת שמיים אחת
  שמזינה את צבע השמיים, האובך, האור הסביבתי וההשתקפויות. חמש שעות ביום, שכבת עננים עם צל על
  הקרקע, דיסקת שמש.
- **קרקע** (`render/terrain_r.cpp`): השיידר של המקור (שכבות גיר, דרדרת, כרי דשא, שלג, חופים,
  חצץ הנחלים), צללי ההרים אפויים לפי השעה, הצללה סביבתית. מקרוב: תצלומי הקרקע של המקור (דשא,
  סלע, חצץ, CC0 מ-Poly Haven), אפויים לקובץ אחד בלי JPEG (`tools/bake_ground.py` → `assets/ground.bin`).
- **מים** (`render/water_r.cpp`): אגמים עם השתקפות מישורית אמיתית, צבע קרחוני לפי עומק, קצף
  בחוף, נצנוץ שמש, אדוות וקצף מתחת לסילונים; שישה נחלים זורמים עם מים לבנים בקטעים התלולים;
  רסס במפלים.
- **מזג אוויר** (`render/weather_r.cpp`): בהיר, גשם (קווי טיפות לפי התנועה היחסית למצלמה, שמיים
  מעוננים, קרקע רטובה) ושלג (פתיתים, כיסוי עד קרקעית העמק). הרוח של הפיזיקה נושאת את הטיפות.
  ארבע רמות רוח.
- **האופנוע**: המודל של המקור (`render/bike_mesh.cpp`) עם החומרים של המקור, חלק אחרי חלק:
  מתכתיות, חספוס ולכה שקופה על הצבע (`pbr()` ב-`render/env.cpp`, המודל של three.js). המתכת משקפת
  את השמיים והעננים, לוחות המרכב מעוגלים בקצוות כמו במקור, השמשה שקופה, והפנסים, הליבה והנחירים
  מאירים לפי המנוע המדומה.
- **צל בזמן אמת** (`render/shadow.cpp`): מפת צל של 140 מ' סביב האופנוע, כמו במקור. האופנוע מטיל
  צל על הקרקע ועל הפדים ומצל על עצמו. `--shadow 0` מכבה, `--shadow 1024` מקטין את המפה.
- **הפדים** (`render/props_r.cpp`): שמונת מקומות הנחיתה, מצוירים בשיידר בלי טקסטורה (אספלט, טבעת
  צהובה, עיגול לבן, F בבסיס ו-H בשאר), והמזח מעץ.
- **סילונים** (`render/fx.cpp`): פלומה על כל אחד מתשעת הנחירים לפי הדחף שיוצא ממנו באמת (יהלומי
  הלם, להבת ה-overdrive באחורי, סגול בבעיטת צד), ואבק, רסס או שלג שעולים מהמקום שבו הסילון פוגע
  בקרקע או במים.
- **מעבר post** (`render/post.cpp`): bloom, קרני שמש, טשטוש תנועה של המצלמה, פסי מהירות, חשיפה,
  ACES, גוון, הצללת פינות וגרעין, באותם מספרים כמו במקור. הכול ב-8 ביט ובלי טקסטורת עומק (ראה
  `toolchain/NOTES.md`). `--nopost` מכבה אותו ומחזיר את ה-tone mapping לסוף כל שיידר.
- **שליטה כמו בגרסת הרשת** (`sim/rider.hpp`): חץ למטה מושך את המוט ומטפס, מצערת, בלם ו-overdrive
  באותם חוקים של `js/sim/game.js`.
- **מארח PC** (X11 + EGL + GLESv2) לפיתוח וכיול על הלינוקס, **ואותו קוד גרפי** עובר ל-PS4.

צילומים ב-`docs/`. חמישה מהם הם השוואה מול גרסת הרשת מאותה מצלמה (המקור למעלה, הפורט למטה):
`compare_golden.png`, `compare_bike.png`, `compare_hover.png`, `compare_pad.png` ו-`compare_shadow.png`.
מה שחסר בפורט נראה שם מיד: היער, הכפר, והחלקים שזזים במודל (עלי הנחיר האחורי).

זמן פריים על GTX 1060 ב-720p: כ-4.85 אלפיות שנייה (כולל מעבר ההשתקפות, מפת הצל שעולה כ-0.13,
ומעבר ה-post שעולה בין 0.1 ל-0.4), ו-5.7 כשהמצלמה צמודה לאופנוע מעל הפד. כ-1.9 מתוכן הן תצלומי הקרקע, ורובן הסינון האניזוטרופי שלהם: `--aniso 4` מוריד כ-0.4
כמעט בלי הבדל לעין, `--aniso 1` כ-1.3 עם קרקע מטושטשת בזווית שטוחה.

## עדיין לא (הצעדים הבאים)
- לחבר את `platform_ps4.cpp` מול ה-SDK המותקן (ראה `toolchain/NOTES.md`).
- החלקת קצוות (אין MSAA ליעד רינדור ב-GLES2 בסיסי; מועמד: FXAA אחרי ה-post).
- יער וצמחייה (וכשיגיעו, גם הם ייכנסו למפת הצל).
- פיצוץ ושברים בהתרסקות (באים עם רצף ההתרסקות של המשחק), נחירים ובלמים שזזים במודל.
- מבצר, כפר, חיות, מנהרות, 10 האירועים, HUD, העלילה, קול.
- מיפוי אנלוגי מלא של ה-DualShock 4 (כרגע סף דיגיטלי).

## בנייה והרצה (PC)
```bash
cmake -B build && cmake --build build -j
./run.sh                      # הדרך הנוחה: בונה אם משהו השתנה ומריץ, מכל תיקייה
./run.sh dusk rain gale       # שעה, מזג אוויר ורוח במילים (morning/noon/afternoon/golden/dusk, clear/rain/snow, calm/breeze/wind/gale)
./run.sh shot pic.png golden  # צילום ל-PNG במקום חלון. כל דגל אחר עובר לתוכנית כמות שהוא; ./run.sh -h לרשימה
./build/foehn                 # אינטראקטיבי (צריך DISPLAY)
./build/foehn --time golden --wx rain --wind 2     # שעה, מזג אוויר, רוח
./build/foehn --shot out.ppm  # מרנדר פריים אחד לקובץ (offscreen)
./build/foehn --shot out.ppm --pos 1600,1500,14,0,30 --frames 60   # צילום ממקום נתון: x,z,גובה,כיוון,מהירות
./build/foehn --shot out.ppm --bench --frames 300                  # מדידת זמן פריים
./build/foehn --shot out.ppm --side --boost --pos -1500,2300,20,20,60 --frames 90   # מבט צד קרוב עם overdrive
./build/foehn --shot out.ppm --cam 1606,984,1499,1596,982,1501     # מצלמה קבועה (עין ויעד), להשוואה מול dbg.free בגרסת הרשת
./build/foehn --nopost        # בלי מעבר ה-post
./build/foehn --invert        # חץ למעלה מטפס
python3 tools/bake_ground.py  # אופה את תצלומי הקרקע (build.sh עושה את זה לבד; צריך Pillow)
./build/test_sim              # בדיקת פיזיקה headless (בלי גרפיקה)
```
או ישירות: `./build.sh`.

### שליטה (PC)
כמו בגרסת הרשת: חצים ימינה/שמאלה — פנייה · **חץ למטה — טיפוס, חץ למעלה — צלילה** (`--invert`
הופך) · W,S — מצערת · A,D — צעד צד בריחוף, בעיטת צד במהירות · רווח — overdrive · Shift או B —
בלם · R — זינוק מחדש · T — שעה · X — מזג אוויר · N — רוח · Esc — יציאה.

## בנייה ל-PS4
ראה `toolchain/NOTES.md`. בקצרה: OpenOrbis toolchain → `cmake -DPS4=ON` → `.pkg` → התקנה
דרך GoldHEN. **לא לעדכן את מערכת הקונסולה.**

## מבנה
```
src/sim/      הסימולציה (פורט נאמן של js/sim) — בלי תלות בפלטפורמה
src/render/   רנדרר GLES2 — בלי תלות בפלטפורמה
src/platform/ PC (X11+EGL) ו-PS4 (OpenOrbis+Piglet) מאחורי ממשק אחד
src/main.cpp  לולאת המשחק: קלט → sim.advance → מצלמה → render
assets/       symlink לטרמין של ../foehn, ו-ground.bin האפוי (לא בגיט)
tools/        bake_ground.py: תצלומי הקרקע של ../foehn/assets/ground לקובץ גולמי
docs/         צילומים, כולל השוואות מול גרסת הרשת
toolchain/    הגדרות ה-build ל-PS4
```
