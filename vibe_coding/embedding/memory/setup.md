# הוראות הפעלה — פרויקט שיכון

## דרישות מוקדמות

התקן את החבילות הנדרשות:

```
pip install -r requirements.txt
```

בפעם הראשונה,
gensim
יוריד את מודל
GloVe
(כ-128MB) אוטומטית.

## הפעלה

```
python app.py
```

הסרבר עולה על פורט
5000
.
אם הפורט תפוס — הוא ידלג אוטומטית לפורט הבא הפנוי (5001, 5002, ...).
הפורט בפועל יופיע בטרמינל:

```
Starting server on port 5000
```

## גישה לאפליקציה

פתח בדפדפן:

```
http://localhost:5000
```

(או הפורט שהופיע בטרמינל)

## מצבים באפליקציה

| מצב | תיאור |
|-----|--------|
| Quiz | שאלות אנלוגיה אוטומטיות |
| Free Mode | בנה אנלוגיה חופשית מתוך pool של מילים |
| Visualize | הקרנת וקטורים ל-2D (PCA / t-SNE) |
| Nearest | מצא שכנות קרובות לכל מילה |
