# רודסטר

סימולטור פיזיקלי של הרודסטר שטסלה הציגה ב-15/10/2026: מכונית שנצמדת לקירות במאווררי יניקה וקופצת על סילוני אוויר דחוס. יש בו גם מרכז מקצועי עם הסברים והדמיות אינטראקטיביות.

- `index.html`: הסימולטור. 3 דגמים (פרפורמנס, ת'ראסט, רוקט), 8 תרחישים (הקיר מההדגמה, קיקפליפ מעל המכוניות, מסלול תאוצה, צינור, לולאה, קיר אנכי, ריחוף), מצלמה עוקבת, מבט מתוך הרכב ומצלמה חופשית.
- `academy.html`: המרכז המקצועי. 13 פרקים: צמיגים, יניקה, הקיר, גז קר, COPV, בקרת טיסה, תקציב אוויר, הגוף, הנעה, היסטוריה ובדיקת מציאות.

סטטי לגמרי, בלי build. Three.js 0.170 מ-jsdelivr.

```
python3 -m http.server 8790      # ואז http://localhost:8790/
node tools/test_physics.mjs      # בדיקות הפיזיקה מול המספרים מההדגמה
```

פרמטרים ב-URL: `?v=rocket&s=wall&cam=cockpit&auto=1`.
