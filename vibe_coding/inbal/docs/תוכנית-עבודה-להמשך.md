# תוכנית עבודה להמשך

## מצב נוכחי ✅
האפליקציה בנויה ועוברת build. נשאר לחבר לבסיס נתונים אמיתי (Supabase) ולהעלות ל-Vercel.

---

## שלב א - פריסה ראשונית (דחוף)

### 1. חיבור ל-Supabase
- [ ] פתיחת חשבון Supabase
- [ ] יצירת project חדש (region: EU West)
- [ ] העתקת Connection strings ל-`.env.local`
- [ ] הרצת `npx prisma migrate dev --name init`
- [ ] הרצת `npm run db:seed` לנתוני דוגמה

### 2. העלאה ל-Vercel
- [ ] יצירת repository ב-GitHub
- [ ] `git push` ראשוני
- [ ] פתיחת חשבון Vercel + חיבור ל-GitHub repo
- [ ] הזנת כל ה-Environment Variables ב-Vercel
- [ ] Deploy ראשוני + בדיקה

### 3. Google OAuth (כדי שתלמידים יוכלו להיכנס עם Google)
- [ ] פתיחת project ב-[console.cloud.google.com](https://console.cloud.google.com)
- [ ] יצירת OAuth 2.0 credentials
- [ ] הוספת Authorized redirect URI: `https://[your-domain]/api/auth/callback/google`
- [ ] עדכון GOOGLE_CLIENT_ID/SECRET ב-Vercel

## שלב ב - תכונות חסרות (חשוב)

### העברת שיעורים (Transfer)
כרגע ניתן רק לבטל. צריך להוסיף:
- [ ] בחירת שיעור חלופי בממשק התלמיד
- [ ] עדכון `transferredFromId` ו-`transferredToId`
- [ ] הצגת "הועבר מ..." בפרטי השיעור

### שינוי סיסמה
- [ ] דף "הגדרות" לתלמיד - שינוי סיסמה
- [ ] שליחת "שכחתי סיסמה" במייל (דורש הגדרת Email provider)

### ייצוא ודוחות
- [ ] ייצוא רשימת נוכחות לשיעור כ-PDF או Excel
- [ ] דוח חודשי - הכנסות לפי קבוצה
- [ ] ייצוא רשימת תלמידים עם סטטוס תשלום
