# אפליקציית ניהול סטודיו קרמיקה - מה האפליקציה עושה

## מטרה
אפליקציית Web לניהול סטודיו קרמיקה. פותחה עבור מורה קרמיקה שמנהלת מספר קבוצות תלמידים ומתקשה לעקוב אחרי הרשמות, ביטולים, העברות ותשלומים.

---

## שני ממשקים

### ממשק המנהלת (המורה)
- **דשבורד ראשי** - תצוגת שיעורים קרובים: כמה יבואו, מי ביטל, מי הועבר. סטטיסטיקות: מספר תלמידים, קבוצות, הכנסות החודש.
- **ניהול קבוצות** - יצירת קבוצה (שם, יום, שעה, משך, מיקום, קיבולת). יצירה אוטומטית של 8 שיעורים קדימה. צפייה בתלמידים ובשיעורים.
- **ניהול שיעורים** - לכל שיעור: רשימת נוכחות מלאה עם סטטוס לכל תלמיד (יבוא / ביטל / הועבר / נעדר). עדכון נוכחות בזמן אמת.
- **ניהול תלמידים** - רשימת כל התלמידים, הוספת תלמיד חדש. לכל תלמיד: הקבוצות שלו, היסטוריית נוכחות, היסטוריית תשלומים.
- **ניהול תשלומים** - תצוגה מרכזית: מי שילם החודש, מי לא. הוספת תשלום לתלמיד (סכום, תיאור, תאריך, סוג). הכנסות החודש הנוכחי.

### ממשק התלמיד
- **הדשבורד שלי** - הקבוצות שלי, השיעורים הקרובים, סטטוס תשלום החודש.
- **ביטול שיעור** - ביטול חד-פעמי לשיעור ספציפי (לא מוחק את ההרשמה לקבוצה).

## תהליכים עיקריים

| תהליך | מי עושה | מה קורה |
|--------|---------|----------|
| יצירת קבוצה | מנהלת | נוצרת קבוצה + 8 שיעורים קדימה |
| הרשמת תלמיד לקבוצה | מנהלת | תלמיד נרשם לכל השיעורים העתידיים |
| ביטול חד-פעמי | תלמיד / מנהלת | סטטוס השיעור הספציפי משתנה ל-"ביטל" |
| העברת תלמיד | מנהלת | סטטוס משתנה ל-"הועבר", מופיע בשיעור אחר |
| תשלום | מנהלת | רישום תשלום לתלמיד עם פרטים ותאריך |
| מחיקת שיעורים מיושנים | - | אוטומטי - מוסיפים שיעורים חדשים לפי הצורך |
