# פתרונות WhatsApp לאפליקציה — מחקר 2026

## רקע
נכון ל-1 ביולי 2025, Meta עברה לתמחור לפי **הודעה בודדת** (במקום לפי שיחה).
הנפח הצפוי: 50–200 הודעות Utility לחודש (ישראל).

---

## 1. Meta Cloud API — ישירות מ-Meta

**סוג:** רשמי

### תמחור (ישראל, Utility messages)
- $0.0053 להודעה
- 200 הודעות/חודש = **~$1.06/חודש**
- ללא אגרה חודשית קבועה

### דרישות
- חשבון Meta Business Manager מאומת
- אימות עסקי (מסמכים: רישיון עסק, כתובת, שם חוקי) — לוקח שבוע-שבועיים
- מספר טלפון ייעודי שאינו רשום ב-WhatsApp
- כתובת HTTPS webhook פומבית
- אישור Meta לכל תבנית הודעה (template approval)

### יתרונות
- הכי זול בנפח נמוך
- ישיר, ללא ספק ביניים
- יציב וממוסד
- SDK רשמי ל-Node.js

### חסרונות
- הגדרה ראשונית מורכבת
- אימות עסקי לוקח שבוע-שבועיים
- כל תבנית הודעה צריכה אישור נפרד
- המספר מאבד גישה ל-WhatsApp Personal

### קלות אינטגרציה
בינוני — מצריך עבודת DevOps ראשונית, לאחר מכן פשוט

---

## 2. Twilio

**סוג:** BSP רשמי (Business Solution Provider)

### תמחור
- אגרת Twilio: $0.005 להודעה
- בנוסף: אגרות Meta ($0.0053 לישראל Utility)
- **סה"כ:** ~$0.0103 להודעה
- 200 הודעות/חודש = **~$2.06/חודש**
- ללא אגרה חודשית קבועה

### יתרונות
- תשתית אמינה ומבוססת
- תיעוד מעולה ו-SDK לכל שפה
- לוח ניהול נוח
- ניסיון חינם (trial credits) לפיתוח
- הגדרה מהירה יחסית (2–3 ימים)

### חסרונות
- יקר יותר מ-Meta ישיר
- עדיין מצריך אימות עסקי Meta

### קלות אינטגרציה
גבוהה — אחד מה-API הנוחים בתעשייה

## 5. GREEN-API

**סוג:** לא רשמי

### תמחור
- Business Plan: **$12/חודש** (flat, ללא אגרות Meta נוספות)
- Developer Plan: חינם (מוגבל ל-3 צ'אטים)

### יתרונות
- ללא אימות עסקי Meta
- אינטגרציה מהירה מאוד (שעות)
- מחיר קבוע וידוע

### חסרונות
- **לא רשמי** — עלול לגרום להשעיית המספר
- תלות בשירות שלישי בלתי מאומת
- עלול להפסיק לעבוד בכל עדכון של WhatsApp
- הודעות עוברות דרך שרתים חיצוניים (פרטיות)

### מסקנה
אפשרי לזמן קצר / פיתוח, לא מומלץ לטווח ארוך.

## 6. whatsapp-web.js / Baileys (קוד פתוח)

**סוג:** לא רשמי לחלוטין

### תמחור
- חינם — רק עלות שרת (~$5–10/חודש VPS)

### סיכונים קריטיים
1. **השעיית חשבון** — WhatsApp מזהה אוטומציה וחוסמת מספרים
2. **אירוע אבטחה (דצמבר 2025):** חבילה מזויפת בשם `lotusbail` הורדה 56,000 פעמים וגנבה הודעות, אנשי קשר ו-tokens
3. **שבירת שינויים** — כל עדכון WhatsApp Web עלול לשבור את הספרייה
4. **הפרת תנאי שירות** — שימוש מסחרי מפר את תנאי WhatsApp

### מסקנה
**לא מתאים לפרודקשן בשום אופן.**

## המלצה לפרויקט

### מומלץ ביותר: Meta Cloud API ישירות
- עלות: כמעט חינם (~$1/חודש)
- רשמי ויציב
- אינטגרציה ל-Next.js: 2–4 שעות עבודה לאחר אימות
- **חסרון:** אימות עסקי לוקח שבוע-שבועיים

**צעדים נדרשים:**
1. פתיחת Meta Business Account ואימות עסקי
2. רישום מספר טלפון ייעודי ב-WhatsApp Business Platform
3. יצירת תבניות הודעה ואישורן ב-Meta
4. הגדרת webhook באפליקציה

### אם רוצים להתחיל מהר: Twilio
- עלות: ~$2/חודש
- הגדרה: 2–3 ימים
- רשמי ואמין
- עדיין מצריך אימות Meta, אבל תהליך ה-onboarding מהיר יותר
