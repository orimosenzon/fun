# סיכום סשן - 2026-03-24 (סשן קצר)

## מה נעשה בסשן הזה

- בדיקת לוח השיעורים של ענבל (שני, חמישי, שישי)
- אין שיעורים ביום רביעי

## איפה עצרנו

אותו מצב כמו בסשן הקודם — בעיה פתוחה עם WhatsApp Business API.

## צעדים הבאים (ממשיכים מסשן קודם)

1. **להחליט** — מספר של ענבל או מספר וירטואלי נפרד
2. **בהתאם להחלטה** — לסיים הוספת המספר ב-Meta ולייצר Access Token
3. **לכתוב קוד** — חיבור WhatsApp API, עדכון `notifyNextStandby`
4. **Template Message** — הודעת standby ל-WhatsApp
