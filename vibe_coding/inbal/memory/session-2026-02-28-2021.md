## מצב הפרויקט road-to-recovery

### MVP הושלם ✓
Build עובר בהצלחה. 65 קבצים, 21 routes.

### Stack
- Next.js 14 (App Router) + Supabase + Tailwind CSS
- Google Maps Distance Matrix API (server-side)
- Supabase Realtime לעדכונים חיים

### מה נבנה

#### תשתית
- `supabase/schema.sql` — סכמת DB מלאה (5 טבלאות + enums + triggers + RLS + seed 8 בתי חולים)
- `middleware.ts` — auth guard + role-based routing
- `lib/types/index.ts` — TypeScript interfaces + state machine constants
- `lib/supabase/client.ts` + `server.ts` — Supabase clients
- `lib/i18n/` — he.json + ar.json + hook (מתג שפות)
- `lib/utils/` — rideStatus, reimbursement, formatters
- `lib/hooks/` — useCurrentUser, useNotifications (Realtime)
- `lib/maps.ts` — Google Maps wrapper (server-only)
- `.env.local` — template (ריק, ממתין לפרטי Supabase)
