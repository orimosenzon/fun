# סיכום סשן - 2026-03-29 (ערב)

## מה נעשה בסשן הזה

### WhatsApp — חיבור מלא לפרויקט
- כתבנו `lib/whatsapp.ts` — פונקציית `sendStandbyNotification(phone, name)` שולחת תבנית WhatsApp
- עדכנו `lib/standby.ts` להשתמש ב-WhatsApp במקום Twilio SMS
- שדרגנו את תבנית `standby_notification` ב-WhatsApp Manager לכלול `{{1}}` (שם התלמידה) — מאושרת ופעילה
- הכל בפרודקשן ועובד end-to-end

### סקריפט חידוש Token
- נוצר `scripts/renew-whatsapp-token.sh` — סקריפט לחידוש ידני של ה-token
- מעדכן `.env.local` ושולח הודעת בדיקה לאורי לאימות

## בעיה פתוחה — WHATSAPP_ACCESS_TOKEN ב-Vercel
- ה-token הנוכחי עודכן ב-`.env.local` אבל **לא עודכן ב-Vercel** (Environment Variables)
- **צריך לעשות בתחילת הסשן הבא:**
  1. כנס ל-vercel.com → inbal → Settings → Environment Variables
  2. עדכן `WHATSAPP_ACCESS_TOKEN` ל-token הנוכחי מ-`.env.local`
  3. Redeploy

## ניסיון כושל — System User Token
- ניסינו ליצור System User Token קבוע דרך Meta Business Manager
- נתקענו: הממשק של Meta לא איפשר לקשר את ה-WABA ל-System User
- הפתרון הזמני: חידוש ידני כל ~2 חודשים דרך הסקריפט

## צעדים הבאים
1. **עדכן token ב-Vercel** (דחוף — הפרודקשן לא עובד עד אז)
2. **חבר לוגיקת standby** — לוודא שהפונקציה מופעלת כשתלמידה עולה מרשימת המתנה
3. **Webhook לתגובות אוטומטיות** — אם מישהו עונה על ההודעה, לשלוח בחזרה "זוהי מערכת אוטומטית"
