# סשן 2026-07-19 — הקמת פרויקט כרמית

## מה זה כרמית
תיקייה עם חומרי גלם: `re.zip` מכיל 11 תמונות של חידות מילים (עברית/אנגלית) בכתב יד/ילד,
כל תמונה בפורמט שם קובץ `שאלה_תשובה_רמז`. יש גם `Photos-1-001.zip` ו-`extracted/` —
תמונות אישיות לא קשורות לחידות (ירקות, תמרים, עוגת יום הולדת עם נרות "37") שהושארו כמו שהן.

## מה נבנה
- **build_riddles.py** — סקריפט חד-פעמי/חוזר: מפרק את `re.zip` לפי המבנה `שאלה_תשובה_רמז`,
  מייצר `app/riddles.js` (מערך JS, לא JSON, כדי לעבוד גם ב-file:// בלי fetch/CORS) + מעתיק
  תמונות ל-`app/images/riddle-XX.jpg`. להריץ שוב אם מוסיפים עוד חידות ל-re.zip.
- **app/** — אפליקציית חידות סטטית (HTML/CSS/JS טהור, בלי שרת, בלי build step בזמן ריצה):
  מסך פתיחה → סבב חידות (סדר מוגרל בכל משחק) עם תמונה+שאלה+שדה תשובה+כפתור רמז
  (מושבת אוטומטית אם אין רמז) → משוב מחמיא/מנחם → דוח סופי (טבלה מלאה + ציון) + "שחק שוב".
  בדיקת תשובה סלחנית: מקבלת גם התאמה חלקית (מילה בודדת מתוך תשובה מרובת-מילים).

## באג שנמצא ותוקן
CSS הגדיר `.screen.hidden`, `.feedback.hidden`, `.hint-box.hidden` בנפרד אבל לא כלל גנרי
`.hidden` — כפתור "לחידה הבאה" (class `primary-btn hidden`) נשאר גלוי מההתחלה. תוקן עם
כלל גנרי `.hidden { display: none !important; }` בראש הקובץ.
