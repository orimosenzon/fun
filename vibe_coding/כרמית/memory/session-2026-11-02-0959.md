- **דף ניהול חדש** (`admin.html`, `admin.js`):
  - גלריית שעשועונים: שער ומאחוריו 3 חידות מוטות כמו דפים, שנפתחות למניפה במעבר עכבר, וחלון תצוגה מקדימה עם כל החידות והתשובות. בלי שער מוצג `logo.jpg`.
  - טאב "מאגר החידות" עם חיפוש ותגיות שמראות באילו שעשועונים כל חידה נמצאת.

  - טופס החידה נפתח בחלון, ואפשר לגרור אליו תמונה. ניתוב: `#pool`, `#quiz/<id>`.
- **המשחק:** `index.html?q=<id>` משחק בשעשועון לפי הסדר שנקבע. בלי `?q=` מוצגת גלריית שעשועונים.
