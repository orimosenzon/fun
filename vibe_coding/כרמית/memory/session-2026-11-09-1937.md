# סשן 2026-11-09 (ערב)

## מה נעשה
- **כותרת לכל חידון:** שדה `heading` בחידון: `{ text, image }`. השורה הראשונה של הטקסט מודגשת (כמו "עברית × English"), והשאר הוא ההסבר. התמונה לא חובה. בדף המשחק (`?p=`/`?q=`) הכותרת מחליפה את שורת "עברית × English" לאורך כל החידון. חידון בלי כותרת, ודף הפתיחה, נשארים עם ההסבר הרגיל. כשיש כותרת, שורת הפתיחה היא "N חידות. מוכנים?" בלי "עברית ואנגלית".
- **בניהול, במסך החידון:** תיבת טקסט (שמירה אוטומטית אחרי הפסקה), כפתור תמונה (עד 600px ו-120K, נשמרת בתוך מסמך החידון), "לקחת כותרת מחידון אחר…" (כל כותרת שונה פעם אחת, עם שמות החידונים שבהם היא מופיעה; מעתיק טקסט ותמונה), "הסרת התמונה", "חזרה להסבר הרגיל", ותצוגה מקדימה שמתעדכנת תוך כדי הקלדה.
- **מכתבים נלווים לשליחה שיווקית:** קולקציה חדשה `letters`: `{ quizId, name, text, image, linkText, linkUrl, by, created }`. נפרדת מהחידון כדי שתמונות המכתבים לא ימלאו את מסמך החידון (מגבלת 1MiB). הקישור הוא `index.html?q=<quiz>&m=<letter>`: חידון בודד (solo), המכתב מעליו (טקסט, תמונה, קישור), ובסוף החידון הכפתור שוב. הכתובות מסוננות ב-`safeUrl` (רק http/https/mailto/tel, ובלי פרוטוקול נוסף https://).
- **בניהול:** פאנל "שליחה כאמצעי שיווק" במסך החידון (מכתב חדש, עריכה, מחיקה, העתקת קישור, תצוגה), ולשונית חדשה "שליחה לשיווק" (`#letters`) עם כל המכתבים מכל החידונים.
- **תיבת "טקסט נלווה" מהבוקר הוסרה.** קישורי `?n=` ישנים עדיין מציגים את הפתק.
- **חוקי Firestore:** נוספה `letters` (קריאה לכולם, כתיבה לאורי וכרמית) ופורסמה.
- **בדיקות:** `tools/test_heading_letters.py` חדש. `test_entry_solo.py` עודכן. `fake_firebase.py` מקבל `window.__LETTERS`. כל הבדיקות עוברות.
- קומיש ופריסה ל-Pages, נבדק שחי.

## מצב נוכחי
- הכל באוויר. נבדק רק מול Firebase מזויף, לא עם חשבון Google אמיתי.
- אף חידון עוד אין לו כותרת, ואין מכתבים.
- אורי ישאל את כרמית אם זה מתאים לה.

## צעדים הבאים
1. בדיקה עם חשבון אמיתי: לכתוב כותרת לחידון, ליצור מכתב, ולפתוח את הקישור בחלון גלישה בסתר.
2. התגובה של כרמית לכותרות ולמכתבים.
3. אפשרויות שהוצעו ולא נבנו:
   - ספירת פתיחות לכל מכתב (דורש לאפשר לדף הציבורי כתיבה מוגבלת).
   - תצוגה מקדימה בוואטסאפ ובפייסבוק (og:image) לכל מכתב. דף סטטי לא יכול, צריך משהו בצד השרת.
4. נשאר מקודם:
   - לסדר את המסלול ואת הרמות.
   - קישור `?p=` לחידון נעול.
   - "______ של סקרנות".
