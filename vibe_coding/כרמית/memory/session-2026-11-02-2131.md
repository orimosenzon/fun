# סשן 2026-11-02

## מה נעשה
- נוסף כפתור ברור לחזרה למצב הראשוני (כל השעשועונים, כשחקן):
  - בדף שעשועון (`?q=`): כפתור "⌂ כל השעשועונים" בראש הדף, בכל המסכים (פתיחה, משחק, תוצאות). מוסתר בגלריה עצמה.
  - באמצע משחק (אחרי שנענתה חידה) יש confirm לפני יציאה, כדי לא לאבד סיבוב בטעות.
  - במסך התוצאות: "לכל השעשועונים" ליד "סיבוב נוסף".
  - בניהול: "⌂ למשחק, כל השעשועונים" בכותרת, ליד שם המשתמש (קודם היה קישור רק לפני הכניסה).
  - הלוגו בראש דף המשחק מקשר ל-index.html.
- CSS: מחלקה `.home-btn` (גלולה ציאן), `.header-end`, `.link-as-btn`.
- נבדק ב-Playwright עם Firebase מזויף (המוק מ-`tools/test_admin_transfer.py`): כל המעברים עובדים, בלי שגיאות. 22 בדיקות הניהול עוברות.

## מצב נוכחי
- האפליקציה באוויר ב-GitHub Pages, החידות ב-Firestore.
- השמירות בניהול עדיין נבדקו רק מול Firebase מזויף, לא עם כניסת Google אמיתית.

## צעדים הבאים
1. לשמוע מכרמית אם השמירות, ההעתקה/העברה ובחירת הסדר עובדות לה עם החשבון שלה.
2. לברר את המילה החסרה ב"______ של סקרנות" ולאשר את התשובות שניחשתי.
3. אם ירצו: og:image לכל שעשועון.
4. אפשר להפוך את בדיקת כפתור החזרה לבדיקה קבועה ב-`tools/` (כרגע רצה רק כסקריפט זמני).
