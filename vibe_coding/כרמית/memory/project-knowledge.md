- **האפליקציה:** `app/` סטטית (HTML/CSS/JS עם ES modules, בלי build), באוויר ב-GitHub Pages: orimosenzon.github.io/fun/vibe_coding/%D7%9B%D7%A8%D7%9E%D7%99%D7%AA/app/index.html

- "השעשועון הראשון" (YIAgWziD4umRqJWLQmGd) נוצר עם כל 17 החידות שהיו במאגר.
- **ניהול:** גלריית שעשועונים (שער עם חידות מוטות מאחוריו, ותצוגה מקדימה במעבר עכבר), טאב "מאגר החידות", ומסך שעשועון (שם שנשמר אוטומטית, שער, העתקת קישור, גרירה לשינוי הסדר ולהוספה מהמאגר). טופס החידה נפתח בחלון. ניתוב: `#pool`, `#quiz/<id>`.

## מ-09/11/2026: מסלול, חידון בודד, טקסט נלווה (פירוט ב-session-2026-11-09-0922.md)
- **שדות חדשים בחידון:** `level` (easy/medium/hard; כרגע רק תווית), `path` (מיקום במסלול, `null` = לא מוצג), `notes` (מפה {id קצר: טקסט נלווה}). כל השדות נכנסו בלי שינוי חוקים, כי החוקים לא מגבילים שדות נוספים.
- **כתובות:**
  - `index.html` הוא המסלול. רק הבא בתור פתוח, וההתקדמות נשמרת ב-sessionStorage (`carmit-quizzes-done`).
  - `?p=<id>` הוא חידון בתוך המסלול.
  - `?q=<id>[&n=<noteId>]` הוא חידון שנשלח לבד (גוף הדף מקבל class `solo`), עם טקסט נלווה אם יש.
- **`fb.js`:** `playerPath(quizzes)` מחזיר את המסלול. כשהמסלול ריק הוא מחזיר את כל החידונים, הקלים קודם. `watchAdmin(cb)` בודק כניסה של אורי או כרמית בדף המשחק.
- **ניהול:** לשונית `#path` ("מה השחקן רואה"), בורר רמה, ותיבת טקסט נלווה ליד כפתור השליחה. כפתור הכניסה לניהול נמצא רק בדף הפתיחה, ואחרי כניסה "⚙ לממשק הניהול" מופיע בכל מסך.
- **ראש הדף** בנוי לפי הסקיצה של כרמית: Wordplay & Wonder, ואחריו "עברית × English" (קבוע בכל מסך), שורת ההסבר והחידונים. "מאחורי החידות" נמצא מתחת לחידונים.
- **בדיקות:** `tools/fake_firebase.py` משותף לכל הבדיקות (`window.__PATH` / `__PATCH` / `__NO_USER`). `test_path.py`, `test_navigation.py`, `test_entry_solo.py`. מריצים מול שרת שמוגש מתיקיית הפרויקט: `python3 tools/<t>.py http://localhost:8766/app/`.
