# session 2026-06-09-0603 — הקמת factotum

## מטרת הסשן
להקים פרויקט ייעודי שבו Claude מבצע עבודות תשתית (שרתים, Azure, קונסולה) בשם
המשתמש, עם תיעוד מלא. נולד משיחה על "computer use".

## מה נעשה
- אובחן שהטרחה של המשתמש (פינג-פונג צילומי מסך) היא בעיית **גישה**, לא צורך
  ב-computer use. רוב המשימות (שרתים, Azure) ניתנות ל-CLI.
- נבדק: **אין אף CLI ענן מותקן** — אין `az`/`gcloud`/`aws`/`terraform`/`docker`.
  זו הסיבה שעבודת Azure עוברת דרך הפורטל הגרפי.
- הוגדרה ארכיטקטורת 3 שכבות (CLI → Playwright → computer use). ראֵה project-knowledge.
- הוקם שלד: factotum/{memory,logs,screenshots} + project-knowledge.md.

## הותקן (בוצע בסשן)
- **Playwright + chromium** ב-`factotum/venv` (בלי sudo). smoke-test עבר →
  `screenshots/smoke_example.png`. אין ספריות מערכת חסרות.
- **Azure CLI `az` 2.87.0** ב-`factotum/venv` דרך pip (בלי sudo). בינארי:
  `factotum/venv/bin/az`. לוג: `logs/az_install.log`.
- שניהם ב-venv אחד: `source factotum/venv/bin/activate`.

## צעדים הבאים
1. `az login` (device-code) — המשתמש מאשר התחברות; Claude לא נוגע בסיסמה.
2. הגדרת גישת SSH לשרתים — **צריך מהמשתמש:** IP/hostname/ספק (או `~/.ssh/config` קיים).
3. רישום factotum ב-index.html (דף הפרויקטים) — לסיום.

## בוצע בהמשך הסשן (שכבה 1+2 בפעולה אמיתית)
- **Azure CLI מחובר** (`az login` device-code). פרטי subscription/tenant/RG
  שמורים מקומית ב-`access-inventory.md` (gitignored — לא בריפו ציבורי).
- **סקר משאבים:** 2 cognitive accounts (haskala-foundry-resource eastus2 + haskala-openai-orim eastus).
- **מודלי תמונה — אבחנה:** כל החיים (gpt-image-*) עם quota=0; DALL-E עם quota אבל deprecated.
  ניסיון פריסת gpt-image-1 → InsufficientQuota (הוכחה).
- **`az support` ticket נחסם:** InvalidSupportPlan (Free tier לא יכול ליצור טיקטים ב-API).
- **בקשת quota הוגשה דרך הדפדפן (Playwright, שכבה 2):** שרשור מלא —
  הפעלת chromium headed (setsid, מנותק כדי לשרוד), המשתמש התחבר ל-Foundry,
  ניווט Quota → כיבוי "New Foundry" → Show all quota → GlobalStandard →
  GPT 2 Image Generation → East US 2 → Request quota → טופס Customer Voice.
  מולא: פרטי חברת Haskala (כתובת+subscription שמורים ב-access-inventory המקומי),
  justification, Azure OpenAI / Global Standard / gpt-image-2 / East US 2 / 10 RPM.
  **הוגש בהצלחה** ("Thanks! You've completed the request!"). צילומים: screenshots/quota_*.png.
- **לקח טכני:** שדות Microsoft Forms הם input ללא תכונת type (querySelector('input[type=text]')
  נכשל) + placeholder-div עד קליק. פתרון: סינון לפי `.type` property + תיוג data-attr + Playwright fill.
