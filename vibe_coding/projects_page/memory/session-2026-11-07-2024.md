## מה נעשה
- כותרת הדף שונתה מ-"✦ Vibe Coding" ל-"אורי מוסנזון - פרוייקטים" (`site.title` ב-`projects.json`).

- `render_header` ב-`build.py` מציג את `subtitle` ואת `meta` רק אם יש בהם טקסט, כדי שלא יישארו תגיות ריקות.

- "Vibe Coding" עדיין מופיע בכותרת הטאב ובשורה בתחתית הדף (`template.html`), ושורת המספרים נשארה מתחת לכותרת. נשאל ועדיין אין החלטה.

1. להחליט אם להסיר את "Vibe Coding" מכותרת הטאב ומהתחתית, ואם להשאיר את שורת המספרים.
2. לסנן את ה-IP של אורי ב-GA.
3. לסגור את פערי `build.py --check`: `jetbikes/jetbike_film`, `one_prompt/emek_hamaayanot_springs`, `one_prompt/personality_screening`.
