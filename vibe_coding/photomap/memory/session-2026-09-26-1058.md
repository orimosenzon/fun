# סשן 2026-09-25/26

## מה נעשה
- פרויקט חדש: מפת עולם של התמונות והסרטונים מגוגל פוטוס (Leaflet + markercluster, בלי build).
- `fetch_album.py`: משיכה מקישור שיתוף של אלבום. זה הערוץ היחיד מגוגל פוטוס שנבדק ושומר מיקום.
  - ה-Library API נחסם ב-3/2025, וה-Picker API מוחק מיקום.
- `import_takeout.py` + `serve.py`: ייבוא Takeout של 142GB **בלי לחלץ**. השרת מגיש ישירות מה-zip, עם מטמון לתמונות ממוזערות ולסרטונים.
- ציר זמן בתחתית: היסטוגרמה אדפטיבית עם בחירת טווח. הזמן זורם מימין לשמאל.
- `trips.py`: זיהוי בית, טיולים ויציאות יום, ושמות מ-Nominatim (עם נקודות עניין בטבע).
- ניקוי **שיבושי GPS** של המלחמה: נקודות בנמלי התעופה של ביירות ועמאן, וקפיצות בלתי אפשריות.
- גלריה: לחיצה על קבוצה פותחת את כל הפריטים שבה. צופה על canvas עם זום בגלגלת עד רמת הפיקסל, גרירה ולחיצה כפולה.
- כניסה בסיסמה (`auth.py`): גיבוב בלבד ב-data/, עוגייה חתומה, הגבלת ניסיונות, ורשימה סגורה של קבצים נגישים.
- שיתוף החוצה דרך מנהרת Cloudflare (`cloudflared`), אחרי שנמדד ש-localhost.run מגביל ל-28KB/s. gzip לקבצי טקסט.
- תיקונים: פאנל מקופל בטלפון, כפתור "הבא" שכיסה את האיקס בגלריה, חצים שהתהפכו בגלל RTL.
