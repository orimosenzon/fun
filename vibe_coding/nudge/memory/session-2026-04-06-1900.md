# Nudge — סשן 2026-04-06

## מה נבנה
MVP ראשון של אפליקציית Nudge — ניהול כספים קולי לדסקטופ.

## קבצים שנוצרו
- `app.py` — Flask server, SQLite, Claude Haiku 4.5, endpoints: /api/chat, /api/tts, /api/expenses, /api/summary
- `templates/index.html` — ממשק שיחה + דשבורד (קטגוריות, קבועות/מזדמנות, הוצאות אחרונות)
- `requirements.txt`, `.env.example`

## החלטות ארכיטקטורה
- **פלטפורמה:** Python + Flask (דסקטופ), לא Flutter
- **מודל:** Claude Haiku 4.5 (`claude-haiku-4-5-20251001`) — הכי זול
- **TTS:** gTTS עם lang=`iw` (קוד עברית ב-gTTS). Web Speech Synthesis לא עובד עברית בלינוקס
- **STT:** Web Speech API עם `continuous=true` + טיימר שתיקה של 1500ms
- **DB:** SQLite עם טבלאות `expenses` ו-`user_settings`
- **Claude:** מחזיר JSON מובנה (action + data + response). Backend מפרסר ומבצע פעולה
