# השכלה — ידע ברמת החברה (Company Knowledge)

> זהו המסמך שנקרא ראשון בפתיחת סשן השכלה. הוא מתאר את **החברה** ואת **תיק המוצרים**.
> ידע ספציפי לכל מוצר נמצא תחת `products/<מוצר>/memory/project-knowledge.md`.

## מהות החברה
**השכלה** היא חברת סטרטאפ שמייצרת פתרונות AI לבתי ספר. הכלי הראשון — בודק תרגילים
אוטומטי — הוא רק אחד מתוך פורטפוליו מתוכנן. הקשר בין המוצרים הוא **לא בקוד** (כל מוצר
עצמאי טכנית) אלא ברמת החברה: אותו צוות, אותם לקוחות, אותה תשתית, אותו מותג וערוץ מכירה.

## הצוות
- **אורי מוסנזון** — פיתוח. פרדס חנה.
- **אבישי שלוש** — תל אביב. מלמד בבית הספר **שמיר** (תל אביב) → אתר הפיילוט הטבעי.
- **ירון קדם** — שוודיה (לאישור).

## לקוחות
- **בית ספר שמיר, תל אביב** — לקוח/אתר פיילוט ראשון, דרך אבישי. חשבון מורה הושג ב-2026-06.
  - לבדוק: האם החשבון הוא Google Workspace for Education (משפיע על הרשאות Classroom API).

## היסטוריה
- **גרסה ראשונה (≈2024):** התחלנו את הרעיון. עבדנו כחודשיים ואז זנחנו — זמינות אישית של
  אורי + המודלים של אז היו חלשים ב-vision של כתב יד עברי, ולא היה כלי קוד אגנטי.
- **2026: חזרה.** הסיבות: מודלים חזקים בהרבה (Claude Opus Vision מטפל בכתב יד עברי),
  Claude Code כשותף פיתוח, ו-Google Classroom שהבשיל כשער לשוק החינוך הישראלי.

## תשתית משותפת (חוצת-מוצרים)
- **AI:** Claude Vision/Opus (caching מופעל לחיסכון ~90% על system prompt).
- **אינטגרציה חינוכית:** Google Classroom API + Google Drive API (OAuth 2.0).
- **סטאק backend:** Flask (תואם לשאר פרויקטי המפתח).
- **פריסה:** HF Spaces / Render. דפוס "קמס" = git commit/push + deploy.sh.
