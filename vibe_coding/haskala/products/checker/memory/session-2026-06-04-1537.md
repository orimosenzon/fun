`Uncaught (in promise) ReferenceError: currentModel is not defined`

**סיבת השורש:** הקובץ `templates/index.html` מכיל **שני IIFE נפרדים**:
- חיצוני (995-1241) — כולל `const currentModel = () => modelSel.value;` (שורה 1146)
- פנימי בתוך `{% if pages %}` (1313-2219) — שם רצים handlers של `save-decode-docx` / `save-eval-docx`

**תיקון:** הוספת `function currentModel()` מקומי לאחר `baseName()` בתוך ה-IIFE הפנימי (שורות 1788-1791).

**Commit:** `32e2b1f` — haskala: fix ReferenceError — define currentModel inside results IIFE
