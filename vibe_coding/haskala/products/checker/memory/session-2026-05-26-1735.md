# סשן 2026-05-26 — צבעים לרובריקה + תמונת מקור ב-DOCX + לנצ'ר

## מה נעשה

### 1. צבעים לקריטריוני הרובריקה
**הבעיה:** המורה רוצה לזהות מהר איזה סוג טעות זה אילו תאים ברובריקה. צריך עקביות
בין רובריקות (תחביר תמיד אדום, איות תמיד סגול) למרות שכל רובריקה מגדירה קריטריונים
שונים.

**הפתרון:** מיפוי קבוע של מילות מפתח (עברית+אנגלית) → צבע ב-[app.py:938-980](haskala/app.py#L938-L980).
- תחביר/grammar/syntax → אדום `#d9534f`
- ניסוח/coherence/task achievement → כחול `#337ab7`
- אוצר מילים/vocabulary → אמבר `#e0a800`
- איות/mechanics/spelling/punctuation → סגול `#8e44ad`
- מבנה/structure → ירוק `#28a745`
- תוכן/content/ideas → טורקיז `#16a085`
- שטף/fluency → כתום `#e67e22`

Fallback: לקריטריון שלא מתאים לאף מילת מפתח → צבע דטרמיניסטי מתוך פלטה של 8
לפי md5 hash של השם. כך שאותו שם תמיד יקבל אותו צבע.

הצבע מוצמד ב-3 מקומות: `evaluate_with_rubric` (כל יצירה חדשה), `parse_saved_json`
(תאימות אחורה לקבצים שמורים בלי צבע), ובתחילת `build_evaluation_docx` (חגורה +
שלייקס).

### 2. תצוגת הצבעים
- **UI:** תא הקריטריון מקבל `border-inline-start: 6px` בצבע + ספוגית 12x12px ליד
  השם. תקין גם RTL וגם LTR.
- **DOCX:** רקע התא צבוע בתינט בהיר (`_tint_hex` עם mix=0.18, כ-82% לבן) כך שטקסט
  שחור נשאר קריא. python-docx לא חושף API לרקע תא — נדרש לרדת ל-OOXML עם
  `OxmlElement('w:shd')`.

### 3. תמונת תרגיל מקורי + פענוח שורה-שורה ב-DOCX
אחרי בלוק "סיכום" — page break, כותרת "תרגיל מקורי ופענוח", ולכל עמוד:
1. תמונת המקור (`original_b64`) ברוחב 5.5".
2. טבלת 2-עמודות: תמונת השורה (`image_b64`, רוחב 4") ↔ הטקסט המתומלל.

ה-frontend (collectPages) שולח עכשיו את ה-pages עם הבקשה ל-`/evaluation/docx`.

### 4. Launcher `run.sh`
**הבעיה שצצה:** המשתמש הריץ `python3 app.py` עם פייתון מערכת במקום
`venv/bin/python`. ה-import של `docx` הוא lazy (בתוך הפונקציה), אז השרת עלה
תקין — קרס רק כשהמשתמש לחץ "שמור Word" וקיבל "No module named 'docx'".

**הפתרון:** [run.sh](haskala/run.sh) — מוודא ש-`venv/bin/python` קיים, מאמת שכל
ה-requirements importable עם מיפוי שמות נכון (`python-docx`→`docx`, `pillow`→`PIL`,
וכו'), ומריץ עם `exec`. אם משהו חסר — שגיאה ברורה והוראת התקנה לפני שהשרת עולה.

מעכשיו `./run.sh` במקום `python3 app.py`.

## דיון אסטרטגי — אינטגרציה עם Google Classroom

המשתמש שאל איך מורה ילחץ על כפתור ויבדוק את כל ההגשות של מטלה במכה אחת.
המלצתי על staging דו-שלבי:

**שלב 1 (מומלץ להתחיל ממנו):** Google Drive Picker + bulk processing.
- המורה בוחר תיקייה ב-Drive דרך ה-Picker.
- Scope: `drive.file` — non-sensitive, אימות OAuth מינימלי.
- אנחנו רואים רק את הקבצים שהמורה בחר במפורש.
- מעבדים את כולם, מציגים דשבורד, תור סקירה לנמוכי-confidence.

**שלב 2 (אחרי שה-UX יציב):** Classroom API.
- `classroom.coursework.students` — scope sensitive, אימות 2-6 שבועות + privacy policy.
- מאפשר גילוי אוטומטי של תיקיית המטלה והחזרת ציון+תגובה פרטית ל-Classroom.

**שיקולי תכנון לשלב 1 שצריך לדאוג להם מההתחלה:**
1. קונקרנסי — 30 תמונות במקביל מול rate limits של Anthropic. צריך throttle.
2. תור סקירה — confidence score מהמודל + threshold + UI מורה.
3. פרטיות — privacy policy ברורה, מחיקה תקופתית של תמונות של קטינים.

המשתמש לא נתן go עדיין על שלב 1 — שיחת התייעצות בלבד.
