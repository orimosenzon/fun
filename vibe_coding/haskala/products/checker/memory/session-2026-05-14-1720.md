## מה הוכרע ונבנה בסשן
**אורי בחר להתחיל מ-POC טכני של OCR, ולא מהכרעות תכנון** — אפליקציית web פשוטה שמעלים אליה PDF של תרגיל בכתב יד ומקבלים תמלול ורבטי.

נבנתה גרסה ראשונה עובדת:
- `app.py` — Flask app, endpoint יחיד שמקבל PDF
- `templates/index.html` — דף RTL עם טופס העלאה ותוצאה
- `requirements.txt`, `.gitignore`, `.env.example`, `.env` (מפתח הועתק מ-nudge)
- סטאק: Flask + Anthropic SDK + pymupdf + Pillow + Claude Opus 4.7

## איטרציות המוצר בתוך הסשן
1. **גרסה 1 (תמלול בודד)**: PDF נשלח ישירות ל-Claude כ-`document` block, תמלול מוחזר כטקסט יחיד ומוצג ב-`<pre>`.
2. **בקשת שיפור מאורי**: רצה להעריך איכות OCR ויזואלית → צריך alignment שורה-מקור ↔ שורה-תמלול.
3. **גרסה 2 (alignment)**: ממיר PDF → PNG (200 DPI), מבקש מ-Claude JSON מבני עם `text + y_top + y_bottom` (`output_config.format` עם json_schema), חותך כל שורה כתמונה ומציג ליד הטקסט.
4. **תיקון חיתוך**: Claude לפעמים מחזיר חיתוך של הקו המודפס במחברת במקום של כתב היד. תיקנו ב: prompt מפורט יותר על ascenders/descenders, padding 8px → 30px, ו-`normalize_line_heights` שמרחיב outlier-ים דקים מ-60% מחציון העמוד.

אורי אישר ש"זה מספיק טוב בינתיים".

## החלטות טכניות
- **מודל**: Claude Opus 4.7 (איכות OCR מקסימלית, ~$0.02-$0.03 לעמוד).
- **רזולוציה**: 200 DPI (A4 → ~1700×2340 פיקסלים, נכנס בגבול 2576px של Opus 4.7).
- **Prompt caching**: מופעל על system prompt (חיסכון לקריאות עוקבות באותו חלון 5 דקות).
- **PDF → PNG**: pymupdf (fitz), בלי תלות חיצונית כמו poppler.
