# סשן 2026-05-30 — רובריקת משרד החינוך (Module C/D) כברירת מחדל

## אופי הסשן
סשן קצר וממוקד: הוספת רובריקת כתיבה רשמית של משרד החינוך (מודולים C ו-D)
לרשימת הרובריקות, והפיכתה לברירת המחדל בדרופ-דאון.

## מה נוסף

### 1. קובץ הרובריקה החדש
`rubrics/ministry-writing-module-c-d.json` — רובריקה רשמית של משרד החינוך
לכתיבה במודול C internal (016382) ובמודולים C+D external (016484):
- 4 קריטריונים: Content & Organization (10), Vocabulary (8), Language Use (8), Mechanics (4) — סה"כ 30 נקודות.
- 4 רמות לכל קריטריון (Correct / Partially / Minimally / Incorrect).
- כללי ניכוי לפי אורך — טבלאות נפרדות למודול C (70-90 מילים) ולמודול D (80-100 מילים).
- כללי "אפס לכל המטלה": <25 מילים, חוסר רלוונטיות מוחלט, חוסר הבנה מוחלט, העתקה מהאינטרנט.
- כללי העתקה מטקסט קריאה (entire vs substantial parts).
- ניכויים ספציפיים: list form, letter format שלא במכתב, "Hi, my name is..." לא רלוונטי, חזרות, סלנג/קיצורים.

הרובריקה כתובה באנגלית (כפי שהמקור הרשמי) — הוראות הפלט ל-evaluator
דורשות פידבק בעברית בכל מקרה (זה כבר ב-EVAL_SYSTEM_PROMPT).

### 2. מנגנון default rubric
היה: סדר עדיפויות = `prev` → `localStorage` → ראשון אלפבתית.
עכשיו: `prev` → `localStorage` → **`default_rubric_id` מהשרת** → ראשון אלפבתית.

איך:
- `app.py:DEFAULT_RUBRIC_ID = "ministry-writing-module-c-d"` (קבוע מודולי).
- `_inject_rubrics()` חושף אותו לכל ה-templates דרך context processor.
- `render_result()` משדר אותו ב-`server_data` יחד עם הרובריקות.
- ה-JS ב-`renderRubricSelect()` משתמש בו כ-fallback אחרי localStorage.

החלטה: לא לדרוס localStorage קיים — משתמש שכבר בחר אקטיבית רובריקה לא
תיגנב הבחירה ממנו. רק users חדשים / clean state יראו את החדשה כברירת מחדל.

## בדיקה
- `/rubrics` החזיר את שתי הרובריקות (כולל החדשה) — אומת מקומית.

- בדיקה ידנית בדפדפן מקומית בוצעה ע"י המשתמש לפני האישור לקמש.
