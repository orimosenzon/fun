## מה נבנה (app.py + templates/index.html)
- **רובריקה אופציונלית:** textarea (accordion) בטופס. נשלחת ב-`_rubric_block()` ב-user turn — לא בפרומפט המוקש, כדי לשמור prompt caching. מותנה הניקוד לפיה; ריק → נגזר מהניקוד המודפס בדף.
- **ניקוד מספרי:** `points_max` + `points_earned` נוספו ל-ANALYSIS_SCHEMA (+_JSON_CONTRACT ל-Groq/Azure, _GEMINI_SCHEMA נגזר אוטומטית). `compute_totals()` מסכם → **ציון כולל**.
- **flow אישור מורה (הליבה — הגנת ערעורים):**
  - בתוצאות: ניקוד = number inputs עריכים, feedback = contenteditable.
  - כל עריכה → עדכון `_pages` → recompute → autosave debounced ל-`POST /update/<job_id>` (ממזג רק שדות עריכים, משמר תמונה+LaTeX+steps).
  - כפתור "אשר בדיקה ✓": טיוטה→אושר. **עריכה אחרי אישור מבטלת אותו אוטומטית.**
  - flush לפני כל הורדה (save) כדי שהייצוא ישקף את המאושר.
- **ייצוא HTML+Word:** מציג ניקוד per-תרגיל, ציון כולל, ובאנר טיוטה/אושר.
