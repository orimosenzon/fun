## מה נעשה

### app.py — שוכתב מ-MVP סינכרוני ל-pipeline מלא
- **זרימת SSE עם progress bar אמיתי** (כמו checker): `/analyze/start` יוצר job
  ברקע (thread) → `/analyze/stream/<id>` משדר התקדמות (render → orient → analyze)
  → `/result-data/<id>` מחזיר JSON לרינדור בצד-לקוח.
- **3 שלבים פר עמוד:** render (pymupdf 200dpi) → detect_rotation (Haiku
  `claude-haiku-4-5-20251001`) → analyze_page (Opus `claude-opus-4-8`).
- **analyze_page עם json_schema מובנה** (`output_config`) במקום `_extract_json`
  הישן + prompt caching על ה-system prompt. סכמה: page_summary, has_diagram,
  diagram_description, problems[] עם student_steps[] (latex/ok/comment),
  verdict, score_suggestion, feedback, final_answer_latex, topic, id.
- **Basic Auth** (HASKALA_USER/PASS) + `MATH_CHECKER_DESKTOP` — אותו דפוס כמו checker.
- **humanize_error** — גרסה מצומצמת (Anthropic בלבד) להודעות שגיאה בעברית.
- **save/load JSON** — `/save/<id>` הורדה, `/load` העלאה.

### templates/index.html — עיצוב זהה ל-checker
- אותה פלטת צבעים (slate canvas + paper-cream cards + teal accent), Heebo,
  hero עם art, global-reset, toolbar עם save-menu, progress-box, error-banner,
  app-stamp תחתון. RTL מלא.
- **KaTeX** לרינדור LaTeX (טעינה async עם event `katex-ready`).
- כרטיסי בעיות (לא שורה-שורה): badge verdict צבעוני, צעדים עם border ok/bad,
  הערות שגיאה, ניקוד מוצע, feedback. Drag-and-drop בmempty state.
- צ'קבוקס "תיקון סיבוב אוטומטי".
