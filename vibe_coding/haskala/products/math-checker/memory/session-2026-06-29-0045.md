## תיקונים שבוצעו (deployed)
1. **`esc()` קרס על מספרים** ([index.html:873]) — `(s || "")` הניח מחרוזת; `points_earned=8.5`
   (float) → `(8.5||"").replace` קרס. תוקן ל-`String(s ?? "")`. זו הייתה השגיאה
   "replace is not a function" שהמשתמש ראה.
2. **`m()` הזריק LaTeX ל-innerHTML בלי escaping** ([index.html:876]) — `<x` (קטן-מ + אות)
   נפרש כתג HTML, בלע חלק מהמחרוזת ושבר את צמד `\(...\)` → KaTeX לא רינדר, הוצג גולמי.
   תוקן לעטיפה ב-`esc()`. הערה: `build_result_html` בצד השרת (app.py:805–810) **כבר** עשה
   זאת נכון — התיקון מיישר את ה-frontend לקו ה-backend.
- צד השרת היה תקין כל הזמן (הלוג הראה verdicts ו-result-data 200). הכשלים היו רק client-side.
- **לקח חוזר:** "התחל מחדש"/"בדיקה" מריצים JS בדף שכבר טעון — לא טוענים HTML מחדש. אחרי
  שינוי תבנית צריך **לסגור לשונית ולפתוח חדשה** (או `esc.toString()` ב-Console לאימות).

## POC Google Classroom (הונח, לא רץ)
- `pull.py` (חדש, בריפו) — אימות OAuth desktop → קורס "integration" → studentSubmissions →
  הורדת קבצים מצורפים מ-Drive. ארגז חול: **bdika.net** (אורי אדמין). נבחר **OAuth קודם**,
  אח"כ מעבר ל-service account+DWD ל-Cloud Run (קריאות ה-API זהות).
- **חוסם:** דורש `credentials.json` (OAuth client "Desktop app" מ-GCP console). אורי התקשה
  בלוגין Google בדפדפן Playwright (חסימת אוטומציה). הפרטים והצ'קליסט בהיסטוריית הסשן.
- google-api-python-client + google-auth-oauthlib הותקנו ב-venv.
