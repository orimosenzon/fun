## מה נעשה (products/math-checker/)

### 1. לוגים למעקב בזמן אמת (app.py)
- `[upload]` ב-`analyze_start`: filename, ext, size, model, auto_orient.
- `[job]`: מספר עמודים שעברו render ב-RENDER_DPI.
- timing על orient + analyze לכל עמוד (`(30.3s)` וכו') לזיהוי תקיעות.

### 2. ייצוא HTML + Word
- `build_result_html(pages, filename)` — HTML עצמאי אחד, RTL, KaTeX מ-CDN עם
  auto-render על `\(...\)`, סריקות מוטמעות base64, CSS משוכפל מה-UI (badges,
  step ok/bad, feedback). **זה "הפורמט הנח"** — נפתח בכל דפדפן, Ctrl+P→PDF נקי.
- `build_result_docx(pages, filename)` — Word עם python-docx. LaTeX כטקסט
  monospace LTR (python-docx לא מרנדר LaTeX — מודע ומוצהר). verdict צבעוני,
  ✓/✗ לכל צעד, הערות, ניקוד, משוב, סריקה מוטמעת לכל עמוד. RTL = alignment RIGHT + w:bidi.
- routes: `/save/html/<job_id>`, `/save/docx/<job_id>`. helper `_export_basename`.
- UI: תפריט "שמור ▾" עכשיו 3 אפשרויות (HTML / Word / JSON) + wiring `saveAs(fmt)`.
- `requirements.txt`: +python-docx>=1.1.0 (הותקן ב-venv, lxml+python-docx-1.2.0).
