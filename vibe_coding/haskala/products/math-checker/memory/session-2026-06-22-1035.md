## מה נעשה (products/math-checker/) — קומש 32d4bc2, נפרס Space 24b8366

### 1. תיקון יישור (הבאג המרכזי)
- **שורש:** ה-checkbox "תיקון סיבוב אוטומטי" היה דלוק כברירת מחדל, ו-Haiku החזיר 270° על עמוד
  גאומטריה **שכבר היה זקוף** (portrait) — וההיפוך הוא ששיכב אותו על הצד. אומת אמפירית:
  detect_rotation→270 על דף תקין, apply הופך ל-landscape שגוי.
- **תיקון:** auto-orient כבוי כברירת מחדל (`request.form.get("auto_orient","0")`). הסריקה מוצגת
  כפי שהיא. לסריקה הפוכה אמיתית — ↺/↻ + "בדוק מחדש" או סימון ה-checkbox.
- **באג שני שהסתתר מאחורי הראשון:** אחרי התיקון בשרת, הדפדפן המשיך לשרת HTML מ-cache
  (שלח `auto_orient=1` ישן). הוכח מהלוג: `model=opus` חדש אבל `rotation=270°` ישן.
  **תיקון:** `Cache-Control: no-store` על route ה-`/` (index).

### 2. בורר מודל ב-UI (כמו checker)
- dropdown במסך הפתיחה: Opus 4.8 (ברירת מחדל) / Sonnet 4.6 (~5× זול, מומלץ לשוטף) / Haiku 4.5.
- `MODELS`/`MODEL_IDS`/`resolve_model()` ב-app.py; מחובר ל-`analyze_start`→`_process_stream`→
  `analyze_page(img, model_id)` ול-`reanalyze` (משתמש ב-`job["model"]`).
- זיהוי הסיבוב נשאר תמיד Haiku (זול); רק הניתוח משתנה לפי הבחירה.
- שם המודל מופיע דינמית בפס ההתקדמות ("מנתח מתמטיקה (Claude Sonnet 4.6)").

### 3. פרוגרס באר "חי"
- בעיה: עם עמוד 1 הבר קופץ ל-50% ויושב ~30ש' בזמן Opus (LLM = קופסה שחורה).
- פתרון: `startCreep()` — זוחל אסימפטוטית לעבר היעד (לא מגיע) + מונה זמן `62% · 0:18`.
  עוצר ב-event הבא / done / error.

### 4. זום מסך-מלא (lightbox)
- קליק על הסריקה → overlay fullscreen. גלגלת = זום לעבר הסמן (transform-origin עוקב), עד 8×.
- יציאה: ESC / כפתור × / קליק על הרקע. פס רמז קבוע עליון: "גלגלת = זום · ESC ליציאה".
- תיקון z-index: ל-`<img>` יש `will-change:transform` (stacking context) שהסתיר את הפס הקבוע →
  פס+× קיבלו `z-index:10`, img `z-index:1`.

### 5. פאביקון בעיגול לבן
- הלוגו (ספר כהה, שקוף) נבלע בטאב כהה. עוטף כעת בעיגול רקע לבן (supersample 1024→256→64,
  לוגו ~70% מהקוטר). עודכנו favicon.png + favicon.ico (16/32/48/64).

### 6. תיקון deploy.sh (באג שהיה מפיל build)
- `DIRS=(templates static)` — קודם `static` **לא** סונכרן ל-Space, אבל ה-Dockerfile (מ-18.6)
  דורש `COPY static/ static/`. זו הייתה הפריסה הראשונה עם static → היה נכשל ב-build בלי התיקון.

## רקע — אינטגרציית Google Classroom (נקרא, טרם מומש)
נקרא מסמך handoff מפורט (פרויקט `classroom-writing-eval` תחת ארגון `shamir.school`).
החלטות שכבר נסגרו שם: open-loop (מסמך סקירה, לא ציון חוזר), חשבון קורא ייעודי co-teacher,
אפליקציה Internal (בלי אימות Google, scopes read-only), Pull-by-polling עם watermark על
updateTime, eval דרך Vertex AI (Claude Sonnet ברירת מחדל), Cloud Run+Scheduler+Pub/Sub+
Firestore+Storage. **צעד מיידי מומלץ שם:** pull.py לוקאלי שמוכיח משיכת קובץ מ-Classroom
(לפני כל עבודת ענן). שאלת compliance פתוחה: residency פיזית-בישראל (me-west1) מול in-tenant-EU.
