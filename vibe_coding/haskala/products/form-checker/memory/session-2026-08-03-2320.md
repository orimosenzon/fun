# form-checker — session 2026-08-03

**First end-to-end run against real Google succeeded.** Three works graded, three
Google Docs written into the teacher's own folder, summary email delivered.

## What changed

The product was rebuilt around **shared Drive folders** instead of file uploads,
after Avishai's form turned out to ask for a folder link. Teachers on regional
(מחוז) domains cannot be added to our Classroom, but they *can* grant Editor on a
Drive folder — that is the whole reason for the redesign.

- **`drive_folder.py`** (new) — resolve the pasted link, require Editor before
  anything is graded, list one level, write results into a `Bdika` subfolder as
  Google Docs.
- **`checker.py`** — grades one file at a time instead of one response.
- **`main.py`** — second Firestore ledger at file level (`form_checker_files`).
  A folder is live; without it, a teacher adding scans and resubmitting would
  re-grade and re-pay for everything already done.
- **Typed-vs-scan split, free.** A PDF with a text layer and no images is a
  context document, not student work. It is read for the task rather than
  graded — which recovers the assignment when the form does not carry it.
- **Four MoE rubrics bundled** (`moe-writing-module-c/d/f/g`), matched on the
  exam **code**. Previously every dropdown option fell through to the 9th-grade
  ESL rubric, grading a 40-point Module G task on a 30-point scale. The old
  `ministry-writing-module-c-d.json` was left untouched so oris-scanner's live
  path is unaffected.
- **`MAX_WORKS_PER_FOLDER=3`** for the pilot — a limit, not a refusal. The
  ledger filter runs *before* the cut, so resubmitting the same folder advances
  through the class three at a time.
- **No-task handling.** When neither the form nor the folder supplies the
  assignment, the work is still graded, but the model is explicitly told not to
  infer the topic and to state that it cannot determine whether the student
  answered the question.
- **`haskala/connect`** (new, repo root) — one script for the gcloud logins.

## Infrastructure unblocked (all of it was blocking, none of it was code)

1. Workspace **Google Cloud session control** → "Never require reauthentication".
   This was the 16h expiry that had blocked five consecutive sessions.
2. ADC needed **"Select all"** on the consent screen. An unticked box silently
   downgrades the grant and surfaces as `Scope has changed from … to …`.
3. `roles/iam.serviceAccountTokenCreator` granted to the human account on the
   `sainter@` service account, so production's auth path can be run locally.
4. **Domain-wide delegation** gained `spreadsheets.readonly` and `gmail.send`
   (client id `114647217076557059736`, now 8 scopes). The admin console edits
   scopes as separate fields, so nothing is replaced — the earlier fear of
   wiping oris-scanner's scopes was unfounded.
5. `sheets.googleapis.com` and `gmail.googleapis.com` enabled on the project.

## The big product finding

The teacher submitted from a **regional domain**, not bdika.net, and the folder
came through with **Editor** access. Cross-domain Drive sharing is not blocked,
at least for that מחוז. That was the largest open risk in the whole design and
it is answered empirically rather than assumed.

## Open items

- **Read the three reports.** Raw scores before any length deduction were low
  (14/30, 0/30, 12/30). Whether that is fair is the one thing logs cannot say,
  and it is the reason the run happened.
- One submission produced 11 words and 3 OCR lines with a raw score of 0 —
  likely an unreadable scan rather than a failing student. Check the source
  file; if the scan is fine, that is a bug, not a grade.
- Two submissions had identical word and line counts. Duplicate upload, or
  copying between students — worth a look.
- **Word-count conflict, undecided.** The teacher's task said "minimum 20 words";
  the Module C rubric requires 70–90 and deducts deterministically. We silently
  apply the rubric. Cost 3 points here, would cost 15 on a 25-word answer.
  Options: let an explicit teacher instruction override the rubric's table, or
  warn in the report. Needs a decision with Avishai.
- An image named like the assignment was classified as student work. Images are
  always treated as student work by design (skipping a real scan is worse than
  wasting one report), so this is accepted behaviour, not a bug to fix blindly.
- `.docx` in a folder is skipped as an unsupported format.
- Native Google Docs submissions are also skipped — more likely in a Classroom
  flow. Cheap to add via Drive export if it comes up.
- **Not deployed.** Everything so far ran locally. `RESPONSES_SHEET_ID` is now
  known, so `RESPONSES_SHEET_ID=… ./deploy.sh` is unblocked.
- `FORM_CHECKER_ALLOWED_DOMAINS` still unset — anyone with the form link spends
  budget. Set before the link circulates.
- Dedicated service account still not provisioned; `ori@bdika.net` remains the
  share target. Switching later forces every teacher to reshare, so do it before
  the link spreads.
