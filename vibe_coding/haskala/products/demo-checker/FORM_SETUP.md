# demo-checker — הטופס והלולאה

המוצר שמאחורי **Bdika Demo- English** — הטופס שאבישי בנה ב-6/8/2026.

הרעיון: מורה שלא מכיר אותנו מעלה תרגיל **אחד**, מקבל את הבדיקה במייל, ומתבקש
למלא משוב. זו לולאת ההיכרות — לא כלי עבודה יומיומי.

---

## 1. הטופס — מה כבר תקין

הכותרות נבדקו מול גיליון התשובות האמיתי ב-8/8/2026, וכל שמונה העמודות ממופות
נכון. **אין צורך לשנות שאלות.**

| # | שאלה בטופס | ממופה ל־ | חובה |
|---|-------------|----------|------|
| — | Timestamp | `timestamp` | ✅ (Forms מוסיף) |
| — | Email Address | `email` | ✅ (הגדרה) |
| 1 | First name | `first_name` | |
| 2 | Last name | `last_name` | |
| 3 | Use rubric | `rubric` | |

שאלת ההעלאה היא היחידה שהיא **חובה** מבחינת המערכת — בלעדיה אין מה לבדוק,
והמיפוי ייכשל ברעש ולא בשקט.

הרשימה המעודכנת תמיד מהקוד:

```
cd products/demo-checker && python3 form_schema.py --template
```

## 3. מי הבעלים של הטופס — התנאי הקשיח

טפסי גוגל שומרים קבצים שהועלו ב-Drive של **בעל הטופס**. הטופס בבעלות
`exam@bdika.net`, והשירות קורא בתור `ori@bdika.net`.

זה עובד היום כי שני החשבונות באותו Workspace **והתיקייה `Bdika forms`
משותפת**. הגישה מתקבלת בירושה מהתיקייה.

⚠️ **אם הטופס יוצא מהתיקייה `Bdika forms` — הגישה נשברת בשקט.** לא להעביר אותו.
טופס שייבנה מחדש בחשבון מחוץ ל-bdika.net לא ניתן לתיקון בלי בנייה מחדש.

## 4. מה קורה אחרי השליחה

1. תוך כ-5 דקות המערכת מורידה את הקובץ ובודקת אותו.
2. המורה מקבל **מייל באנגלית** עם:
   - הדוח כקובץ Word **מצורף** (לא לינק — מורה שלא מכיר אותנו לא אמור לעבור
     דרך בקשת הרשאה של Drive כדי לראות תוצאה)
   - שם הקובץ נושא חותמת זמן, כי מורה שבודק יציבות שולח את אותו דף שלוש פעמים
   - קישור לשאלון המשוב
3. אם משהו נכשל — מייל שמסביר **מה לתקן** ואיך, לא הודעת שגיאה.

### המשוב

`Feedback to Bdika Demo- English` — גם הוא של אבישי. הקישור מוטמע במייל
אוטומטית. לשינוי: משתנה הסביבה `FEEDBACK_FORM_URL`.

## 5. מגבלות

| מגבלה | ערך | הערה |
|---|---|---|
| `MAX_PAGES_PER_RESPONSE` | **4** | זו המכסה שבאמת חוסמת את החשבון (~$0.05 לעמוד) |
| `MAX_FILES_PER_RESPONSE` | 1 | דמו הוא תרגיל אחד |
| `MAX_ROWS_PER_RUN` | 5 | |

חריגה מהעמודים היא **דחייה** ולא דחייה-לשלב-הבא, בניגוד ל-form-checker: אין
תיקייה לחזור אליה, אז "בדקנו חלק" לא נתלה בכלום. המורה מקבל מייל שאומר לו
בדיוק את זה.

**הטופס פתוח לכל מי שיש לו את הקישור** — וזו כוונת המוצר, לא פספוס. אין
allowlist של דומיינים כי כל המטרה היא מורים שלא מכירים אותנו. מה שמחזיק את
הקו הוא תקרת העמודים.
