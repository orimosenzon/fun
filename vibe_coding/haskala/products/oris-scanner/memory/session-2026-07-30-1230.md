## Design decisions worth remembering

**Feedback language follows the exercise language.** `core.DEFAULT_FEEDBACK_LANG` is now
defined as `DEFAULT_EXERCISE_LANG` rather than `"he"`. Because the report only renders
the parallel second-language column and the translated summary when the two langs
differ, this one line collapses all the bilingual machinery at once. The machinery is
kept intact — a Hebrew exercise still works, verified.

**Three bundled rubrics hard-coded "feedback in Hebrew" in their prompt text** and would
have fought the language directive. All three patched to "in the language of the
exercise".

**The length rule had to be parseable from rubric *text*, not just JSON.**
`DEFAULT_RUBRIC_ID` is `esl-9th-grade-analytical`; the ministry rubric reaches production
as an *attached document*, i.e. plain text with no JSON fields. A `word_count_rule` key
alone would never have fired on the live path. So `core.parse_word_count_rule()` extracts
the table out of the rubric text; `resolve_word_count_rule()` prefers the JSON field and
falls back to the parser. Tested against the real rubric — recovers both ministry tables
exactly (Module C 70–90: `60-69→-1, 50-59→-3, 40-49→-6, 30-39→-10, 25-29→-15, <25→-30`;
Module D 80–100 with its extra band). With two tables present it picks by module letter
found in the assignment name, else the first — Module C, which is Shamir.

**The model grades on merit; the code applies the deduction.** Ori's call: the ministry
length table is a lookup, and a lookup in code is reproducible, auditable and free. The
ministry rubric's OUTPUT INSTRUCTIONS were rewritten to tell the model explicitly *not*
to apply the deduction itself — otherwise the student is penalized twice.
`apply_length_deduction()` subtracts from the `"X/Y"` overall score, floored at 0, and
leaves non-numeric scores (e.g. a CEFR level) untouched with a warning. Verified across
every band.

## Known gaps (deliberate, not oversights)

- **Word count is still mechanical** `len(text.split())`. The rubric's counting
  *exclusions* — date, "Dear X", signature, instruction sentence copied verbatim,
  passages copied from the reading text — are not implemented, so on a letter-format task
  the count runs a few words high. This matters at a band edge. The fix is to have the
  model return the countable figure (schema + prompt change, both providers).
- **An attached/Classroom rubric with no recognizable table** yields no deduction; the
  word-count row degrades to a plain count. Logged when it happens.
- **The transcript now appears three times** — "Text analysis" at the top, plus the
  unchanged "Clean transcript" and "Marked transcript" at the end. Avishai asked to move
  the table, not to delete the other two, so they were left in place. Recommendation is
  to drop both; awaiting Ori's call.
