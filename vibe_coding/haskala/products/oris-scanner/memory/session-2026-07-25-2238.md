## 1. Fixed: draft attachments were being checked before formal hand-in
Classroom attaches a student's uploaded file to the submission (and it lands in the
assignment's Drive folder) the moment they attach it — well before they press "Hand in".
`run_workspace_scan()` in `main.py` was reading every `studentSubmission` with attachments,
regardless of `state`, so a student who just uploaded a draft got checked prematurely.

Fix: skip any submission whose `state` isn't `TURNED_IN` or `RETURNED` (covers a
resubmission after the teacher reopens it), **without** claiming it in the Firestore ledger —
so once the student does formally submit, the next poll (every minute) picks it up normally.
Committed `4afbfc5`, deployed `oris-scanner-00017-nxk`.

## 2. Fixed: checker ignored the assignment's own rubric and description
Previously `checker.check_hw()` always graded against the one bundled local rubric
(`core.DEFAULT_RUBRIC_ID` = `esl-9th-grade-analytical`), completely ignoring whatever the
teacher actually set up in Classroom for that specific assignment.

Two additions, both fetched once per courseWork (not per submission):
- `_get_classroom_rubric()` in `main.py` calls `courses().courseWork().rubrics().list(...)` —
  the real Classroom Rubrics feature (criteria → levels, each with title/description/points).
  No new OAuth scope needed — covered by the existing `classroom.coursework.students` scope.
- `cw.get('description')` — the assignment's free-text definition as the teacher wrote it —
  was already present on the courseWork object, just never read.

New `core.rubric_from_classroom()` converts the Classroom Rubric's structured
criteria/levels into the same free-text `{name, content}` shape the bundled rubric JSONs use,
so it plugs into `evaluate_with_rubric()` unchanged. `check_pages()`/`check_hw()` gained
`rubric_override` (Classroom rubric, if any — takes priority) and `question` (the assignment
description, merged into the rubric dict, independent of whether a Classroom rubric exists)
parameters. When an assignment has no Classroom rubric attached, behavior falls back exactly
to the old bundled-default path.

Committed `b3185b1`, deployed `oris-scanner-00018-xjq`.
