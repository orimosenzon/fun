## The regression worth remembering

Deploying the 7/30 code took the whole scanner down for ~20 minutes and wedged the
Cloud Scheduler job into a 10-minute retry backoff.

Cause: `classroom.rosters.readonly` + `classroom.profile.emails` had been added to
the requested scope list on 7/30 but were not in the service account's
domain-wide-delegation entry. **Domain-wide delegation is all-or-nothing per token
request** — one unauthorised scope makes the token endpoint reject the *entire*
request with `unauthorized_client`. It does not return the authorised subset. So
there was no token, the first Classroom call died, and nothing was graded.

The 7/30 code comment asserting this would "degrade to the userId rather than
failing a scan" was simply wrong. Fixed in `get_workspace_credentials`:
`BASE_SCOPES` (what the scanner needs) is now separate from `PROFILE_SCOPES` (what
only improves the filename), the credentials are **refreshed eagerly** so the
failure surfaces where it can be handled, and a `RefreshError` retries with the
base scopes alone. A filename nicety can no longer take grading down.

Denial is memoised for `PROFILE_RECHECK_SECONDS` (600) rather than forever — an
earlier version cached it for the life of the instance, which would have meant a
warm instance never noticing the admin-console fix. The warning logs only on a
state change, so a once-a-minute scan doesn't flood the log.

## Unsubmit failure — diagnosed, not a bug in our code

Ori cannot unsubmit in Classroom ("There was an error unsubmitting your
assignment"). Cause: he submits as **a consumer Gmail account** into a class in the
**bdika.net** Workspace domain. Turn-in transfers file ownership student → teacher
and unsubmit reverses it, but **Google Drive does not permit ownership transfer
across domains**. Not a sharing permission — "sharing outside bdika.net" was
already ON and made no difference. No admin toggle fixes it.

Fix: submit from an account inside bdika.net. That also matches production at
שמיר, where every student is in the school's domain, so this failure won't exist
there. Flagged that adding a Workspace user may add a paid seat.
