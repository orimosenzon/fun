## תוכניות בפרויקט

### 1. OCR POC — תמלול שיעורי בית בכתב יד (`app.py`)

אפליקציית Flask קטנה שמקבלת PDF של תרגיל בכתב יד, מתמללת אותו בעזרת Claude Opus 4.7, ומציגה הצגה צמודה של כל שורת מקור (חיתוך מהתמונה) לצד התמלול שלה — להערכה ויזואלית של איכות ה-OCR.

#### דרישות מוקדמות

- Python 3.10+
- מפתח API של Anthropic

#### התקנה (חד-פעמית)

מהתיקייה של הפרויקט:

</div>

```bash
cd ~/fun/vibe_coding/haskala

# יצירת סביבה וירטואלית והתקנת תלויות
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# לאפליקציית הדסקטופ (desktop.py) — תלויות נוספות:

# הגדרת מפתח API — העתיקו את .env.example ל-.env והכניסו את המפתח
cp .env.example .env
# ערכו את .env והחליפו את sk-ant-... במפתח אמיתי
```

> **הערה ל-Linux:** pywebview דורש backend של Qt. הוא כבר מותקן ב-venv (`PyQt5`, `PyQtWebEngine`, `qtpy` — מסומנים ב-requirements כתלויות Linux בלבד). ב-Windows/macOS משתמשים ב-webview של מערכת ההפעלה ואין צורך בתלויות האלה.

לחלופין, להרצה כשרת ווב בדפדפן (פיתוח): `python app.py` → [http://localhost:5050](http://localhost:5050). כל שלושת הכפתורים עובדים גם בדפדפן (שמירה יורדת לתיקיית ההורדות במקום דיאלוג שמירה).

**פריסה לענן (כדי שאבישי ישתמש בלי התקנה):** ראו [DEPLOY.md](DEPLOY.md) — פריסה חינמית ל-Hugging Face Spaces עם Basic Auth.

#### שימוש (מסך אחד, שלושה כפתורים)

1. **פענח קובץ** — נפתח דיאלוג קבצים (תיקייה אחרונה, רק PDF). אחרי הבחירה הפענוח מתחיל מיד עם פס התקדמות אמיתי (עמוד/שלב).
2. אחרי הפענוח מוצגת כל שורה: תמונת המקור והתמלול שלצידה. **סמנו טקסט בעכבר כדי להוסיף הערה** על בעיה בפענוח.
3. **שמור קובץ מפוענח** — נפתח דיאלוג שמירה (תיקייה אחרונה). נשמר כ-JSON עם ההערות.
4. **העלה קובץ מפוענח** — נפתח דיאלוג קבצים (רק JSON) כדי לחזור לעבודה שמורה ולהמשיך להעיר.

#### פרמטרים שכדאי להכיר

- `RENDER_DPI` ב-[app.py](app.py) — DPI שבו ה-PDF מומר לתמונה לפני שליחה ל-Claude. ברירת מחדל 200. גבוה יותר = OCR טוב יותר אך יקר יותר וקרוב למגבלת 2576px של Opus 4.7.
- `padding` ב-`crop_line()` ([app.py:125](app.py#L125)) — ריווח אנכי סביב כל שורה בעת חיתוך. ברירת מחדל 30 פיקסלים.
- המודל קבוע ל-`claude-opus-4-7` ב-[app.py:87](app.py#L87). אם רוצים לחסוך — אפשר לנסות Sonnet, אך לפי הניסיון של הסשן הקודם Opus נותן OCR משמעותית טוב יותר על כתב יד עברי.
