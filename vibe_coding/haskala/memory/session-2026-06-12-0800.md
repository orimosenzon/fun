# Session 2026-06-12 (08:00)

## מה נעשה
שלושה שינויים לפי בקשת המשתמש, בעבודה מול שרת לוקאלי (port 5050) עם גישה ללוג.

### 1. תווית "מילה לא קריאה" לפי שפת התרגיל
- **באג:** כלל 7 בפרומפט התמלול (`build_ocr_prompt`) הורה למודל לכתוב `[לא קריא]` (עברית) עבור מילה לא קריאה — בלי קשר לשפת התרגיל. בתרגיל אנגלי זה הזריק מילה עברית באמצע הטקסט.
- **תיקון:** הוספת שדה `illegible` לכל שפה ב-`LANGS` (`[illegible]` / `[לא קריא]` / `[غير مقروء]`). כלל 7 משתמש ב-`{illegible}` לפי שפת התרגיל, עם הנחיה מפורשת לא לכתוב תווית עברית בטקסט לא-עברי.

### 2. בורר שפת פידבק עבר למסך הפתיחה
- היה רק ב-⚙ הגדרות. עכשיו מופיע במסך הפתיחה מתחת לבורר שפת התרגיל.
- שמירה על האינווריאנט הקיים: כל picker מופיע **פעם אחת לכל state** (inline בפתיחה / ב-⚙ במצב loaded). עטפתי את ה-picker שבהגדרות ב-`{% if pages %}` יחד עם exercise-lang. ה-JS/localStorage עובדים ללא שינוי (מסתמכים על ה-id היחיד).

### 3. שמירת בדיקה כדף ווב אינטראקטיבי + טעינה חזרה
- **ייצוא:** אפשרות חדשה בתפריט "שמור ▾" → "שמור בדיקה (דף ווב)". `buildEvalHtml()` ב-JS בונה HTML עצמאי לחלוטין (snapshot של ה-DOM המרונדר — eval-section + page-sections + תמונות base64 inline + CSS מוטמע). hover על אות מודגשת מציג tooltip עם הקריטריון+הערה דרך עותק עצמאי של סקריפט ה-tooltip. הערות-מורה מופיעות כ-`title` נייטיב.
- **דו-תכליתי (נטען חזרה):** ה-payload הנטען (זהה לפורמט "שמור JSON") מוטמע ב-`<script type="application/json" id="haskala-data">`, עם `</`→`<\/`. בשרת, `parse_saved_json` מזהה HTML מיוצא ומחלץ את ה-JSON (`_unwrap_saved_payload` + `_EMBEDDED_DATA_RE`). שני נתיבי ההעלאה (פולבק POST ל-`/` + נייטיב `/load`) נהנים אוטומטית.
- **UI:** כפתור ההעלאה שונה ל"העלה תרגיל שמור (JSON / דף ווב)" (2 מקומות), input מקבל `.html/.htm`, בורר נייטיב (`desktop.py:pick_json`) מסונן ל-`*.json;*.html;*.htm`. נוסף `desktop.py:save_html`.

## אומת אוטומטית
- round-trip: HTML מיוצא עם `</script>`/`</div>` בטקסט תלמיד → חולץ ושוחזר מילה במילה + הערות נשמרו
- JSON רגיל עדיין נטען (תאימות לאחור)
- תחביר Python (app.py, desktop.py), שני בלוקי ה-JS עוברים `node --check`
