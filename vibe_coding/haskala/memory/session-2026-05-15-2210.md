# סשן 2026-05-15 (ערב) — פיצ'ר הערות + שמירה/טעינה JSON

## מה נעשה

הורחב ה-OCR POC עם שכבת **הערות אינטראקטיביות על התמלול** ויכולת **שמירה/טעינה של עבודה שלמה** כקובץ JSON.

### בצד הקליינט (`templates/index.html`)
- כל אות בטקסט המתומלל נעטפת ב-`<span class="char">` ב-JS על page-load (עם `Array.from` ל-Unicode תקין בעברית).
- **סימון עם העכבר** (mouseup על range בתוך `.line-text`) פותח popup צף עם textarea + שמור/בטל.
- שמירת הערה → האותיות מקבלות class `annotated` (אדום, bold, underline), נשמרות ב-localStorage עם key לפי `doc_key`.
- **קליק על אות אדומה** → popup קריאה עם רשימת הערות חופפות, כפתורי ערוך/מחק לכל אחת.
- Esc / קליק בחוץ → סוגר popup.
- כפתור "שמור עבודה (JSON)" → קורא טקסט + תמונות base64 מה-DOM + הערות מ-localStorage, מוריד `haskala-<שם>-<timestamp>.json`.
- הטופס פוצל לשני טורים: "תמלול PDF חדש" / "טעינת עבודה שמורה".

### בצד השרת (`app.py`)
- `compute_doc_key()` — sha1 של כל טקסטי השורות (16 תווים). משמש כ-localStorage key לזיהוי המסמך בין refreshes.
- `parse_saved_json()` — קורא JSON, מחלץ pages + annotations, מחזיר במבנה שה-template מצפה לו.
- `render_result()` — helper שמרכז קריאה ל-`render_template` ומזריק `server_data_json` (doc_key + filename + annotations) דרך `<script type="application/json">`.
- ה-route הראשי תומך גם בהעלאת PDF (`pdf`) וגם ב-JSON שמור (`saved`). JSON עוקף את Claude לחלוטין.

### פורמט JSON
```json
{
  "version": 1,
  "filename": "...",
  "created_at": "ISO timestamp",
  "pages": [{"page": N, "lines": [{"text": "...", "image_b64": "...", "annotations": [{"id, start, end, note"}]}]}]
}
```
אופציה A מהדיון: תמונות מוטמעות base64 בקובץ JSON אחד — לא ZIP. סיבה: זה POC, התמונות כבר ב-base64 בדפדפן, אין dependencies נוספים, דיבוג קל.

## בדיקות שעברו
GET ריק, render עם pages, parse JSON roundtrip, יציבות `doc_key`, העלאת JSON end-to-end דרך `test_client`. **לא נבדק בדפדפן אמיתי** — השרת הופעל אבל המשתמש לא הספיק לבדוק.

## מצב נוכחי
- ה-POC כולל עכשיו: תמלול PDF → הצגה שורה-שורה → סימון/הערה אינטראקטיבית → שמירה/טעינה של עבודה שלמה.
- כל הקבצים מקומיים — אין שינוי במודל הפעלה, אין מסד נתונים.
- ה-JSON אוטונומי לחלוטין (אפשר לשלוח באימייל, כל המידע בפנים).

## פתוח לסשן הבא
1. **בדיקה אמיתית בדפדפן** של פיצ'ר ההערות — חוויית הסימון בעברית RTL (במיוחד טווחים חוצי-מילה), מיקום ה-popup ליד הסלקשן, התנהגות הערות חופפות.
2. הצעדים המקוריים (לא השתנו): בדיקת ה-POC על דוגמאות PDF מגוונות באיכויות שונות.
3. ההכרעה הקריטית בשאלת נקודת הכניסה של התלמיד (Classroom / companion app) — עדיין מחכה.
4. אם בעתיד הקובץ הופך גדול מדי (תרגילים ארוכים) — לחזור לאופציה B (ZIP), אבל כרגע 2-7MB מקובל.

## הערה טכנית קטנה
ה-`doc_key` מחושב מטקסטים בלבד (לא מתמונות) — כך שאם המשתמש מעדכן את התמלול ידנית בקובץ JSON, ייווצר key חדש וההערות ב-localStorage "יתאבדו". כרגע אין UI לעריכת טקסט מתומלל, אז זה לא בעיה — אם נוסיף עריכה, כדאי לחשוב על מיגרציה.
