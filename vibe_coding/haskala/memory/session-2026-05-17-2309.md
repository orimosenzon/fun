# סשן 2026-05-17 (23:09) — קלט תמונה, ריבוי שפות, וריבוי מודלים (Claude + Gemini)

## מטרת הסשן
שלוש בקשות מוצר: (1) תמיכה ב-JPG/PNG ולא רק PDF, (2) בדיקת תרגילים
בעברית/ערבית/אנגלית, (3) אפשרות לבחור מודל אחר (Gemini) דרך bורר ב-UI.

## החלטות מרכזיות
- **שפה — זיהוי אוטומטי, בלי בורר.** עברית/ערבית/אנגלית הם סקריפטים
  ויזואלית חד-משמעיים; ה-OCR prompt לא הגביל שפה ממילא. בורר-שפה מראש
  היה מזיק לתרגיל מעורב (הוראות עברית + תשובות אנגלית, נפוץ בארץ). הורחב
  ה-prompt: זיהוי כתב לפי-שורה, בלי תרגום. **הסתייגות:** כשייבנה שלב
  הבדיקה/משוב — שם השפה כן חשובה (משוב בשפת התלמיד). לא בסקופ עכשיו.
- **קלט תמונה מפשט את הקוד.** `file_to_page_images` מפצל: PDF→fitz,
  תמונה→עמוד יחיד שמדלג על הרינדור. אותו deskew→ocr→segment→crop.
- **תקרת 5MB של ה-API.** צילום טלפון מלא כ-PNG חורג. תוקן:
  `ocr_jpeg_bytes` מקטין קצה ארוך ל-2400px (עקבי עם 200-DPI A4) ושולח
  JPEG q90 — קטן בהרבה, אפס פגיעת OCR. ההקטנה רק בעותק ל-API; רזולוציה
  מלאה נשמרת ל-deskew/חיתוך.
- **ריבוי מודלים — בחירת המשתמש.** בורר ב-UI (לא ברירת-מחדל סמויה).
  `MODELS` registry + `ocr_page(img, provider)` dispatcher; provider
  מושחל decode_start→run_job→process_pdf_stream→ocr_page. Gemini דרך
  `google-genai`, client עצל, schema בתת-קבוצת OpenAPI (בלי
  additionalProperties). catch-all ב-run_job כדי ששגיאת Gemini תוצג
  במקום לתקוע את ה-SSE.
- **`load_dotenv(override=True)`** — ה-.env הוא מקור האמת המקומי;
  placeholder ישן ב-shell הצל על המפתח האמיתי. ב-HF אין .env → no-op,
  ה-Secret מנצח.
- **Gemini free tier — הגנת עלות מבנית.** מפתח בפרויקט בלי billing =
  אי-אפשר לחייב (חריגה = 429, לא חיוב). אותו עיקרון כמו תקרת הקרדיטים
  של Anthropic. **trade-off פתוח:** free tier עלול לשמש לאימון Google —
  רלוונטי כי הקלט הוא שיעורי בית של ילדים. לייצור עם נתוני תלמידים
  שוטפים — להחליט מחדש (paid tier מחזיר סיכון billing).

## פתוח לסשן הבא (לפי עדיפות)
1. **חיתוך השורות — הבעיה הפתוחה הגדולה.** צילום מחברת פתוחה
   (דאבל-ספרד) חשף שזה גרוע מהמתוכנן: הצנרת תוכננה לדף בודד, אבל
   צילום אמיתי כולל קיפול/כריכה אמצעי + טור שוליים + עיוות פרספקטיבה
   (לא רק סיבוב). `deskew_page` יודע רק לסובב. תוצאה: התמלול נכון אבל
   הרצועה החתוכה לא תואמת לטקסט. דורש כנראה זיהוי-טור + טיפול
   פרספקטיבה, או גישת חיתוך אחרת לגמרי. (היה גם פריט #1 מהסשן הקודם —
   connected-components לרצועת-רפאים — שעדיין לא נעשה.)
2. **כיול בחירת המודל** — להשוות איכות Claude מול Gemini על מדגם
   תרגילים אמיתיים (עברית/ערבית/מעורב) ולהחליט ברירת מחדל.
3. **משוב מהבדיקה החיצונית** של איכות ה-OCR — החסם להמשך הפרויקט
   (אינטגרציית Classroom וכו').
4. הכרעת נקודת כניסת התלמיד (Classroom / companion app) — עדיין פתוחה.
