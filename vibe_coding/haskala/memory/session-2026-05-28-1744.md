## פיצ'רים שנוספו

### 1. Highlights פר-קריטריון על הטקסט המפוענח
היה: צבעים רק בטבלת הרובריקה. עכשיו: ספאנים ספציפיים בתוך השורות
המפוענחות צבועים בצבע הקריטריון (תחביר=אדום, ניסוח=כחול, איות=סגול וכו').

**איך:** ה-evaluator מחזיר עכשיו `issues: [{line_ref, quote, comment}]`
לכל קריטריון. ה-prompt מאומן להחזיר ציטוט מילולי מהשורה + רפרנס בפורמט
`p1-l3` (התמלול נשלח למודל עם תיוג שורות). פונקציית `resolve_issue_spans`
מאתרת את הציטוט בשורה (exact → case-insensitive → difflib longest-block
≥80%). First-criterion-wins על חפיפות.

**רנדור:**
- **ווב:** ה-`.char` ספאנים הקיימים (שכבר משמשים annotations) מקבלים
  רקע צבעוני + tooltip מותאם (תיבה צפה עם פס צבע + שם קריטריון + הערה).
- **Word:** runs מחולקים בתוך פסקה, רקע על ה-run, ואחרי כל ספאן —
  `(שם-קריטריון: הערה)` באיטליק קטן באותו צבע.

### 2. שינוי מבנה קובץ ה-Word
לבקשת המשתמש — פירוק הסעיף התחתון לשלושה:
1. **תעתיק נקי** — טקסט גולמי, ללא מרקרים
2. **תעתיק עם סימונים** — אותו טקסט עם הצבעים, **בלי** הסוגריים `(comment)`
3. **תרגיל מקורי ופענוח** — הטבלה הקיימת (תמונה + טקסט עם הערות), ללא שינוי

`_fill_paragraph_with_spans` קיבל `include_notes` flag כדי לשתף לוגיקה
בין הסעיף בלי-הערות לסעיף עם-הערות.

## תשתית פריסה ל-HF

### הבעיה
פריסה ל-HF Space `orimosenzon/haskala-ocr` נעשתה ידנית דרך הדפדפן (העלאת
קבצים אחד-אחד). זו הייתה נקודת חיכוך חוזרת.

### מה הוקם
- ה-clone המקומי הועבר מ-`/tmp/haskala-space` (שיוצמד אחרי ריבוט) ל-`~/fun/haskala-space/` (קבוע).
- ה-remote הוחלף ל-SSH (`git@hf.co:spaces/orimosenzon/haskala-ocr`).
- נכתב `haskala/deploy.sh`: pull-rebase מה-Space → rsync של הקבצים הרלוונטיים
  (app.py, Dockerfile, .dockerignore, requirements.txt, templates/, rubrics/,
  deploy/space-readme.md כ-README) → commit → push.
- README של ה-Space (עם frontmatter title/sdk/port) מתוחזק נפרד ב-`deploy/space-readme.md`
  כדי לא להתנגש עם README של GitHub.

### חיכוך באמצע — אימות HF
לקח זמן לפתור את ה-step-up auth של HF. הסיסמה שהוגדרה ידנית לא נשמרה
כראוי (UX מבלבל); פתרון: "Forgot password" → reset במייל → התחברות נקייה
→ הוספת SSH key. דרישה חד-פעמית: SSH public key הועלה ל-https://huggingface.co/settings/keys.

### זרימה חדשה
```bash
./haskala/deploy.sh                       # קומיט אוטומטי לפי הסבג'קט האחרון בריפו
./haskala/deploy.sh "msg"                 # הודעה מותאמת
```
