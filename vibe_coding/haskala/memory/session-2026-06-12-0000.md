## מה נעשה
סשן קריאה מעמיקה + תיקוני באגים + עיצוב מחדש של ה-UI.

### שלב א' — תיקוני באגים (קומש + קומס בסשן הקודם)
1. **XSS** ב-`server_data_json|safe` — תוקן ב-`app.py` עם `.replace('</', '<\\/')`
2. **דליפת זיכרון ב-JOBS** — נוסף `_evict_stale_jobs()` עם TTL של שעה
3. **באג עמודת תרגום (אבישי)** — `feedback_lang`/`exercise_lang` נשמרים עכשיו בתוך אובייקט ההערכה ונקראים משם ב-`renderEvaluation` וב-`evaluation_docx`
4. **Azure לא מוכר ב-`humanize_error`** — נוסף טיפול ב-KeyError ו-exceptions של openai SDK
5. **`getApi` עיכוב 1.5s** — נוסף קאש לפרומיס, הטיימאאוט רץ פעם אחת בלבד
6. **שדה `level` מפורש בסכמת ההערכה** — כל 5 סכמות (EVAL_SCHEMA, 2×Gemini, Groq, Azure) עודכנו; גריד הרובריקה משתמש ב-`level` מפורש, עם fallback לרבעון
7. **אזהרת ענן לרובריקות** — modal warning ב-`{% if cloud_mode %}` מסביר שרובריקות שנוצרות ב-HF אפמרליות
