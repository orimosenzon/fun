# Session 2026-06-14 (07:30) — מיתוג (לוגו/favicon) + תיקון שפת פידבק מקצה-לקצה

## TL;DR
שלושה דברים נסגרו ונפרסו: (1) שילוב לוגו ו-favicon, (2) תיקון שפת הפידבק — הבאג
האמיתי היה שהמודל התעלם מהוראת השפה כי הפרומפט כולו עברית, (3) fallback לטבלת הבדיקה
הישנה לרובריקות בלי `criteria_grid`. הכל קומש, נדחף, ונפרס ל-Space.

## מה נעשה

### 1. מיתוג — לוגו + favicon
- נכסים ב-`static/`: `logo.png` (מפורט, מעגלים/נחושת, 320px), `favicon.png` (שטוח, 64px),
  `favicon.ico` (16/32/48). מקור: `/home/ori/Pictures/{logo,favicon}.png`.
- הרקע הלבן הוסר לשקיפות אמיתית עם Pillow (whiteness-keying חלק) + autocrop.
- favicon ב-`<head>`. **הלוגו לא ב-hero** (המשתמש דחה — ציור הבית נשאר) אלא כ**חותמת בתחתית
  הדף**: `<footer class="app-stamp">` עם הלוגו 46px + "השכלה" + "בדיקת תרגילים חכמה", opacity 0.62.
- Dockerfile: נוסף `COPY static/ static/`. deploy.sh: נוסף `static` ל-DIRS.

### 2. שפת הפידבק (הבאג המרכזי)
- **שורש:** `build_eval_prompt` כתוב כולו בעברית. ההוראה "פסקת סיכום ב{primary}" נבלעה,
  והמודל החזיר עברית גם כש-feedback_lang=en. **אומת בקריאת API ישירה** (233 תווים עבריים).
- **תיקון:** הוספת `LANG_DIRECTIVES` — הוראת שפה תקיפה הכתובה **בשפת היעד עצמה**
  (לאנגלית: "ALL feedback... MUST be in English only. Do NOT write in Hebrew, even though
  these instructions are in Hebrew"). ממוקמת בראש הפרומפט (‼️) וכתזכורת לפני ה-JSON.
  אומת: feedback=en → 0 תווים עבריים; feedback=he,exercise=en → עברית ראשי + אנגלית משני.
- **לוקליזציה מלאה של הדו"ח:** כל התוויות הקבועות עוקבות אחרי feedback_lang —
  web דרך `REPORT_LABELS` (he/en/ar), Word דרך `DOCX_LABELS`. כולל: ציון כללי, ענה על השאלה,
  ספירת מילים, מילות עזר, כותרות טבלה, כותרת סקשן, "רובריקה:".
- **RTL/יישור:** `#eval-section` מקבל `dir` לפי feedback_lang (en→ltr שמאלה). ה-grid שומר
  dir:ltr משלו, פסקת המודל dir:auto. ב-docx — `main_align` לפי כיוון השפה.

### 3. Fallback לטבלת בדיקה ישנה
- ב-web: כשאין `criteria_grid`, הטבלה הישנה הצבעונית חוזרת (`showLegacy = SHOW_LEGACY_EVAL_TABLE || !hasGrid`).
  הדגל `SHOW_LEGACY_EVAL_TABLE` נשאר כ-override. ב-docx הטבלה הישנה עדיין מאחורי הדגל (לא הורחב).
