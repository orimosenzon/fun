# סשן 2026-06-04 09:19 — בוררי שפה (תרגיל/פידבק) + שדרוג ל-Opus 4.8

## מה נעשה

### 1. שני בוררי שפה ב-UI
נוספו ל-actionbar הראשי שני בוררי `<select>`, כל אחד עם 3 אופציות (עברית/אנגלית/ערבית):
- **שפת תרגיל** — מה שכתוב בצילום של התלמיד. ברירת מחדל: **אנגלית**.
- **שפת פידבק** — שפת המשוב/הסברים/הערות. ברירת מחדל: **עברית**.

הערכים נשמרים ב-localStorage (`haskala-exercise-lang`, `haskala-feedback-lang`)
ונשלחים בכל קריאה ל-`/decode/start`, `/evaluate/start`, ו-`/evaluation/docx`.

### 2. פרומפטים הפכו להיות תלויי שפה
- `OCR_SYSTEM_PROMPT` → `build_ocr_prompt(exercise_lang)` — מציין את השפה
  העיקרית הצפויה במפורש למודל. כשהשפה RTL, נוסף emphasis בראש הפרומפט
  על כיוון הכתיבה.
- **כלל 9 חדש** ב-OCR prompt: פלט תמיד ב-Unicode logical order — המילה
  הראשונה במחרוזת היא הימני-ביותר בקריאה. כולל דוגמה בערבית. זה הפתרון
  להיפוך שראינו (המודל היה מוציא מילים בסדר תצוגתי, מה שגרם ל-renderer
  להפוך אותן שוב).
- `EVAL_SYSTEM_PROMPT` → `build_eval_prompt(feedback_lang, exercise_lang)` —
  דורש פידבק בשפת הפידבק + תרגום שני בשפת התרגיל. כששתי השפות זהות,
  השדה השני מתבקש כמחרוזת ריקה.

### 3. שינוי שמות שדות (`_en` → `_secondary`)
ב-schema של ה-eval:
- `feedback_en` → `feedback_secondary`
- `overall_feedback_en` → `overall_feedback_secondary`

ב-UI וב-Word generation יש fallback ל-`_en` כדי שקבצים שמורים ישנים
ירונדרו תקין.

### 4. Word doc אדפטיבי לשפות
- כשהשפות שונות: 4 עמודות, כותרת "פידבק ({שם שפת התרגיל})".
- כשהשפות זהות: 3 עמודות בלבד.

### 5. שדרוג ל-Opus 4.8
`_ANTHROPIC_MODEL` = `claude-opus-4-8` (+ עדכון label ב-MODELS, הערה על
מגבלת 2576px, README).
