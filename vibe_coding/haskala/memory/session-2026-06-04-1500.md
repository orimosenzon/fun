# סשן 2026-06-04 15:00 — שינוי מדיניות שמות קבצי Word

## מה נעשה

שונתה מדיניות שמות קבצי ה-Word שנשמרים מהאפליקציה:

**לפני:**
- `haskala-decode-<basename>-<timestamp>.docx`
- `haskala-eval-<basename>-<timestamp>.docx`

**אחרי:**
- `ocr-YYYYMMDD-<basename>.docx`
- `eval-YYYYMMDD-<basename>.docx`

קצר יותר, ומכיל: סוג (OCR/הערכה), תאריך, שם תלמיד (=שם קובץ ה-PDF המקורי).

## קוד שנשתנה
- `app.py` — נוסף `import datetime`, עודכן `out_name` בשני ה-endpoints (`/decode/docx`, `/evaluation/docx`)
- `templates/index.html` — עודכן `name` בשני ה-handlers ב-JS (save-decode-docx, save-eval-docx)

## מה לא יושם (חוב)
**מדיניות שמות מיוחדת לקבצים שמתחילים ב-`_`:**
- אם שם הקובץ המקורי מתחיל ב-`_`, השם יהיה: `<שם_מקורי>_OCR_<מודל>.docx` / `<שם_מקורי>_Eval_<מודל>.docx`
- דיון הגיע עד לשלב ניתוח הקוד (MODELS dict, `currentModel()` בJS) אבל לא יושם.
- נדרש: הוספת `MODEL_FILENAME_LABEL` dict בפייתון, הזרקתו ל-template, פונקציית `docxName(kind)` בJS.
