# סשן 2026-06-07 07:32 — פריסת gpt-4o ב-Azure Foundry (חסום על quota)

## מטרה
להמשיך מהסשן הקודם — לפרוס gpt-4o ב-Azure resource הקיים, להוציא KEY+endpoint ל-.env, ולפתוח את הצינור לבנצ'מרק Claude vs GPT-4o.

## מה הושג

### 1. פרויקט Foundry נוצר
- במקום להמשיך עם ה-resource הישן (`haskala-openai-orim`), Microsoft Foundry יצר resource חדש בעת יצירת הפרויקט:
- **Project name:** `haskala-foundry`
- **Resource name (חדש):** `haskala-foundry-resource`
- ה-resource הישן `haskala-openai-orim` יושב יתום — אין צורך בו יותר, כדאי למחוק אחר כך
- **חשוב:** הקרדיט ה-$1,000 שייך ל-subscription, לא ל-resource, אז זה לא בוזבז

### 2. Endpoints + API Key נשלפו
שני endpoints קיימים בפרויקט:
- **Project endpoint** (לא רלוונטי לנו): `https://haskala-foundry-resource.services.ai.azure.com/api/projects/haskala-foundry` — מיועד ל-Agents SDK
- **Azure OpenAI endpoint** (זה מה שאנחנו צריכים): `https://haskala-foundry-resource.openai.azure.com/openai/v1`

### 3. `.env` עודכן
נוספו 3 משתנים חדשים:
```
AZURE_OPENAI_API_KEY=<KEY 1>
AZURE_OPENAI_ENDPOINT=https://haskala-foundry-resource.openai.azure.com/openai/v1
AZURE_OPENAI_DEPLOYMENT=gpt-4o-vision
```
`.env` עדיין ב-`.gitignore` ✅

### 4. בחירת מודל לבנצ'מרק
התלבטות — Foundry מציע 115 מודלים (Claude, Gemini, Mistral, DeepSeek, Llama, Grok...). הכריע:
- **רק `gpt-4o` בסשן הזה** — זו המטרה של הקרדיט
- אסור Claude דרך Azure: כבר משלמים ישירות, וזה פי 6 יקר מ-gpt-4o ($15 vs $2.50 per 1M input tokens)
- מודלים אחרים נשמרים לסשנים עתידיים (gemini-2.5-pro, mistral-document-ai מועמדים סבירים ל-OCR)

## נקודת החסימה

**גילינו ש-Insufficient quota על gpt-4o Global Standard** — Subscriptions חדשים של Founders Hub לא מקבלים מכסה אוטומטית.

הניווט עצר בדיוק בנקודה הזו:
- Discover → gpt-4o → Deploy → Custom settings → דיאלוג נפתח
- Deployment type: Global Standard
- Deployment name: השם המוצג נשאר `gpt-4o` (היה צריך לעדכן ל-`gpt-4o-vision`)
- במקום כפתור Deploy — הופיע "Insufficient quota"

## הצעדים לסשן הבא (לפי הסדר)

### א. לפתור את ה-quota
ננסה לפי הסדר:
1. **לפתוח שוב את דיאלוג Deploy gpt-4o** ב-Foundry
2. **לשנות Deployment type** מ-Global Standard ל-**DataZone Standard** (מאגר אחר) — אם זמין, נסה. אם גם זה Insufficient → **Standard** (אזורי)
3. **אם כל הסוגים נופלים** — בקשת quota ידנית:
   - `portal.azure.com` → Azure OpenAI → Quotas
   - Request quota על gpt-4o (East US, 30K TPM)
   - **סיבה:** "POC for Hebrew handwriting OCR benchmark, Microsoft for Startups credit"
   - אישור אנושי — לוקח שעות עד יום

### ב. לתקן את שם ה-deployment
ברגע שפותחים את הדיאלוג — לעדכן ל-`gpt-4o-vision` (השם שכבר ב-.env), או לחלופין לעדכן את `.env` לשם שמתקבל.

### ג. אחרי שפריסה הצליחה
1. להוסיף Azure provider ל-`vision_providers.py` (SDK: `openai` עם `base_url`+`api_version`)
2. לבדוק על עמוד אחד ידנית — לוודא שהתמלול חוזר
3. בנצ'מרק 5-10 דפים: Claude vs GPT-4o Vision על דיוק, latency, עלות

### ד. הגנות על הקרדיט (לפני הרצת קוד אמיתי)
חוב פתוח שלא הספקנו לטפל בו:
1. **לבדוק סוג subscription** — Sponsorship (מוגן אוטומטית) vs Pay-As-You-Go (עלול לחייב כרטיס):
   - portal.azure.com → Subscriptions → Overview → "Offer"
2. **להגדיר Budget Alerts:** Cost Management → Budgets → `haskala-1000-cap` ב-$900, התראות ב-50%/80%/95% לאימייל
3. **אם Pay-As-You-Go** — להפעיל Spending Limit

הסיבה לעדיפות: אורי נגנב בעבר על AI APIs (ראה `feedback_paid_api_risk`).
