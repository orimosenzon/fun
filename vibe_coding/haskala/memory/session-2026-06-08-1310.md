# סשן 2026-06-08 13:10 — אינטגרציית Azure OpenAI (gpt-4.1-mini) מקצה לקצה

## מטרה
להוסיף מודל OpenAI לאפליקציה ולנצל את קרדיט Microsoft for Startups. הסשן הקודם נעצר על "Insufficient quota". הסשן הזה השלים את כל השרשרת: פריסה → קוד → production → הגנות.

## מה הושג

### 1. פריסת gpt-4.1-mini ב-Azure Foundry
- **הבלוקר נפתר:** quota מחושב **לכל Deployment type בנפרד**. ל-**Global Standard** יש 0 מכסה ב-subscription חדש של Founders Hub. הפתרון: לעבור ל-**Standard** (אזורי) — לו יש מכסה כברירת מחדל (ראינו 100K TPM זמינים).
- **מלכודת שנייה:** gpt-4o-mini הוצא משירות (deprecated 31/03/2026, רק גרסת 2024-07-18 קיימת). עברנו ל-**gpt-4.1-mini** (יורש, גרסה 2025-04-14, GA, יש vision: Input type = text,image). עדיף בלאו הכי.
- Deployment name: `gpt-4.1-mini`, type Standard, resource `haskala-foundry-resource`.

### 2. קוד — ספק Azure נוסף ל-app.py
- Azure תואם-OpenAI בדיוק כמו Groq (`chat.completions.create` עם `image_url` data-URL), אז שוכפל דפוס Groq לכל שלוש נקודות ה-dispatch: OCR (`_ocr_azure`), eval רגיל, eval בסטרימינג.
- Provider key: `azure-gpt41-mini`, תווית: "GPT-4.1-mini (Azure)".
- לקוח: `OpenAI(base_url=AZURE_OPENAI_ENDPOINT, api_key=...)` — ה-endpoint הוא ה-v1 surface (`.../openai/v1`), שה-SDK הסטנדרטי מדבר ישירות. בנייה lazy (נכשל רק אם בוחרים Azure בלי env).
- המודל נבחר לפי `AZURE_OPENAI_DEPLOYMENT` — החלפת מודל עתידית = עריכת .env בלבד.
- הותקן `openai>=1.50.0` (גם ב-requirements.txt).
- **נבדק מקצה-לקצה:** קריאת OCR סינתטית חזרה HTTP 200 + JSON תקין (`writing_region` + `lines`). עובד.

### 3. Production
- קומיש ל-GitHub (master) + `./deploy.sh` ל-HF Space.
- **3 secrets נוספו ב-Space** ידנית: `AZURE_OPENAI_API_KEY`, `AZURE_OPENAI_ENDPOINT`, `AZURE_OPENAI_DEPLOYMENT` (כי deploy.sh לא מעתיק .env).

### 4. הגנות על הקרדיט
- **סוג החשבון אומת:** Plan = Azure Plan, מבוסס-credit ($1,000 remaining, Amount due $0.00, אפס חשבוניות). זה hard cap דרך *סוג החשבון* — כשהקרדיט נגמר השירות מושבת, **בלי חיוב כרטיס**.
- **תאריך תפוגת קרדיט: 4 בספטמבר 2026.**
- **Budget alert נוצר:** `haskala-budget`, $100 חודשי, התראה ב-50% ($50) למייל. (Budget = התראה, לא חוסם — ההגנה האמיתית היא סוג החשבון.)

## תובנות מפתח (לשימוש חוזר)
- ב-Azure לא "מעלים" מודל — "deployment" = endpoint בעל-שם למודל שכבר מתארח. הבלוקר הוא **quota** (רשות), לא התקנה.
- quota הוא **לכל deployment-type בנפרד**. נתקעת על Global Standard? נסה Standard / DataZone Standard לפני בקשת quota ידנית.
- Budget ב-Azure לא עוצר הוצאה — רק מתריע. חסם קשיח אמיתי = סוג subscription (sponsorship/credit) או TPM rate-limit על ה-deployment.

## צעדים הבאים (לפי עדיפות)
1. **לבדוק תמלול אמיתי** עם gpt-4.1-mini על דף כתב יד עברי (לוקאלי או ב-Space).
2. **בנצ'מרק Claude vs gpt-4.1-mini** על כתב יד עברי — דיוק, latency, עלות. זו הייתה כל מטרת הקרדיט.
3. שאריות: למחוק resource יתום `haskala-openai-orim` (לא עולה כסף); לבטל GROQ_API_KEY שדלף (פעולה ידנית ב-console.groq.com).
4. החובות הישנים: באג עמודת התרגום של אבישי (`[eval DIAG]` עדיין בקוד), אינטגרציית Classroom+OAuth, pilot עם מורה.
