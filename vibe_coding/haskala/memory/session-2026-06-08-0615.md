# סשן 2026-06-08 06:15 — בקשות אבישי (UI) + DIAG לעמודת התרגום

## מטרה
לטפל בבקשות הממשק של אבישי (המשתמש העיקרי כרגע) לפני המשך עבודת ה-quota של Azure.

## מה הושג — שלוש בקשות אבישי (יושמו, נבדקו, נפרסו)

### 1. בורר המודל עבר למסך הפתיחה
- הוצא ממסך ההגדרות (⚙) ל-inline במסך הפתיחה (empty-cta), מעל "שפת התרגיל".
- במצב טעון הבורר נשאר ב-⚙ — בדיוק `#model-select` אחד קיים בכל מצב (guard `{% if pages %}` במודל), כדי שה-JS יישאר פשוט.

### 2. כפתור איתחול גלובלי
- `#global-reset` קבוע (position:fixed, פינה שמאלית-עליונה) — נגיש מכל מסך: פתיחה / תצוגה מקדימה / פענוח / תוצאה.
- מבקש אישור (confirm) רק כשיש פענוח טעון על המסך; במסך פתיחה פשוט מרענן.
- כפתור ה"אתחל" הישן בתפריט ⋯ נשאר (לא הזיק).

### 3. אנגלית בלי חיתוכי שורות
- ב-`process_pdf_stream`: כש-`exercise_lang == "en"` מדלגים על `segment_into_lines`+`crop_line`, בונים line_items עם `image_b64: ""`. חוסך עבודה. מבנה השורות נשמר (entry לכל שורה מ-OCR).
- בתבנית: `{% if line.image_b64 %}` עוטף את `<img class="line-image">` — אין תמונת חיתוך כשאין b64.
- `collectPages` ב-JS: `img ? ... : ''` — שמירת JSON לא קורסת בלי תמונת שורה.
- Word: כבר היה `if line_b64:` → באנגלית "שורה-שורה" מציג טקסט בלבד. עברית/ערבית — החיתוכים נשארים כרגיל.

## חוב פתוח עיקרי — באג עמודת התרגום בטבלת הבדיקה (לא נפתר)
אבישי דיווח: בטבלת הבדיקה נעלמה עמודת התרגום לשפת הממשק. "פעם הופיע בשתי שפות".
- המנגנון: עמודת "פידבק (שפת תרגיל)" מוצגת רק כש-`feedback_lang != exercise_lang` ([index.html](../templates/index.html) ~showSecondary) **וגם** המודל מילא את `feedback_secondary`.
- ברירת מחדל: exercise=en, feedback=he → אמורה להופיע. אז או שהשפות נקבעו זהות (config), או שהמודל לא מילא את התרגום.
- **הוסף DIAG זמני** ב-`evaluate_with_rubric_stream` (לפני yield ה-result): לוג `[eval DIAG]` עם feedback_lang/exercise_lang/same + criteria/with_secondary + דגימת קריטריון ראשון חסר. נכתב ל-`haskala.log`.
- **המתנה:** אבישי/אורי צריך להריץ "בדוק תרגיל" במצב הבעייתי, ואז לקרוא את הלוג. שלושה תרחישים:
  - `same=True` → השפות זהות, הסתרה מכוונת — החלטת מוצר.
  - `same=False` ו-`with_secondary < criteria` → המודל לא מילא — בעיית prompt/מודל.
  - `same=False` ו-`with_secondary == criteria` → הנתונים תקינים → באג frontend, להוסיף DIAG שם.
- **לזכור:** להסיר את לוג ה-DIAG אחרי שמתקנים, ולקמס שוב.
