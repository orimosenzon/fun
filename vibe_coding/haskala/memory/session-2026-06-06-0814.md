## מה נעשה (טכני)

### 1. ניקוי UI ראשי
- **מצב ריק:** CTA יחיד גדול ("פתח תרגיל לבדיקה") + בוחר שפת תרגיל בולט מעליו. קישוטיות טקסט: "העלה JSON" + "⚙ הגדרות".
- **מצב טעון:** סרגל עליון קומפקטי (שם קובץ + מספר עמודים + "פתח קובץ אחר" + ⚙ + ⋯), workbar שני (רובריקה + שמור + בדוק).
- **תפריט שמור:** Word options ראשונים (שימוש כבד), JSON תחת מפריד "דיבאג".
- **תפריט ⋯:** "העלה JSON מפוענח" + "אתחל" — פעולות נדירות.
- **מודאל הגדרות (⚙):** מודל + שפת תרגיל (במצב טעון בלבד) + שפת פידבק.

### 2. שפת תרגיל בולטת לפני פענוח
- בעקבות פידבק של אורי: שפה היא per-file choice שמשפיעה על OCR — חייבת להיות גלויה לפני "פתח תרגיל".
- במצב ריק → inline מעל ה-CTA. במצב טעון → חוזרת למודאל (לא רלוונטי לראות תמיד אחרי שפוענח).

### 3. פס התקדמות אמיתי ל-/preview
- /preview היה סינכרוני → הפס נתקע על 0% עד שהכל מוכן.
- שינוי: `/preview` מחזיר `{job_id}` מיידית; `/preview/progress/<id>` זרם SSE עם events פר-עמוד (פותח את הקובץ → מסובב לכיוון נכון → מתקן הטיה עדינה → מוכן).
- מבנה הפונקציה: `run_preview_job` ב-thread, queue, כמו `run_job` של ה-decode.
  ([app.py:run_preview_job](app.py))

### 4. תיקון bug — מודאל רובריקה תקוע
- ה-CSS שהוספתי ל-`.modal-backdrop` של ההגדרות (`display:flex` תמיד + `[hidden]→none`) דרס את ה-CSS הקיים (`display:none` + `.visible→flex`) של מודאל רובריקה. תוצאה: מודאל רובריקה היה תמיד מוצג ומסך את הכפתורים.
- תיקון: השתמשתי בדפוס `.visible` הקיים גם למודאל ההגדרות, הסרתי הגדרת `.modal-backdrop` כפולה.
- לקח: לבדוק collision עם CSS קיים לפני להוסיף global selectors.
