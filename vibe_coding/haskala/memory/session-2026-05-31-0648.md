## מה השתנה ב-`templates/index.html`

### פלטת צבעים חדשה
- `--bg: #f1e1c2` (קלף חם) במקום לבן/קרם בהיר
- `--paper / --paper-alt`: שני גוונים של קרם לכרטיסי שורה מתחלפים
- `--accent: #1e5145` (ירוק יער) — כפתורי primary
- `--header-bg-1 → header-bg-2: #f4a587 → #d97a5a` — גרדיאנט קורל לבאנר
- `--badge: #5a8d48` — באדג'ים עגולים
- `--secondary: #b08a52` (טאן) במקום אפור — כפתורי secondary

### Hero banner חדש
- `<div class="hero">` עוטף h1 + subtitle
- גרדיאנט קורל 135°, פינות מעוגלות 16px, צל
- SVG inline של בית-ספר (דגל, גג, חלונות, דלת) משמאל ב-`hero-art`
- `padding-left: 7.5rem` להבטיח שאין חפיפה בין SVG לטקסט
- Media query ב-640px: SVG מוסתר, padding מצומצם

### Subtitle בפתק קרם (אחרי כמה איטרציות)
- ניסיון 1: שקוף + dark — לא מספיק קונטרסט
- ניסיון 2: weight 600 + text-shadow — עדיין לא נח
- ניסיון 3 (סופי): **`display: inline-block` עם רקע קרם, פינות מעוגלות, צל** — קלאסי מ-Stripe/Linear, נקרא מצוין
  ```css
  background: rgba(253, 246, 224, 0.94);
  color: #2a1408;
  padding: 0.55rem 0.95rem;
  border-radius: 10px;
  ```

### Buttons → pill shape
- `border-radius: 999px` במקום 4px
- `box-shadow` + hover עם `translateY(-1px)`
- Primary: ירוק יער. Secondary: טאן (במקום אפור). Disabled: בז' עמום.

### Line cards
- צבעים מתחלפים (`:nth-child(even)`) בין `#fdf8e9` ל-`#faf1d6`
- `border-radius: 10px`, hover shadow
- `padding-right: 3rem` כדי לפנות מקום לבאדג'

### Line numbers → באדג'ים עגולים
- היה: `<span class="line-num">1.</span>` inside `.line-text-row` (טקסט אפור קטן)
- עכשיו: `<span class="line-num">1</span>` ישירות בתוך `.line` (ללא נקודה!)
- `position: absolute; top: 50%; right: 0.6rem; transform: translateY(-50%)`
- 32×32 עיגול ירוק, טקסט לבן bold, צל

### Floating evaluate button
- היה: `<button id="evaluate-btn">` בתוך actionbar
- עכשיו: `<div id="floating-eval" class="floating-eval visible">` קבוע למטה
- `position: fixed; bottom: 1.5rem; left: 50%; transform: translateX(-50%)`
- כולל svg של עט-נוצה (`feather-icon`), padding-bottom 6rem על ה-body כדי שלא יחפוף תוכן
- ה-`eval-spinner` הועבר לתוך ה-container הצף (אותו ID — JS ממשיך לעבוד)

### Eval table + modal
- פינות מעוגלות יותר (14px)
- `border-radius: 10px` על הטבלה עם `overflow: hidden`
- `border-bottom: 1px dashed var(--border)` ב-page header במקום solid
- Modal עם רקע `var(--paper)` במקום לבן

## מה לא נשבר
- כל ה-IDs וה-class names ש-JS משתמש בהם נשמרו
- `getElementById('evaluate-btn')` ו-`getElementById('eval-spinner')` עדיין מוצאים אותם (פשוט מ-DOM אחר)
- אנוטציות, highlighting, evaluation, save — ללא שינוי
- ה-modal של הוספת רובריקה תפקודית, צבעים חדשים בלבד
