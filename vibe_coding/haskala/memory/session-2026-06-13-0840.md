אותו לריפו (וזה קרה — קובץ קיים בריפו ה-Space, commit b266cf9), **אבל ה-Dockerfile

runtime ImportError → 503.

## התיקון

- קומש ל-master (GitHub) + הורץ deploy.sh → נדחף ל-Space (c1d3f2a).
- אימות: curl לרוט החזיר HTTP 401 עם `server: gunicorn` +
  `www-authenticate: Basic realm="haskala"` + גוף "נדרשת הזדהות" — כלומר
  ה-Flask app רץ בריא, פשוט מאחורי ה-Basic Auth (HASKALA_USER/PASS כ-Space secrets).
  עברנו מ-503 (קריסה) ל-401 (auth gate תקין).

## לקח לעתיד

שווה לשקול `COPY *.py .` כדי שזה לא יחזור (לא בוצע — כדי לא לגרור קבצים לא רצויים).
