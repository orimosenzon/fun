# Session 2026-06-02 23:40 — אסטרטגיית מימון AI credits וכיוון סטארטאפ

## סוג הסשן
דיון אסטרטגי — ללא שינויי קוד. בירור מסלולי מימון לעלויות AI ובחירת ארכיטקטורה לסקייל.

## רקע השיחה
התחלנו מהשאלה הפרקטית: חסרה לנו quota של Gemini, האם אפשר להשתמש בחשבון של בית הספר של אבישי? הלכנו עמוק יותר וגילינו ש-haskala צריך כיוון אסטרטגי מהיסוד.

## החלטות והבחנות מרכזיות

### 1. שימוש בחשבון בית ספר של אבישי — לא ריאלי
- Google Workspace for Education נותן Gemini בתוך Docs/Gmail אבל **לא API keys**.
- Free Tier של Gemini API זהה לכל חשבון Google — אין הטבה ייחודית למורים.
- ToS-wise: שימוש בחשבון בית הספר באפליקציה שמתארחת ב-HF Space ציבורי = בעייתי.
- סיכון אבטחה: דליפת API key מחשבון בית ספר → חשבון חיוב גדול שיורד עליהם, לא עלינו.

### 2. Google Cloud for Education credits — לא רלוונטי ל-K-12
- **Teaching Credits**: רק להשכלה גבוהה (faculty באקדמיה). אבישי לא זכאי.
- **Research Credits**: רק faculty/PhD/postdoc במוסדות אקדמיים מוכרים.
- בית ספר K-12 ישראלי ממוצע **לא זכאי** לאף תוכנית קרדיטים של גוגל.

### 3. מעבר ל-GCP hosting (Cloud Run) — לא פותר quota
- מקום ה-hosting **לא קובע quota**. ה-quota תלויה ב-billing account של הפרויקט.
- היתרון היחיד של מעבר ל-Cloud Run הוא **service accounts במקום API keys** (אבטחה).
- מעבר לחשבון GCP של בית הספר היה תיאורטית מסייע — אבל רוב בתי הספר אין להם GCP בכלל, רק Workspace.

### 4. תובנה אסטרטגית — "בית ספר מקים GCP" הוא חסם adoption (אורי)
אם המטרה היא להגיע למאות בתי ספר, לדרוש מכל אחד להקים GCP זה לאבד 95% מהם בבירוקרטיה. צריך ארכיטקטורה שמתאימה לסקייל מההתחלה.

### 5. הבהרת חזון — haskala הוא סטארטאפ עתידי (אורי)
**זה לא סייד פרויקט.** המטרה: לבנות סטארטאפ ש-(א) מתחיל ממימון משקיעים (ב) עובר להכנסות ממשתמשים. אורי לא מעוניין לממן עלויות AI מהכיס שלו.

זה משנה את כל המשוואה — צריך לחשוב על haskala כעסק, לא כפרויקט.

## אסטרטגיה שגובשה

### ארכיטקטורת AI לסקייל
**BYOK (Bring Your Own Key)** — כל מורה נרשם ל-AI Studio בעצמו (5 דקות), מקבל API key, מדביק באפליקציה.
- אפס חיכוך מוסדי
- אנחנו לא משלמים על API
- Free tier מספיק לכיתה
- צריך UX טוב למסך הוספת ה-key

### מימון לפני BYOK / כשעדיין צריך לפתח
**מסלול קרדיטים לסטארטאפים** — לא לבית ספר, אלא כסטארטאפ:

**Tier A (השבוע, לבד):**
1. Microsoft for Startups Founders Hub — $150K Azure + Azure OpenAI. self-serve, מאושר תוך ימים.
2. Anthropic for Startups — קרדיטים ל-Claude. רלוונטי כי Claude הוא ה-OCR שאנחנו משתמשים בו בפועל ב-haskala.
3. NVIDIA Inception — חינם, להירשם.

**Tier B (אחרי רישום חברה):**
4. Google for Startups Start ($2K-$25K)
5. מתי שיש backing מאקסלרטור → Google Founders ($200K), AWS Activate ($100K)

**Tier C (ישראל ייחודי):**
6. רשות החדשנות — מסלול תנופה (עד 500K ש"ח, 75-85% מימון ממשלתי) — דורש traction.
7. אקסלרטורים: **MindCET** (EdTech ייעודי), **Mass Challenge Israel** (ללא equity), **8200 EISP** (אם יש קשר).
