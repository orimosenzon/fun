## מה בוצע

### 1. ננטש: פריסה על ה-VM
תקוע כמעט כל הסשן על אימות gcloud מקומי (localhost redirect נכשל פעמיים עם
שגיאת 400/SetSID; `--no-launch-browser` גם נתקל בבעיות). הפתרון שעבד בסוף:
**Cloud Shell** בקונסולה — מאומת אוטומטית, אין צורך באימות מקומי בכלל.

### 2. DNS
נוספו רשומות A ב-Squarespace (ביקשנו מאבישי לבצע, הוא ביצע):
- `checker.bdika.net` → `34.30.199.161`
- `math.bdika.net` → `34.30.199.161`
⚠️ **אלה עדיין מצביעות על ה-VM הנטוש** — צריך לעדכן שוב ל-Cloud Run domain
mapping (CNAME, לא A) אחרי שהשירותים יהיו ציבוריים.

### 3. פריסת checker ל-Cloud Run — **הצליחה חלקית**
```
gcloud run deploy checker --source . --region us-central1 --port 7860 --allow-unauthenticated
```
נפרס בהצלחה: `https://checker-311716089389.us-central1.run.app`
🔴 **חסום:** `--allow-unauthenticated` נכשל — org policy בשם **Domain Restricted
Sharing** (`iam.allowedPolicyMemberDomains`) חוסם הענקת גישה ל-`allUsers`.
לתקן: מישהו עם הרשאת **Organization Policy Administrator** צריך ללכת ל-
`console.cloud.google.com/iam-admin/orgpolicies/iam-allowedPolicyMemberDomains?project=master-gecko-500709-t0`
→ Manage policy → Applies to: Customize → Policy enforcement: **Off** → Save.
אורי ניסה — קיבל "You need permissions for this action" (Fix access). **לא
נבדק סופית האם אבישי (Workspace super admin) יכול לתקן** — זה השלב הבא.

### 4. math-checker — עדיין לא נפרס ל-Cloud Run
ממתין לפתרון חסימת ה-org policy (אותה בעיה תחסום גם אותו).

### 5. אינטגרציית scan2 של ירון — קוד מוכן, טרם נפרס
ירון בנה בעצמו Cloud Run function (`scan2`, europe-west1, entry point
`process_my_drive_files`) שסורק Classroom → כל קורס → כל מטלה → כל הגשה,
ומצפה לפונקציה `checker.check_hw(drive_service, file_ids, folder_id)`.

כתבנו:
- **`checker.py`** — אדפטר אמיתי: מוריד קבצים מ-Drive, מריץ כל אחד דרך
  `core.process_stream` של math-checker, ממזג עמודים מכמה קבצים לדוח אחד,
  מייצר Word (`report.build_result_docx`) ומעלה ל-`folder_id`.
- **`main.py`** — זהה לגרסת ירון, עם **תיקון אחד**: נוסף scope חסר
  `https://www.googleapis.com/auth/documents` (בלעדיו `append_text` היה
  נכשל בכל קריאה ועוצר את שאר הלולאה).
- **`requirements.txt`** — נוספו `anthropic`, `pymupdf`, `Pillow`,
  `python-docx`, `python-dotenv`.

⚠️ **דגל לירון (טרם הועבר):** ב-`run_workspace_scan()` אין דה-דופליקציה —
הערה `# check if we checked this submission` קיימת אך לא ממומשת. כל הרצה
מחדש תעבד את **כל** ההגשות מההתחלה, כולל כאלה שכבר נבדקו. יש לנו כבר פתרון
לזה ב-`math-checker/poller.py` (ledger אטומי לפי submissionId+updateTime) —
כדאי להציע לירון.

**מצב ביצוע:** נתנו לאורי בלוק פקודות ל-Cloud Shell (`~/scan2-src/`) שמרכיב
את חמשת הקבצים (`core.py`+`report.py` מועתקים מ-math-checker, `checker.py`+
`main.py`+`requirements.txt` חדשים) — **הסשן הסתיים באמצע**, לפני ההרצה של
`gcloud run deploy scan2 --source ~/scan2-src --region europe-west1
--function process_my_drive_files --project master-gecko-500709-t0`.

### 6. Cloud Tasks
אושר כבחירה טובה לתור משימות אסינכרוני (עיבוד OCR ברקע), מתחבר טבעי ל-Cloud
Run. **טרם מומש בפועל** — נשאר משימה פתוחה.

## חוסם יחיד לכל ההמשך
**org policy "Domain Restricted Sharing"** על הפרויקט `master-gecko-500709-t0`
— בלי לפתור את זה, אין אפליקציה ציבורית אחת שתעבוד (לא checker, לא
math-checker, וגם לא הרחבה עתידית). לבדוק אם אבישי (Workspace super admin)
יכול לפתוח את זה, או למצוא מי כן Organization Policy Administrator.

## צעדים הבאים (לפי עדיפות)
1. לפתור את חסימת ה-org policy (אבישי?)
2. אחרי שנפתר: `gcloud beta run services add-iam-policy-binding` על checker
3. להריץ את פריסת scan2 שכבר מוכנה ב-Cloud Shell (`~/scan2-src`)
4. להגדיר `ANTHROPIC_API_KEY` כ-secret/env var על scan2 **וגם** על checker/math-checker
5. לפרוס math-checker ל-Cloud Run (אותו תהליך כמו checker)
6. לעדכן DNS מ-A record (IP של ה-VM הנטוש) ל-CNAME של Cloud Run domain mapping
7. להעביר לירון: הדגל על חוסר דה-דופליקציה ב-`scan2/main.py`
8. Cloud Tasks — לתכנן ולממש תור משימות אסינכרוני
9. בדיקה מקצה לקצה בדפדפן לשתי האפליקציות
