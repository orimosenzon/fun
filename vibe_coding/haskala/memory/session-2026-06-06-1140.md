## הצעדים להמשיך (בסשן הבא)

### א. פריסת המודל (5 דקות)
1. לך ל-`portal.azure.com` → חפש `haskala-openai-orim` → פתח
2. לחץ **"Go to Foundry portal"** למעלה
3. ב-Foundry: **Model catalog** או **Deployments** → **"+ Deploy model"**
4. בחר **gpt-4o** (לא mini)
5. **Deployment name:** `gpt-4o-vision`
6. **Deployment type:** Global Standard
7. לחץ Deploy

### ב. שליפת הסודות (2 דקות)
1. חזור לדף `haskala-openai-orim`
2. **"Click here to manage keys"** → העתק **KEY 1**
3. **"Click here to view endpoints"** → העתק endpoint (`https://haskala-openai-orim.openai.azure.com/`)
4. שמור ב-`.env` של haskala:
   ```
   AZURE_OPENAI_KEY=<KEY 1>
   AZURE_OPENAI_ENDPOINT=https://haskala-openai-orim.openai.azure.com/
   AZURE_OPENAI_DEPLOYMENT=gpt-4o-vision
   ```
5. ⚠️ **לא לדחוף ל-git** — לוודא ש-`.env` ב-`.gitignore`

### ג. אינטגרציה ב-haskala (30-60 דקות)
1. להוסיף Azure OpenAI כספק נוסף לצד Claude ב-`vision_providers.py` (או איפה שיש בחירת מודל)
2. SDK: `openai` package — אבל עם `base_url` של Azure ו-`api_version` query param
3. בדיקה ידנית על עמוד אחד — לוודא שהתמלול עובד

### ד. בנצ'מרק (1-2 שעות)
1. לבחור set של 5-10 דפים מייצגים (כתב יד יסודי, איכויות שונות)
2. להריץ את אותו flow על Claude + GPT-4o Vision
3. למדוד: דיוק, latency, עלות
4. תוצאה: החלטה לאיזה ספק לבסס את haskala (או hybrid)
