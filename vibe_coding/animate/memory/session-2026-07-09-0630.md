# סיכום סשן — שדרוג גדול: anim12 → animate.html

## מה נעשה

### תיקון באג קריטי (data loss)
ב-anim11 ומטה, ציור עקומה חדשה בפריים 1 דרס את **כל** הפריימים האחרים
(clone של פריים 0 על כולם) — כל עבודת אנימציה בפריימים 2+ נמחקה.
תוקן: עקומה חדשה מתווספת (append) לכל הפריימים בלי לגעת בקיים.
גם merge שוכתב לעבוד פר-פריים לפי id, עם שמירת האנימציה.

### פיצ'רים חדשים (anim12)
1. **ציור בכל פריים** — הוסרה מגבלת "פריים 1 בלבד"
2. **Autosave** — localStorage עם debounce, שחזור אוטומטי בטעינה; "נקה הכל" מוחק גם אותה
3. **Onion skin דו-כיווני** — קודם (אדמדם) + הבא (ירקרק) + סליידר שקיפות
4. **Easing** — לינארי/רך/האטה/האצה + **לולאה חלקה** (אינטרפולציה אחרון→ראשון)
5. **עריכת נקודות** — דאבל-קליק מוסיף anchor (פיצול de Casteljau משמר-צורה, בכל הפריימים), Alt+קליק מוחק
6. **כלי רצף נבחר** — שכפול (כולל האנימציה), z-order קדימה/אחורה, מחיקה — סרגל קונטקסטואלי
7. **ציר זמן משופר** — thumbnails בקנה מידה גלובלי אחיד, drag לסידור מחדש, שכפול/מחיקה בריחוף
8. **קנבס רספונסיבי + HiDPI** (devicePixelRatio), רקע לבן (מתקן ייצוא שקוף)
9. **מקלדת** — ←/→ ניווט, Enter נגן/עצור, Escape ביטול ציור/בחירה, Home/End
10. **פורמט .clp** — נוסף meta {animDuration, easing, seamless}; תאימות לאחור מלאה (נבדק מול animation.clp)

### בדיקות
Chrome headless (אין Puppeteer): עותק עם סקריפט בדיקה מוזרק, `--headless=new --enable-logging=stderr`,
לכידת CONSOLE. כל הזרימות ירוקות, אפס שגיאות JS, כולל תאימות לאחור. + screenshot לפריסה.
