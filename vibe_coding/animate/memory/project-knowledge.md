# פרויקט עורך אנימציית עקומות בזייה

## מיקום
`/home/ori/fun/vibe_coding/animate/`

## מה זה
עורך אנימציה מבוסס web (HTML5 Canvas + Vanilla JS) לציור עקומות בזייה קוביות ויצירת אנימציות מרובות פריימים.

## סטאק
- **Frontend only**: HTML + CSS + Vanilla JavaScript
- **Canvas API** לציור
- **אין שרת** — קובץ HTML סטטי שעובד ישירות בדפדפן
- **פורמט שמירה**: `.clp` (JSON מותאם אישית)

## פיצ'רים עיקריים
- ציור עקומות בזייה קוביות על canvas — **בכל פריים** (מ-v12); עקומה חדשה מתווספת אוטומטית לכל הפריימים בלי לדרוס עריכות קיימות
- מצב עריכה: גרירת anchors/controls/רצפים, בחירת רצף, מחיקה, שכפול, סדר עומק (z-order)
- הוספת נקודת עיגון בדאבל-קליק (פיצול de Casteljau משמר-צורה, בכל הפריימים) ומחיקה ב-Alt+קליק
- Onion skin דו-כיווני: פריים קודם (אדמדם) + הבא (ירקרק) + שקיפות מתכווננת
- Easing: לינארי / רך / האטה / האצה + לולאה חלקה (אינטרפולציה אחרון→ראשון)
- שמירה אוטומטית ל-localStorage (שחזור אוטומטי בטעינה; "נקה הכל" מוחק גם אותה)
- ציר זמן: thumbnails בקנה מידה גלובלי אחיד, גרירה לסידור מחדש, שכפול/מחיקת פריים בריחוף
- קנבס רספונסיבי + HiDPI (devicePixelRatio)
- undo/redo, זום בגלגלת, פאן ב-Space+גרירה
- קיצורים: ←/→ ניווט פריימים, Enter נגן/עצור, Escape ביטול, Home/End
- ייצוא WebM (רקע לבן, רזולוציה מלאה, משך לפי מחזור)
- שמירה/טעינה `.clp` (כולל meta: מהירות/easing/לולאה — תאימות לאחור לקבצים ישנים)

## קבצים
- `anim12.html` — **הגרסה הנוכחית** (יולי 2026: propagation לא-הרסני, autosave, onion דו-כיווני, easing, עריכת נקודות, ציר זמן משופר, רספונסיבי)
- `anim11.html` — קודמת (מחיקות, צבע/עובי, סגירת עקומה, pan, WebM)
- `anim10.html` ומטה — גרסאות ישנות
- `*.clp` — קבצי אנימציה שמורים (animation.clp, nose.clp, וכו')

## פורמט `.clp`
JSON עם `animationFrames`: מערך של פריימים, כל פריים מכיל מערך של רצפים (sequences).
כל רצף: `id`, `anchors` (נקודות עגינה), `segments` (פלחי בזייה עם p0, cp1, cp2, p1).
מ-v12 נוסף `meta` אופציונלי: `{animDuration, easing, seamless}`.

## אינווריאנט חשוב (v12)
טופולוגיה זהה בכל הפריימים: אותם רצפים (לפי id), אותו מספר anchors/segments, אותו סדר.
כל שינוי טופולוגי (ציור, מחיקה, merge, הוספת/מחיקת נקודה, z-order, שכפול) מוחל על **כל** הפריימים;
שינויי מיקום (גרירה) הם פר-פריים — זה מה שיוצר את האנימציה.
