# דרך הנדיב · מה קורה עכשיו

מפה חיה של כל אירועי פסטיבל דרך הנדיב (29–31.10.2026) בפרדס חנה-כרכור. נבנה בסשן פרדספדיה 22/10/2026, ומקושר מהערך "דרך הנדיב 2026".

הכל תלוי בערך אחד, נקודת הזמן (יום ודקה). פס הזמן, המפה, הרשימה ולוח הזמנים מצטיירים כולם ממנה.

- **פס זמן**: גוררים, או לוחצים ▶ כדי להריץ את היום. ההיסטוגרמה מראה כמה אירועים פעילים בכל עשר דקות, צבועה לפי סוג.
- **מפה**: אירוע פעיל מסומן בעיגול מלא שפועם, ואירוע שמתחיל בשעה הקרובה בטבעת עם ספירה לאחור. לקראת הערב המפה מחשיכה.
- **לוח זמנים**: מקומות מול שעות. אירועים חופפים באותו מקום נפרסים לנתיבים.
- **התוכנית שלי**: מסמנים ★, והאפליקציה מראה את זמן ההליכה בין אירוע לאירוע, מזהירה מחפיפות ומשרטטת מסלול על המפה. אפשר לשתף בקישור (`#plan=id,id`) או להוריד קובץ `.ics` ליומן.
- **סינון**: לפי סוג, לפי "מתאים לילדים" ולפי "נגיש", וחיפוש חופשי. כפתור המיקום מסדר את הרשימה לפי מרחק.

## נתונים

אין build. הדף טוען את `data/hanadiv.json` מהריפו `orimosenzon/derech-kitzur-data`. את הקובץ מייצר `dereh_kitzur/build_hanadiv.py`, שרץ ב-cron כל לילה ב-00:05 ומשם הוא מתפרסם. כך האפליקציה מתעדכנת בלי פריסה. העותק ב-`data/` הוא גיבוי למקרה שגיטהאב לא זמין. כדי לרענן אותו:

    cp ../dereh_kitzur/web/data/hanadiv.json data/

כתובת בלי מיקום (אין לה FIXES ב-build_hanadiv.py) מופיעה ברשימה ובלוח הזמנים, אבל לא על המפה.
