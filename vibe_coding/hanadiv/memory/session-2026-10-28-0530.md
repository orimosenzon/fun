# סשן 2026-10-28

סשן ארוך, 23–28.10.2026, של אפליקציית "דרך הנדיב · מה קורה עכשיו" (מפה חיה של אירועי הפסטיבל 29–31.10.2026). זה הסשן הראשון שנפתח לפרויקט כפרויקט נפרד. הוא נולד בסשן פרדספדיה ב-22.10.

## מה נעשה
- **מפה**: כל מקום מוצג בתמונה של האירוע בתוך טבעת בצבע הסוג. התמונה גדלה עם הזום. יש צילום אוויר, תלת־ממד עם תבליט, ושיפור ביצועים.
- **תצוגה נקייה**: חלונית "מה להציג", מצב "מפה בלבד", לשונית חץ שמסתירה את הרשימה, והתאמה לטלפון.
- **עכשיו אמיתי מול הצצה קדימה**: "קורה עכשיו" מופיע רק כשהפסטיבל באמת מתקיים.
- **הכתובת מחזיקה את כל מצב האפליקציה**, ויש שיתוף בקישור מקוצר (is.gd).
- **התוכנית שלי**:
  - זוהרת בכל האפליקציה.
  - מסלול מקווקו עם חצי כיוון וזמני הליכה.
  - מספר סידורי שגדל עם הסמן.
  - "מה נכנס בחלון".
- **התוכנית בכל מכשיר**: התחברות עם Google דרך Firebase (`hanadiv-2026`, Firestore `plans/{uid}`). יש כפתור חשבון בכותרת וכפתור Google בתוכנית.
- **ליומן Google**: חלונית עם כפתור "הוספה" לכל אירוע (קישור TEMPLATE שנפתח מלא), וקובץ `.ics` לכל התוכנית.
- **חיפוש**:
  - מבין עברית: אותיות סופיות, רבים ותחיליות.
  - כשאין תוצאות מופיעה תיבה אדומה, ו-Enter מנער את השדה.
  - בזמן חיפוש הרשימה מציגה את התוצאות מכל שלושת הימים.
- **מיקום לפי מספר אירוע**: `EVENT_AT` ב-`dereh_kitzur/build_hanadiv.py` (הידית האחורית, 2261, ברחבת יד לבנים).
- **אינטגרציה עם אתר הנדיב**, שגיא לב, המפתח שלהם, אישר ב-27.10:
  - כל כפתור הרשמה מוביל ל-`event-page/{id}?join=1`.
  - הזמינות נלקחת רק מהשדה `availability`.
  - ארבעה מצבים: נותרו X / להרשמה, רשימת המתנה / הצטרפות לרשימת המתנה, ההרשמה נסגרה בלי כפתור, ובלי נתון לא מוצג כלום.
  - ליד כל מספר כתוב שזו תמונת מצב משעת המשיכה.
  - בדיקה על כל 255 האירועים באתר החי, במחשב ובטלפון: אפס אי-התאמות.
- **הוספה לדף הפרויקטים**, ראשונה בווידג'ט המתחלף.
