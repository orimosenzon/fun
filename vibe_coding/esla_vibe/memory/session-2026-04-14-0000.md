# Session 2026-04-14

## מה נעשה

### פרויקט חדש: esla_vibe
תכנות מחדש של https://github.com/orimosenzon/fun/tree/master/esla (2009, Tkinter/VPython)
לאפליקציית Dash מודרנית עם 5 tabs.

### קבצים שנוצרו
- `app.py` — Dash entry point עם tabs
- `utils/linalg.py` — math utilities משותפות (lerp, grid_lines, gaussian_steps, span_geometry, eval_surface)
- `utils/logger.py` — logging מרכזי (קובץ rotating + console)
- `views/transform.py` — Tab 1: טרנספורמציות לינאריות 2D
- `views/rowcol.py` — Tab 2: וקטורי שורה ועמודה
- `views/gaussian.py` — Tab 3: אלימינציה גאוסית שלב-שלב
- `views/vecspan.py` — Tab 4: span וקטורים ב-3D
- `views/surface3d.py` — Tab 5: פונקציות 3D
- `assets/custom.css` — CYBORG dark theme overrides
- `requirements.txt`

### באג פתוח
**לחיצה על גרף הטרנספורמציות לא מוסיפה נקודות.**
- תוקן חלקית: `hoverinfo="skip"` → `"none"` (skip מנטרל גם click)
- נוספה שכבת נקודות שקופות (22×22 grid) לכיסוי שטח הלחיצה
- הוסף logging — לאחר restart יש לבדוק `logs/esla_vibe.log` בעת לחיצה
