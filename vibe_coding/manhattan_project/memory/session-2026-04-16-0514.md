## באגים שתוקנו

1. `id="map paint-mode"` (רווח ב-id) → מנע את Leaflet מלמצוא את הקונטיינר
2. `cellGroup.bringToFront()` — לא קיים על `L.LayerGroup` → קריסה שקטה בכל עדכון heat map
3. `L.heatLayer` Canvas כיסה את תאי הפארק → קליקים לא הגיעו לתאים
   - תיקון: `map.createPane('heatPane')` עם z-index=350 ו-`pointerEvents: none`
4. Map drag הפריע לציור → הוספת `stopPropagation` על כל אירועי העכבר של התאים
