## מושגי מפתח

- **Park premium**: עלייה בערך נדל"ן בגלל קרבה לפארק
- **FAR (Floor Area Ratio)**: יחס שטח בנוי לשטח קרקע
- **Hedonic regression**: מודל סטטיסטי שמפרק מחיר נכס לגורמיו
- **Externality**: השפעה חיצונית של נכס/שירות על אחרים
