# אופטימוס 3

סימולטור פיזיקלי של הרובוט ההומנואידי של טסלה, ואקדמיה שמסבירה איך רובוט כזה עובד. סטטי לגמרי, בלי build: Three.js 0.170 ו-MuJoCo 3.14 (החבילה הרשמית של Google DeepMind ל-WebAssembly) מ-jsdelivr.

- `index.html`: הסימולטור. שליטה ידנית (הליכה, טלאופרציה של הידיים, דחיפות), 8 משימות אוטונומיות (לך לנקודה, נופף, מיון תאי סוללה, סקוואט, מבחן דחיפות, ריקוד, סיור, העברת ארגז), שכבות מידע (ZMP, מרכז מסה, DCM, צעדים מתוכננים, כוחות מגע), מפת עומסים על המפרקים, הספק וסוללה, ומבט מהמצלמות של הרובוט.
- `academy.html`: האקדמיה. 15 פרקים: אנטומיה, מפעילים, היד, אחיזה, שיווי משקל, הליכה, בקרת כל-הגוף, חושים, למידה, אנרגיה, ייצור, בטיחות, היסטוריה, בדיקת מציאות ומקורות. 13 הדמיות, שתיים מהן מריצות את הרובוט האמיתי עם הבקר שלו.

## הפיזיקה והבקר

הרובוט הוא מודל MuJoCo עם 76 דרגות חופש (6 של הבסיס הצף, 30 מפרקי גוף, 40 מפרקי אצבעות). שום תנועה לא מוקלטת: בכל 2 מ"ש בקר כל-הגוף (`js/ctrl/wbc.js`) פותר יחד את תאוצות המפרקים ואת כוחות המגע (פירמידות חיכוך בפינות הסוליות), ומוציא מומנטים שנחתכים לפי עקומת המומנט-מהירות של כל מנוע. ההליכה (`js/ctrl/gait.js`) מבוססת על DCM עם התאמת צעדים בחיזוי קדימה, וכך הרובוט מתאושש מדחיפות.

## הרצה

```
python3 -m http.server 8791      # ואז http://localhost:8791/
npm install                      # רק לבדיקות ב-node
node tools/test_physics.mjs      # הליכה, דחיפות, הספק ומשימות
```

פרמטרים ב-URL: `?auto=1` (בלי מסך פתיחה), `&task=cells`, `&scene=empty`, `&cam=eyes`, `&pip=1`.

## מה אמיתי ומה משוער

טסלה עוד לא חשפה רשמית את אופטימוס 3 (נכון ל-19 באוקטובר 2026). המראה מבוסס על הדמיות שנמצאו באפליקציה של טסלה בספטמבר 2026, היד על הפטנטים מאפריל 2026, והמספרים של המפעילים, הסוללה וההספק על AI Day 2022. כל ערך ב-`js/robot/spec.js` מסומן במקור שלו, וטבלה מלאה מופיעה בסוף האקדמיה.
