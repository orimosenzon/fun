# חמקן

אפליקציית ווב שמראה מה עומד בפני מי שמתכנן מטוס חמקן, ואקדמיה עם המתמטיקה והפיזיקה.

- `index.html`: **שולחן המתכנן**. משנים את צורת המטוס (גוף, כנף, זנבות, פתחים, ציפוי) ורואים בזמן אמת את חתך המכ"ם בכל כיוון ובארבעה תדרים, את המחיר האווירודינמי, את החתימה התרמית, ומבחן חדירה דרך מערך מכ"מים.
- `academy.html`: **האקדמיה**. 11 פרקים: משוואת המכ"ם, חתך מכ"ם, אופטיקה פיזיקלית ונוסחת גורדון, עיצוב בפאות, עקיפה מקצוות, פיזור מי, פינות וחללים, חומרים בולעים, חום, אווירודינמיקה, היסטוריה. 11 מעבדות, שתיים מהן בתלת-ממד.

## איך זה מחושב

- `js/core/po.js`: אופטיקה פיזיקלית סקלרית על משולשים. האינטגרל על כל משולש בנוסחה סגורה (גורדון, דרך הרמיט-ג'נוקי), עם הפרשים מחולקים יציבים. בנוסף מקדם קצה מפושט לקצוות חדים.
- `js/core/geometry.js`: מחולל מטוס פרמטרי. אותה רשת משמשת לציור ולחישוב.
- `js/core/model.js`: תדרים, מכ"מים, פתחי אוויר (כולל רשת מתחת לתדר הקטעון), תא טייס, אנטנה ונחיר כמפזרים נקודתיים.
- `js/core/ram.js`: שכבות בולעות כקווי תמסורת (דלנבך, סליסברי, פריט).
- `js/core/mie.js`: פתרון מי המדויק לכדור מוליך.
- `js/core/aero.js`, `js/core/ir.js`: גרר גל (פון קרמן / סירס-האק), יציבות כיוונית, פלאנק, חימום עור וטווח IRST.
- `js/core/worker.js`: החישובים הכבדים בעובד רקע.

בלי build. Three.js 0.170 ו-KaTeX 0.16.11 מ-jsdelivr.

## הרצה ובדיקות

```
python3 -m http.server 8791      # מתוך התיקייה
node tools/test_core.mjs         # בדיקות הפיזיקה
python3 tools/tabs.py OUTDIR     # צילומי הלשוניות (playwright)
python3 tools/shotacad.py OUTDIR # צילומי מעבדות האקדמיה
```
