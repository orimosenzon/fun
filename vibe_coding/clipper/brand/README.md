# brand/ — הלוגו, הפתיחה והסיום

כאן יושבים קובצי המיתוג הקבועים. כשהאפליקציה מוגשת מכתובת http(s), היא טוענת אותם
מכאן אוטומטית לפי `brand.json`, אלא אם המשתמש כבר בחר קבצים משלו בדפדפן (אלה גוברים).

| מפתח ב-brand.json | מה | המלצה |
|---|---|---|
| `logo` | הלוגו | PNG עם רקע שקוף, לפחות 600 פיקסלים ברוחב |
| `intro` | סרטון הפתיחה | MP4 (H.264), באותו יחס כמו הפורמט הנפוץ (9:16 לרילס) |
| `outro` | סרטון הסיום | כנ"ל |

אפשר לשנות את שמות הקבצים ב-`brand.json`. מפתח שחסר או קובץ שלא קיים פשוט מדולג.

כשפותחים את `index.html` ישירות מהדיסק (`file://`) הדפדפן חוסם את הטעינה האוטומטית,
ואז בוחרים את הקבצים פעם אחת בפאנל "מיתוג" והם נשמרים בדפדפן.
