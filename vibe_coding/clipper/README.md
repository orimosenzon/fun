# Clipper — קטעים מסרטון, ממותגים, לרשתות החברתיות

אפליקציית ווב: פותחים סרטון ארוך, בוחרים על טיימליין את הקטע שרוצים, והאפליקציה
מייצרת סרטון חדש שבו **פתיחה קבועה → הקטע עם הלוגו → סיום קבוע**, בפורמט שמתאים לרשת
(9:16 לרילס/טיקטוק/שורטס, 1:1, 4:5, 16:9 או כמו המקור).

הכול רץ בדפדפן. אין שרת, אין העלאה לשום מקום, אין build ואין תלויות. הסרטון לא יוצא מהמחשב.

## שימוש
1. פותחים את `index.html` ב-Chrome או Edge (מהדיסק או מכתובת אינטרנט).
2. גוררים סרטון למסך.
3. בוחרים קטע: גרירה על הטיימליין, גרירת הקצוות הצהובים, כפתורי "סמן התחלה/סוף"
   (מקשי I / O), או הקלדת זמנים בשדות.
4. בפעם הראשונה בלבד: בפאנל "מיתוג" בוחרים לוגו, פתיחה וסיום. הם נשמרים בדפדפן.
5. בוחרים פורמט ו"צור סרטון". הייצוא נמשך בערך כאורך התוצאה, ובסוף יש כפתור הורדה.

| מקש | פעולה |
|---|---|
| רווח | נגן / עצור |
| I / O | התחלה / סוף הקטע במיקום הנוכחי |
| P | נגן רק את הקטע |
| ← / → | פריים אחורה / קדימה (עם Shift: שנייה) |
| Home / End | לתחילת / סוף הקטע |
| Ctrl + גלגלת | זום בטיימליין |

## איך זה עובד
| קובץ | תפקיד |
|---|---|
| `js/compose.js` | פריים אחד של התוצאה: מסגור (זום והזזה; כללי, או נפרד לסרטון מהרשימה), מילוי השטח הריק (טשטוש או צבע), טקסט ברצועות, לוגו, דהייה. אותה פונקציה לתצוגה ולייצוא |
| `js/sequencer.js` | מנגן פתיחה → קטע → סיום לקנבס ומקליט ב-MediaRecorder. גרף WebAudio לקול |
| `js/timeline.js` | הטיימליין, קנבס אחד: סרגל, תמונות ממוזערות, צורת גל, פס סקירה |
| `js/media.js` | בניית התמונות הממוזערות וצורת הגל ברקע |
| `js/store.js` | IndexedDB: המיתוג וההגדרות נשמרים בדפדפן |
| `js/i18n.js` | עברית / אנגלית |
| `js/app.js` | חיבור הכול |
| `brand/` | ברירות מחדל למיתוג כשהאתר מוגש מ-http. ראו `brand/README.md` |

**ייצוא בזמן אמת.** הסרטון מתנגן ומצויר לקנבס, והקנבס מוקלט יחד עם הקול. בין החלקים
ההקלטה מושהית (`MediaRecorder.pause`), כך שזמן הטעינה של הסרטון הבא לא נכנס לקובץ.
הקול מושתק בדיוק בנקודת הסוף לפי שעון האודיו, גם אם המחשב עמוס.

**לשונית ברקע.** השעון של לולאת הציור וההקלטה בא מ-Web Worker ולא מ-requestAnimationFrame
או setTimeout. בלשונית ברקע כרום מאט את אלה לפעם בשנייה, ואחרי חמש דקות לפעם בדקה, ואז
התמונה קפאה והקובץ יצא ארוך עם שקט בסוף. אפשר לעבור ללשונית אחרת בזמן ייצוא ארוך.

**מסגור לכל סרטון.** לחיצה על שורה ברשימת הקטעים מסמנת את הסרטון. גרירה וזום בתצוגה
יוצרים לו מסגור משלו (🔍 בשורה), והשאר נשארים עם המסגור הכללי. "סיום" חוזר לערוך את הכללי.
המסגורים נשמרים בדפדפן לפי הטווחים של השורה.

**פורמט הקובץ.** Chrome/Edge על Windows ו-Mac מייצרים MP4 עם H.264 ו-AAC, שמתקבל בכל
הרשתות. Chrome על לינוקס מייצר MP4 עם Opus (אין שם מקודד AAC). דפדפן שלא יודע MP4 נופל
ל-WebM, והאפליקציה מזהירה שאינסטגרם לא מקבל אותו.

## בדיקות
```
cd tests && ./make_media.sh && python3 test_e2e.py
```
Playwright עם Chrome אמיתי ועם חלון (לא headless: בלי GPU הקנבס מצויר בתוכנה ולא
מגיע ל-30 פריימים בשנייה). הבדיקה טוענת סרטון, מיתוג, בוחרת קטע בגרירה ובשדות, מייצאת,
ובודקת ב-ffprobe/ffmpeg את הרזולוציה, הקודק, האורך, ובאיזו שנייה מופיעים הפתיחה (אדום),
הלוגו (ירוק) והסיום (כחול).

- `test_batch.py`: רשימת קטעים, פענוח, אזהרות וייצוא של כמה סרטונים.
- `test_frames.py`: מסגור נפרד לסרטון אחד, נבדק לפי הפיקסלים בקבצים.
- `test_hidden.py`: ייצוא כשהלשונית ברקע. בלי Playwright (הוא מכריח את הדף להישאר "גלוי"):
  כרום עצמאי, CDP גולמי ו-Ctrl+T אמיתי דרך xdotool.
