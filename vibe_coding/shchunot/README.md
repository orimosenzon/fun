# שכונות פרדס חנה-כרכור

כלי אינטראקטיבי לחלוקת פרדס חנה-כרכור ל-10 עד 13 שכונות, באיזון בין מספר תושבים לשטח. נבנה ליוסי לוי.

- `index.html` הדף (Leaflet + אריחי OSM). פתיחה: `python3 -m http.server` בתיקייה.
- `partition.js` אלגוריתם החלוקה (דפדפן ו-Node).
- `data.js` נוצר ע"י `build_data.py` מנתוני `raw/` (שמורדים ע"י `fetch_raw.sh`).
- בדיקה: `node tools/test_partition.mjs [k] [mu]` (גם `INHAB=1`). בודק רציפות של כל שכונה.

מקורות: גבול ומבנים מ-OpenStreetMap; מפקד 2022 של הלמ"ס לפי אזורים סטטיסטיים (שכבת ArcGIS Online); אומדן 47,194 תושבים ל-1/10/2026 (ביטוח לאומי).
