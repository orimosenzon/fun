# אקדמאים לפי יישוב

אחוז בעלי השכלה אקדמית (מבני 15 ומעלה) בכל יישוב בישראל, לפי מפקד האוכלוסין 2022 של הלמ"ס.
דף אחד עם חיפוש לפי שם, סינון לפי גודל יישוב (כולם / 2,000+ / 20,000+) ומיון לפי כל עמודה.

## הרצה
```bash
./fetch_raw.sh        # מוריד את כל האזורים הסטטיסטיים ל-raw/ (לא בגיט)
python3 build_data.py # מחבר לרמת יישוב → data.js
python3 -m http.server 8951   # http://localhost:8951/index.html
```

## מקור ושיטה
- שכבת "מפקד_2022" ב-ArcGIS Online של הלמ"ס (אותה שכבה שמשמשת את `shchunot/`), השדה `AcadmCert_pcnt`.
- הנתון מפורסם לפי אזור סטטיסטי. ביישוב עם כמה אזורים: ממוצע משוקלל לפי קירוב למספר בני 15+
  (תושבים × (100 − 0.75 × אחוז בני 0-19)). ביישוב שהוא אזור אחד זה המספר המדויק.
- 3,857 אזורים, 1,387 יישובים, 1,181 מהם עם נתון השכלה.
