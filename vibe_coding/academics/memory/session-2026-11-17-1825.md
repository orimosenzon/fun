- דף אינטראקטיבי (חיפוש מנורמל, סינון לפי גודל, מיון) פורסם כ-Artifact: https://claude.ai/artifact/3s7v18pAPL8UyyYGptk5TX
- הפך לפרויקט `academics/`: `fetch_raw.sh`, `build_data.py` → `data.js`, `index.html`, README, ידע פרויקט, רשומה בדף הפרויקטים (כלים אינטראקטיביים, ליד שכונות).

## צעדים הבאים
1. עמודות נוספות מאותה שכבה (הכנסה חציונית, גיל חציוני) וגרף הכנסה מול השכלה.
2. מפת יישובים צבועה לפי האחוז.
3. אולי להחליף את הקירוב לבני 15+ בנתון רשמי לרמת יישוב אם יימצא.
