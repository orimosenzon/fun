# סימולציות מתמטיות (math_sims)

סרטוני מתמטיקה עם **ManimGL**, הספרייה של גראנט סנדרסון מערוץ 3Blue1Brown
(הריפו `3b1b/manim`, ולא הגרסה הקהילתית ManimCE).

## הסרטון הראשון: זטה של רימן והמספרים הראשוניים

`videos/zeta_primes.mp4`, 1080p, כיתוביות וקריינות בעברית. ארבע עשרה סצנות:

1. **Title**: פתיחה
2. **PrimeGrid**: הראשוניים עד 100 על לוח
3. **PrimeCounting**: π(x) כמדרגות, הקירוב של גאוס x/ln x והקירוב החלק של רימן R(x)
4. **ZetaDefinition**: הגדרת זטה, והסכום החלקי של ζ(2) מתכנס ל-π²/6
5. **EulerProduct**: מכפלת אוילר והמפה של ארבעת הצעדים שמסבירים אותה
6. **GeometricSeries**: צעד 1: נוסחת הסכום של סדרה הנדסית, הגבול כש-n שואף לאינסוף (עם q=½ על הישר), והצבה q=1/pˢ
7. **OpenBrackets**: צעד 2: ‏(1+x)(1+y) כבחירת איבר מכל סוגר, המקדם 2 ב-(1+x)², וטבלת הכפל של חזקות 2 וחזקות 3
8. **InfiniteProduct**: צעד 3: אינסוף סוגריים, בחירה כרשימת חזקות, בחירות עם אינסוף חזקות חיוביות נעלמות, והפירוק היחיד לראשוניים
9. **EulerCheck**: צעד 4: המכפלה ב-s=2 מתכנסת ל-π²/6, ומשם הוכחת אוילר לאינסוף הראשוניים
10. **ComplexZeros**: המישור המרוכב, הקוטב ב-1, האפסים הטריוויאליים, הרצועה והקו הקריטי
11. **CriticalLineSpiral**: מסלול ζ(½+it) עד t=50, כל מעבר בראשית הוא אפס
12. **ExplicitFormula**: הנוסחה המפורשת: R(x) פחות גלים מ-1, 3, 10, 30, 100 אפסים משחזר את המדרגות
13. **Hypothesis**: השערת רימן ומשמעותה לחסם על השגיאה
14. **Credits**: תודה לגדי אלכסנדרוביץ'

ההסבר על מכפלת אוילר (צעדים 2 ו-3) בהשראת הפוסט של גדי אלכסנדרוביץ'
[הוכחת אוילר לקיום אינסוף ראשוניים](https://gadial.net/2009/05/17/euler_proof_infinity_of_primes/) בבלוג "לא מדויק".

## הרצה

```bash
.venv/bin/python compute/zeta_data.py   # פעם אחת, ~5.5 דקות: אפסים, ערכי זטה, הקירובים
./render.sh                             # כל הסצנות ב-1080p ואיחוד ל-videos/zeta_primes.mp4
./render.sh -l                          # טיוטה מהירה באיכות נמוכה
ONLY="ExplicitFormula" ./render.sh -l   # רק סצנות מסוימות (האיחוד עדיין לוקח את כולן)
```

תצוגה אינטראקטיבית של סצנה בחלון (בלי `-w`):

```bash
PATH=~/.TinyTeX/bin/x86_64-linux:$PATH .venv/bin/manimgl scenes/zeta_primes.py CriticalLineSpiral
```

## מה הותקן

- `.venv/` עם `manimgl` 1.7.2, `ManimPango` (נבנה מקוד מקור מול `libpango1.0-dev`, `libcairo2-dev` מ-apt)
- LaTeX: ‏TinyTeX ב-`~/.TinyTeX` (בלי sudo), עם החבילות של התבנית של ManimGL ו-`dvisvgm`
- פונט עברי Rubik ב-`~/.local/share/fonts`

## קריינות

`caption(text, say=...)` מציגה כיתובית קצרה ומקריאה את `say` (או את הכיתובית עצמה), ו-`say(text)` רק מקריאה.
ההקראה מתחילה ברגע הקריאה, והאנימציות שאחריה רצות במקביל. ההקראה הבאה מחכה שהקודמת תיגמר,
וכך הסצנה מתארכת לפי הדיבור. `fade_all()` מחכה לסוף ההקראה לפני שמנקה את המסך.

הקול: `he-IL-AvriNeural` דרך `edge-tts` (חינמי, דורש רשת). כל משפט נשמר ב-`audio/` לפי hash, כך שרינדור חוזר לא פונה לרשת.
טקסט ההקראה נכתב במילים ("פאי בריבוע חלקי שש", "אלף שבע מאות שלושים וארבע") כי המנוע לא קורא נוסחאות.

## עברית ב-ManimGL

`Text` מרנדר עברית נכון דרך Pango, אבל ביטוי כמו `π(x)` או `12 = 2·2·3` בתוך משפט עברי מתהפך.
הפונקציה `heb()` עוטפת רצפים לטיניים/מתמטיים בתווי בידוד כיווניות (LRI/PDI) ופותרת את זה.
נוסחאות של ממש נכתבות ב-`Tex` בנפרד מהטקסט העברי.
