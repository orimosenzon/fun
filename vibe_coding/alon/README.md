# הגיטרות של אלון — אתר מכירה + הנצחה

אתר סטטי (HTML/CSS/JS, ללא שרת) למכירת מלאי הגיטרות בעבודת יד שנותר מסדנתו של אלון, בונה גיטרות שנפטר.

## הרצה מקומית
```bash
cd /home/ori/fun/vibe_coding/alon
python3 -m http.server 8777
# פתחו http://127.0.0.1:8777
```
(אתר סטטי — אפשר גם לפרוס ב-GitHub Pages / Netlify בגרירה.)

## מבנה
- `index.html` — שלד הדף (hero/הנצחה, קטלוג, על הבונה, יצירת קשר)
- `style.css` — עיצוב כהה-זהוב, RTL
- `data.js` — **כל התוכן נמצא כאן** (גיטרות, מפרט, מחירים, פרטי קשר, ביוגרפיה)
- `script.js` — רינדור הקטלוג, מודאל גיטרה, גלריה ו-lightbox
- `images/<גיטרה>/NN.jpg` — תמונות מלאות · `images/<גיטרה>/thumbs/NN.jpg` — תמונות ממוזערות
- `convert_images.py` — סקריפט שהמיר את ה-DNG המקוריים ל-JPG (להרצה כשמוסיפים גיטרות)

## ⚠️ מה צריך להשלים (הכל בקובץ `data.js`)
1. **מחירים** — כרגע "פנו לפרטים" בכל גיטרה. עדכנו את שדה `price`.
2. **פרטי יצירת קשר** — מלאו `CONTACT.phone` (פורמט `972501234567`) ו/או `CONTACT.email`.
   כל עוד הם ריקים, מופיעה התראה כתומה במקום כפתורי הקשר.
3. **שנים** — `LUTHIER.years` (למשל `"1955–2025"`) — לא ידוע מהסרטון.
4. **מפרט מדויק** — התיאורים מבוססים על מה שנראה בתמונות. כדאי לאמת אלקטרוניקה/עצים מול מי שמכיר את הכלים.

הביוגרפיה של הבונה (`LUTHIER.bio`, `quote`, `paragraphs`, `invitation`) כבר מולאו על בסיס הסרטון המשפחתי.

## הוספת גיטרות נוספות
1. הוסיפו את תיקיית ה-DNG ל-`convert_images.py` (מילון `GUITARS`), הריצו אותו.
2. הוסיפו אובייקט גיטרה למערך `GUITARS` ב-`data.js`.
