# פרויקט alon — אתר מכירה + הנצחה לגיטרות בעבודת יד

## מהות
אתר סטטי למכירת מלאי הגיטרות שנותר מסדנתו של **יצחק (איציק)**, בונה גיטרות (לוּתְיֶיר) שנפטר.
טון: הנצחה + מכירה. נמכר על ידי המשפחה.
**הערה על השם:** שם התיקייה הוא "אלון" אבל שם הבונה האמיתי הוא **יצחק** (מהסרטון). codename הפרויקט נשאר "alon", אבל כל התוכן באתר על יצחק.

## סיפור הבונה (מהסרטון המשפחתי isacc.mp4)
- יצחק אהב מוזיקה, תשוקתו הגדולה: לבנות גיטרות לאחרים ולראות אותם מנגנים. האמין שגיטרה נותנת לאדם "להוציא את הנשמה החוצה".
- לוּתְיֶיר — מקצוע שעובר מאב לבן. בנו ממשיך את המלאכה.
- ציטוט מפתח: **"תקשיב לעץ. תבין מה העץ רוצה."**
- ביוגרפי: שירת בחיל האוויר, גרו במצפה רמון 11 שנה, בנו בית בראש הנקרה.
- בנה כלים חצי-אקוסטיים וגם לרוק/מטאל (חובב איירון מיידן). כל גיטרה נושאת לוגו שלו.
- הזמנה: לבוא, לנגן, לחוות — והכלים למכירה.

## סרטון
מקור: `/home/ori/tmp/אלון/gitars/גיטרות 1/isacc.mp4` (332MB, 1080p, 231s, כתוביות עברית מוטמעות)
דחוס לאתר: `video/isaac.mp4` (37MB, 720p, faststart). poster: `video/poster.jpg` (פריים 130s — נגינה מול מדף הגיטרות).
כלים: ffmpeg לדחיסה, faster-whisper (medium) לתמלול. התמלול ב-/tmp/isaac_transcript.txt (גס, שוכתב ידנית ל-data.js).

## סטאק
HTML/CSS/JS סטטי, ללא שרת. RTL, עברית. גופן Heebo. עיצוב כהה-זהוב.
- `index.html`, `style.css`, `script.js`
- `data.js` — **כל התוכן** (גיטרות, מפרט, מחירים, CONTACT, LUTHIER bio)
- `convert_images.py` — המרת DNG→JPG (rawpy + Pillow; מחלץ thumbnail מוטמע, fallback ל-postprocess)
- `images/<id>/NN.jpg` (מלא 1600px) + `images/<id>/thumbs/NN.jpg` (600px)

## מקור הנתונים
תמונות DNG (RAW, ~75MB כל אחת) ב: `/home/ori/tmp/אלון/gitars/גיטרות 1/`
- "גיטרות 1" היא חבילה אחת מתוך כמה (יש zip של ~1.3GB בתיקיית האב). **צפויות עוד גיטרות.**

## הגיטרות (נכון להקמה)
1. **rockingbird / רוקינגברד** (11 תמונות) — גוף בסגנון B.C. Rich Mockingbird, עץ אגוז flame כהה, צוואר מייפל ענבר, חומרת זהב.
2. **zebrawood / זברווד** (7 תמונות) — גוף Stratocaster מעץ זברנו (פסים שחור-כתום), SSS, גשר tremolo, חומרת זהב. פרט מיוחד: צלחת צוואר עם **חריטת ראש אריה זהב** בגב.
