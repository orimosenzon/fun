# סשן 2026-06-09 — הקמת אתר "הגיטרות של יצחק"

## מה נעשה
- הוקם אתר סטטי (HTML/CSS/JS) למכירת מלאי גיטרות בעבודת יד מסדנתו של **יצחק (איציק)**, בונה גיטרות שנפטר. טון: הנצחה + מכירה, RTL, עיצוב כהה-זהוב.
- **המרת תמונות:** 18 קבצי DNG (RAW ~75MB) → JPG בשתי רזולוציות (מלא 1600px + thumb 600px) באמצעות rawpy + Pillow (`convert_images.py`). 2 גיטרות: רוקינגברד (11) + זברווד (7).
- **סרטון:** תומלל עם faster-whisper (עברית), נדחס מ-332MB/1080p ל-37MB/720p (ffmpeg, faststart), הוטמע בסקשן "סיפורו של יצחק". poster מפריים 130s. הסרטון כולל כתוביות עברית מוטמעות.
- **תוכן:** הביוגרפיה, הציטוט ("תקשיב לעץ. תבין מה העץ רוצה."), סיפור המשפחה וההזמנה — נכתבו מתוך הסרטון. שוכתבו לקול חם ואישי ("אבא", גוף ראשון) אחרי שהגרסה הראשונה הייתה יבשה מדי.
- QA אוטומטי (Playwright): 2 כרטיסים, כל התמונות נטענות, lightbox עובד, אפס שגיאות קונסול/בקשות.
