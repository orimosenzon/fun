## למה התמלול הראשוני גרוע ב-Hebrew handwriting
חמש סיבות מצטברות:
1. הטיה במידע אימון — Vision LLMs ראו 100× יותר English print מאשר Hebrew handwriting.
2. אותיות דומות בעברית (ר/ז/ו, ה/ת/ח, ב/כ/ל) + צורות סופיות.
3. כתבי יד של L2 learners — לא סטנדרטיים.
4. רזולוציה אפקטיבית גבולית (~30-50px לאות אחרי downsampling).
5. **Confabulation**: כשהמודל לא בטוח, הוא ממציא טקסט עברי הגיוני במקום להגיד "לא קריא". זה core failure mode.
