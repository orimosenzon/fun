# remez (רמז)

ניסוי קטן לבדוק תזה: האם נתינת מספר רמזים של מילים מתויגות לאותו תלמיד משפרת את OCR העברי של שאר הדף שלו?

זה לא פרויקט למידת מכונה. אנחנו לא מאמנים מודל. אנחנו רק נותנים ל-Claude Vision כמה דוגמאות של (חיתוך תמונה, התמלול הנכון) כ-in-context examples, ובודקים אם זה משפר את התמלול של שאר הדף.

זהו פרויקט-בת של [haskala](../haskala/) — אם התזה נכונה, ה-flow של haskala (תיקון מורה ↔ תמלול חוזר) יקבל מנגנון כיול אוטומטי.

## שימוש

```bash
# 1. צור ground truth לדף — Claude מתמלל ראשונית, אתה מתקן בעורך
python annotate.py 20260520_103226.jpg

# 2. הרץ את הניסוי
python experiment.py data/annotations/20260520_103226.gt.json --k 0,3,5,10
```

## מבנה הניסוי

1. בוחרים דף של תלמיד אחד עם N מילים.
2. מתויגים את כל N המילים (זה ה-ground truth — נעשה ידנית פעם אחת בלבד).
3. עבור כל k ∈ {0, 3, 5, 10}:
   - בוחרים k מילים אקראיות מהדף.
   - שולחים ל-Claude את החיתוך של כל מילה כזו + ה-label שלה כדוגמה.
   - מבקשים מהמודל לתמלל את כל הדף.
   - משווים את התמלול שלו לתמלול הנכון על המילים שלא ניתנו כרמז.
   - מודדים CER (Character Error Rate).
4. אם CER יורד מונוטונית עם k → התזה אומתה.
