# סשן 2026-04-28 10:30 — יצירת הפרויקט

## מה נעשה
- נפתח פרויקט חדש בשם **surfaces** ב-C++/Qt6.
- הותקנו תלויות: `cmake`, `qt6-base-dev`, `libgl1-mesa-dev`.
- מבנה: CMakeLists, src/, shaders/, memory/.
- הוטמעה היררכיה: Surface (אבסטרקטית) + 7 משטחים: Sphere, Torus, HelixTube,
  ConicalSpiral, Mobius, Klein, Saddle.
- SurfaceView: QOpenGLWidget עם orbit camera, סיבוב אוטומטי וגלגל זום.
- שיידרים: Phong + צביעת tint לפי תחום הפרמטרים + grid עדין.
- MainWindow: רשימת משטחים, פאנל הסבר עם הנוסחה לכל משטח, צ'קבוקס auto-rotate, reset.

## באג שתוקן
שחרור IBO לפני VAO ב-`uploadMesh` גרם ל-segfault ב-`glDrawElements`
(NVIDIA driver). תוקן: `vao.release()` קודם, ואז `vbo.release()` ו-`ibo.release()`.

## איך מריצים
```bash
cd ~/fun/vibe_coding/surfaces
cmake -S . -B build && cmake --build build -j
./build/surfaces
```
