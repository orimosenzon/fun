# סשן 2026-04-28 21:53 — דיאגרמות אינטראקטיביות

## מה נעשה
- הוספת טאב "How it's derived" עם הסבר אינטואיטיבי איך מגיעים לכל פרמטריזציה.
- ניסיון ראשון: SVG inline ב-QTextBrowser. נכשל — Qt לא מרנדר תגיות `<svg>` ב-rich text.
- ניסיון שני: SVG אמיתי דרך QSvgWidget — דיאגרמה דו-ממדית חדה לכדור (P, Q, cos u, sin u, זוויות u/v, מקרא).
- ניסיון שלישי (לבקשת המשתמש): **דיאגרמה תלת-ממדית אינטראקטיבית** עם orbit camera, גלגל לזום, כפתור איפוס.

## ארכיטקטורה
- `src/DiagramScene.{h,cpp}` — תיאור מופשט של סצנה (Point, Segment, ArcAngle, Circle, Plane).
  כל משטח מקבל סצנה משלו ב-`diag::sceneFor(name)`.
- `src/DerivationView3D.{h,cpp}` — `QOpenGLWidget` שמרנדר את הסצנה. שיידרים פשוטים
  ל-GL_LINES + GL_POINTS, ו-QPainter overlay לתוויות (עם רקע כהה לקריאות).
- `src/Derivation.{h,cpp}` — נשאר ל-`derivationTextFor()` בלבד (הטקסט שמתחת לדיאגרמה).
  SVG functions עוד בקובץ אבל לא בשימוש; אפשר למחוק בעתיד.
- ב-MainWindow: הטאב מכיל [reset button | DerivationView3D | derivationText (QTextBrowser)].

## עניינים טכניים
- QTextBrowser **לא תומך** ב-SVG inline — חובה QSvgWidget או QOpenGL/QPainter.
- ב-Qt 6.2 יש libqt6svg6-dev (חבילת ubuntu זמינה דרך apt).
- כיום הפרויקט תלוי רק ב-Qt6 Core/Gui/Widgets/OpenGL/OpenGLWidgets — Svg הוסר.
- DerivationView3D משתמש ב-`paintEvent` (לא רק `paintGL`) כדי שאפשר לשים QPainter overlay
  אחרי השכבה של OpenGL.
