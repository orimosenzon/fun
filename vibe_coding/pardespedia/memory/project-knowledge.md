# pardespedia — ידע פרויקט

## מהות
כלי CLI לניהול דפים בוויקי הקהילתי pardespedia.info (ויקי של פרדס חנה-כרכר) דרך MediaWiki API.

## מבנה
- `wiki_client.py` — קליינט ל-API: לוגין, get/edit/create, search, list, categories
- `pardespedia.py` — CLI: get, edit, create, search, list, cats
- `credentials.json` — פרטי הבוט (ב-.gitignore, לא בריפו). יש `credentials.json.example` כתבנית.

## חשבון
הבוט מתחבר כמשתמש **"אורי מוסנזון בוט"** (חשבון נפרד שאורי פתח בוויקי, לא Special:BotPasswords). לוגין נבדק ועובד (2026-06-11).

## כלל עריכה מחייב — לכבד תוכן קיים
ה-API מחליף את כל הוויקיטקסט של הדף במה ששולחים. לכן **לפני כל עריכת דף קיים: חובה למשוך את התוכן הנוכחי (`get`), לבצע את השינוי הנקודתי בתוכו, ולשלוח את הדף המלא המעודכן.** לעולם לא לשלוח תוכן שנכתב מאפס על דף קיים — זה מוחק את מה שהיה (ההיסטוריה נשמרת, אבל הגרסה החיה נדרסת).
- `create` משתמש בדגל `createonly` ונכשל אם הדף קיים — בכוונה. אם הדף קיים, עוברים ל-flow של edit (get → שינוי → שליחה).

## הרצה
```bash
cd ~/fun/vibe_coding/pardespedia
python3 pardespedia.py list [--prefix X]
python3 pardespedia.py get "שם דף"
python3 pardespedia.py edit "שם דף" content.wiki --summary "..."
python3 pardespedia.py create "שם דף חדש" content.wiki --summary "..."
```

## ערכי אישים — תשתית (2026-06-20)
- **קטגוריה מאוחדת:** `[[קטגוריה: אישים בפרדס חנה-כרכור]]` — הקטגוריה הניטרלית לכל ערך-אדם. (הישנה "אישים שהשפיעו על המושבה" ריקה/מבוטלת — לא להשתמש בה.)
- **דף-ריכוז (hub):** הערך `אישים בפרדס חנה-כרכור` (ב-namespace ראשי, נפרד מהקטגוריה בעלת אותו שם) — טבלת-אב של כל האישים: עמודות תמונה / שם / תיאור 3–6 שורות. **כל ערך-אדם חדש מתווסף אליו** (עריכת get-first, מיקום אלפבתי).
- **כללי-זהב לערך-אדם** (הסקיל `pardespedia-person` שהיה ב-`~/.claude/skills/` נמחק — נכון ל-2026-07-12 הכללים מתועדים רק כאן): אימות מגורים, תמונה חופשית>שימוש-הוגן ותמיד שונה מוויקיפדיה, ניסוח מקורי (לא הדהוד ויקיפדיה), קישורים פנימיים דו-כיווניים, עדכון ה-hub (`דמויות בפרדס חנה-כרכור` — "אישים בפרדס חנה-כרכור" הוא הפניה אליו) והאינדקס (`האינדקס של הדפים`).
- **תמונות:** העלאה דרך `action=upload` (ראו `upload_commons.py` לחופשי; שימוש-הוגן ברזולוציה נמוכה לאדם חי). אם מחליפים תמונה על שם קובץ קיים בממדים שונים — לעשות `action=purge` לקובץ ולדף (thumbnail ישן נתקע).

## כריית אתר בית הראשונים (rishonim.house), מ-1/11/2026
האתר הוא WordPress; כל התוכן נשלף דרך `wp-json/wp/v2/pages|posts?per_page=100&page=N` (339 דפים, 132 עם תוכן היסטורי של יותר מ-1,500 תווים). כותבים במילים שלנו, הערת שוליים לכל עובדה עם שם הכותב כשהוא מופיע, ועדויות מוצגות כעדות.
- **סבב 1 (1/11/2026) נכתב:** אליהו דוד בדש, בתי הכנסת התימניים בכרכור, הצרכנייה של פרדס חנה, קבוצת שלוחות בפרדס חנה, מחצבות וכבשני הסיד של כרכור. הועשרו: המושב (רחוב), נווה אפריים (בתוך "עממי, תל שלום נווה אפריים"), נווה אשר, הדקלים, טבלת המפעלים.
- **שכונת התימנים = רמב"ם (שכונה)**, כבר כתובה מאותו מקור. לא לפתוח כפילות.
- **סבב 2 (2/11/2026) נכתב:** איחוד פרדס חנה וכרכור, המאבק במלריה בפרדס חנה וכרכור, ארגון אימהות עובדות בפרדס חנה, שבט אלון (צופים). הועשרו: המועצה המקומית (ראשי מועצת כרכור, איחוד שני "ראו גם"), היסטוריה, מחנה 80 (ייבוש הביצות), קומונות וגרעינים (הכשרת הצופים 1942–46), נווה מרחב, בית הספר החקלאי, כיכר אברהם שץ. תמונות שימוש הוגן: בנימין שרון, נטיעות אא"ע.
- **חוות ברין כבר מכוסה היטב ב"מגד (שכונה)"** (כולל משק הילדים). לא לפתוח ערך נפרד. אנשי "השומר" מכוסים חלקית ב"אחוזת לונדון" וב"היסטוריה".
- **נשאר לסבבים הבאים (חדשים):** קו הרכבת המזרחי / רכבת האלונים (הקשר למושבה: תחנת תל אסור ליד ברקאי; לבדוק), היישוב העתיק בסביבות כרכור, תל צבי, בית קאופמן, בית רכס, הכשרות בפרדס חנה (קבוצת רוסים, אבוקה, רודג'ס, הגושרים), אנשי השומר בכרכור (אולי כערך נפרד).
- **להעשרה:** בית הספר החקלאי (7 דפים), מחנה העולים (בית העולים), האמפיתאטרון (בית העם, ולכינסקי), מעברת כרכור, משטרת כרכור, מגד, רחובות החרובים/הראשונים.
