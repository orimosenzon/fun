# סשן 2026-10-05 עד 2026-10-07

## מה נעשה
- **ערך חדש [[דרך הנדיב 2026]]** (rev 9147 ← 9152 ← 9158): מדריך למהדורה השמינית של הפסטיבל (29–31/10/2026), באותה מתכונת של [[אמנות במושבה 2026]]. אורי חשב שיש כבר ערך כזה, אבל היה רק [[פסטיבל דרך הנדיב]] הכללי. בדף: תיבת "בשורה אחת", טבלת ימים, המוקדים המרכזיים (שבילים, המתנ"ס, האולם, בית בנגורה, הבית 43), סדרת "אלטרנדיב", ולוח אירועים מלא לכל יום (שעה, קישור לעמוד האירוע באתר, תחום, מקום עם גוגל מפות hl=iw, קהל ונגישות).
- **מקור הנתונים:** API פתוח ב-`api.hanadiv.org` (`/festival?festival=2026`, `/event?festival=2026`). זה אותו API ששכבת דרך הנדיב בדרך קיצור (`build_hanadiv.py`) כבר משתמשת בו.
- **סקריפט חדש** `festival_guides/build_hanadiv_guide.py` (מתועד ב-`festival_guides/README.md`): מושך נתונים ובונה את הדף. מתקן כתובות שהוקלדו לא נכון (`ADDRESS_FIX`) ומקשר מוקדים לערכים בוויקי (`VENUES`). קישורים חיצוניים של המארחים לא מועתקים, בכוונה: חלקם מקוצרים ומסנן הספאם היה דוחה את כל העריכה.
- **סעיף "במפה":** צילום מסך של דרך קיצור כשרק שכבת דרך הנדיב דלוקה (`קובץ:דרך הנדיב 2026 - שכבת האירועים בדרך קיצור.jpg`), עם קישור בכיתוב. אורי ביקש שהתמונה תהיה בלי טקסט צרוב, והקישור יופיע רק בכיתוב (נשמר כ-feedback בזיכרון הגלובלי). אורי גם תיקן את `]]]` בכיתוב, שבלע את הקישור, וזה הוכנס לסקריפט.
- **בערך [[פסטיבל דרך הנדיב]]** נוסף משפט על המהדורה השמינית וקישור לדף החדש (rev 9148). הדף נוסף גם לאינדקס (rev 9149–9150).
- השכבה בדרך קיצור רועננה ב-6/10 בסשן אחר: 114 אירועים. אחרי זה הוויקי והצילום עודכנו גם הם ל-114.

## צעדים הבאים
1. רענון שבועי עד 22/10:
   ```bash
   python3 festival_guides/build_hanadiv_guide.py
   python3 edit_page.py "דרך הנדיב 2026" festival_guides/guide_hanadiv_2026.wiki "רענון תוכנית (בוטי)" --replace
   ```
   לבדוק קודם בהיסטוריית הדף שאף אחד לא ערך אותו. אפשר גם להכניס את זה ל-cron.
2. דרך קיצור: ההפניה ב-`dereh_kitzur/index.html` (meta refresh אל `web/`) מאבדת את פרמטרי ה-query. כרגע הוויקי מקשר ישירות ל-`web/?layers=hanadiv`.
3. מהסשן הקודם, עדיין פתוח: לוח האירועים בעמוד הראשי תקוע בגלל קישור tinyurl בפיד, שמסנן הספאם חוסם. צריך לסנן או לפרוש מקצרי כתובות ב-`update_events.py`.
4. מהסשן הקודם: עתירת רחוב הגליל, ערך "רוצים שקיפות".
