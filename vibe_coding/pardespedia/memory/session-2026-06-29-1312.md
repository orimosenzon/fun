## מובייל — תיקון באנר העמוד הראשי (פתוח, באחריות אורי)
- הבעיה: באנר הכרזה (1423×268) גולש/נדחס במובייל.
- אילוצים: אין MobileFrontend, אין TemplateStyles, הבוט בלי `editinterface`, תגית `<style>` נחסמת.
- מה נעשה: התמונה נעטפה ב-`<span class="phk-hero">` בעמוד הראשי (לא-שובר).
- **נדרש מאורי**: להדביק ל-`MediaWiki:Common.css` (כמנהל):
  ```css
  @media (max-width: 800px) { .phk-hero img { max-width: 100% !important; height: auto !important; } }
  ```

## פתוח להמשך
1. **תיקון מובייל** — אורי צריך להדביק את ה-CSS (ראו לעיל).
2. **חינוך ביתי/אלטרנטיבי** — מחקר העלה שהסצנה האלטרנטיבית במושבה היא בית-ספרית (שבילים, רימון, הבית העגול, בית החינוך הפרדס), לא חינוך-ביתי מתועד. ממתין להחלטת אורי: ערך-סקירה "חינוך אלטרנטיבי" / ערכים להבית העגול + בית החינוך הפרדס / כלום.
3. בתי ספר חדשים — אפשר להוסיף לוגואים (עץ חיים, רבין, אורט שחר וכו').
4. שחר פרטיג / רימון / עסקים — אפשר לעבות עם פרטים/תמונות נוספים.
5. עסקים נוספים בעלי משמעות: אורוות האמנים (קיים — לעבות), השוק, משתלות ותיקות.
