# סשן 2026-06-26 (פרדספדיה)

## מה נעשה

### לוח אירועי תרבות ובילוי — פיצ'ר חדש גדול
נבנה דף מתעדכן אוטומטית **"אירועי תרבות ובילוי בפרדס חנה-כרכור"** + תקציר בעמוד הראשי.
- **`update_events.py`** — דטרמיניסטי (בלי LLM). מקורות מובנים, ממוזגים + dedup:
  - **eventschedule** (`/api/calendar-events`) — JSON נקי, מאגד בית לים/טרקלין/נרבתא ועוד.
  - **מתנ"ס (מרכז אמנויות הבמה)** — schema.org JSON-LD מעמוד הטיקצ'אק (סטנדאפ/תיאטרון/מופעים, כולל מחירים).
  - **`manual_events.json`** — אירועי קהילה שלא בפידים (תומך תאריך חד-פעמי או חזרה חודשית `first_friday` וכו'). נזרעו: שוק השיקשוק (שישי ראשון), מסה קריטית (2.7).
  - כל מקור best-effort: כשל במקור בודד מדולג, השאר מתפרסם.
- **עמודות:** תמונה ראשונה (פלייר מורד+מועלה לוויקי, שימוש הוגן, שם יציב, דילוג-אם-קיים — כי פרדספדיה חוסמת URL חיצוני), מחיר אמיתי כשיש (`₪`), וסרטון אחרון מ-`event_videos.json` (מפה ידנית; הפיד בלי סרטונים). נזרע: אורי חזקיה.
- **תקציר בעמוד הראשי** — סקשן שני, טבלה מתקפלת (`mw-collapsible mw-collapsed`, אומת ש-JS נטען), בלי תמונות/סרטונים, + לינק לטבלה המלאה.
- **אוטומציה:** cron כל 3 ימים (`cron_update_events.sh`, 06:00) + **hook גנרי** — `session-start-hook.sh` בשורש הפרויקט מורץ אוטומטית ע"י סקיל session-start (לא special-case; קונבנציה לכל פרויקט).
- **סקיל חדש:** `~/.claude/skills/pardespedia-events/`.

## צעדים הבאים
1. **ניקוי תמונות אירועים יתומות** — פלייר של אירוע שעבר הופך לקובץ יתום. כל כמה שבועות לעבור על [מיוחד:קבצים שאינם בשימוש] ולמחוק `אירוע-*` ישנים (לבוט אין הרשאת מחיקה).
2. להרחיב מקורות אירועים: אורוות האמנים/יוניקורן (admin-ajax — דורש reverse-engineering), השוק הישן (פייסבוק בלבד).
3. לזרוע עוד סרטונים מאומתים ל-`event_videos.json` לאמנים בולטים.
4. אופציונלי: להוסיף את AIR (וסקשן עסקים/תעשייה) לעמוד הראשי.
5. אופציונלי: redirect מ"אוג'ס וולדמן" ל"אוג'ס ולדמן".
6. אם המחשב כבוי ב-06:00 — לשקול anacron או שעת cron אחרת.
