## איך לחשוב על זה בפעם הבאה
- **טכניקת עקיפה לתמונות פרופיל FB/Instagram**: כש-WebFetch נחסם ע"י פייסבוק/אינסטגרם, `curl -A "Mozilla/5.0..." -L <url>` לרוב עדיין עובד ומחזיר HTML גולמי; אפשר לחלץ ממנו `og:image` (regex/grep) ולהוריד את התמונה עם curl. עמוד הפייסבוק החזיר תמונת פרופיל ברזולוציה גבוהה בהרבה (720×720, ~95KB) מאשר אינסטגרם (100×100 thumbnail בלבד, ~3.7KB) — עדיפות לפייסבוק כשיש את שתי האפשרויות.
