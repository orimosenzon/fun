  מתגוררת בקיבוץ משמרות אך אתרה מציין את פרדס חנה-כרכור ככתובת הפעילות
  והמפגשים מתקיימים בכרכור. **הראשונה בוויקי שאינה תושבת המושבה.**

  "מופה בידי X".
