## מה נעשה
- פתיחת סשן: לוח אירועי התרבות בעמוד הראשי עודכן (rev 9195, 32 אירועים). העדכון עבר למרות קישור ה-tinyurl בפיד.
- **רצועת השבוע בכרטיסי לוח האירועים הפכה לימין-לשמאל**: א' מימין, ש' משמאל. השינוי ב-`week_strip()` ב-`update_events.py`: `dir="ltr"` הפך ל-`dir="rtl"`. ב-28/9/2026 אורי ביקש LTR, וב-11/10/2026 ביקש לחזור ל-RTL. ההערה בקוד מתעדת את שתי הבקשות כדי שלא יחזירו את זה בטעות.
- הלוח נבנה מחדש עם הכיוון החדש (rev 9196), ובוויקיטקסט החי כל 32 הרצועות מוגדרות `dir="rtl"`.

## מצב נוכחי
- ה-cron של לוח האירועים יבנה מעכשיו את רצועת השבוע מימין לשמאל.
- [[דרך הנדיב 2026]] לא רוענן מאז 6/10 (114 אירועים). ההגשה לפסטיבל פתוחה עד 22/10.

## צעדים הבאים
1. לרענן את [[דרך הנדיב 2026]]. קודם לבדוק בהיסטוריה שאף אחד לא ערך את הדף, ואז:
   `python3 festival_guides/build_hanadiv_guide.py` ואחריו `edit_page.py ... --replace`. לשקול cron יומי עד 22/10, ולרענן את השכבה בדרך קיצור באותו מהלך.
2. `update_events.py`: לפרוש או לסנן מקצרי כתובות (tinyurl ודומיו) מהפיד, לפני שהם יתקעו שוב את העמוד הראשי.
3. דרך קיצור: ההפניה ב-`dereh_kitzur/index.html` מאבדת את פרמטרי ה-query.
4. עוד פתוחים: עתירת רחוב הגליל, הערך "רוצים שקיפות".
