# סשן 2026-06-23

## מה נעשה
סשן פורה של יצירת ערכים בפרדספדיה (pardespedia.info), בעיקר אישים ומוסדות, לפי הסקיל `pardespedia-person`:

**ערכי אנשים חדשים:**
- **חנה קים** — עיתונאית ופעילה חברתית (תמונה חופשית CC BY-SA 3.0).
- **יואב טריפון** — אדריכל ויזם, ממייסדי "קבוצת תו" (דיוקן שימוש-הוגן + תמונת רחוב מקומית שסיפק המשתמש).
- **עירית רותם** ו-**גור רותם** — זוג ממקימי חוות "אדממה" בנגב; עירית חברת מועצה ווטרינרית (דיוקנאות שסיפק המשתמש).
- **טובה הורביץ** — אשת חינוך, סופרת וציירת, בת כרכור, ניהלה את ביה"ס "אלונים" כשני עשורים (דיוקן + עטיפת ספרה "כרכור מחצבתי").
- **ליאת ורדי בר** — יזמת חברתית, מייסדת קהילת "השוות" (קבוצת הפייסבוק הקהילתית המשפיעה במושבה ובאזור). **חסרה תמונה** — להשלים מהמשתמש.

**ערכי מוסדות חדשים:**
- **בית הראשונים** — המרכז לתולדות פרדס חנה-כרכור (ארכיון/מוזיאון, מבנה 1930). ערך מקיף, תמונה חופשית (CC BY 2.5, PikiWiki). מקושר מהעמוד הראשי (היסטוריה וציוני דרך).
- **המרכז לצדק חברתי** — הורחב מקצרמר קיים לערך מלא (שימור הקטגוריה הקיימת). קושר דו-כיוונית עם **תאיר ענבר** (מנהלת המרכז), והתווספו הכתובת (החרובים 7) ותפקידה. תוקנו שגיאות הקלדה בערך של תאיר.

**תשתית:**
- כל ערך חדש שובץ בדף הריכוז (כיום בשם **"דמויות בפרדס חנה-כרכור"** — הועבר מ"אישים" משיקולי הכללה מגדרית, ע"י עירית; הקטגוריה נשארה "אישים בפרדס חנה-כרכור") ובאינדקס.
- נוסף קישור חסר: דף הקטגוריה → דף הריכוז (קישור דו-כיווני).

**מחוץ לפרדספדיה:** נוצר סקיל כללי חדש `refresh-session` ("חדש סשן") ב-`~/.claude/skills/` — סוגר סשן, גשר מעל `/clear`, ופותח סשן חדש לאותו פרויקט (דרך marker ב-/tmp). תוקן באג: הוסר `disable-model-invocation` שחסם הפעלה דרך הכלי.
