# מה בונים לנו

אתר סטטי: מה פתוח עכשיו להתנגדות בפרדס חנה-כרכור, מה בדרך, ומה אושר בשנה האחרונה.
דף התוכנית של הפרויקט: `../ma-bonim-lanu.html`. זה שלב 1 מתוך 4.

## מקורות

| רשימה | מקור | מתי מתעדכן |
|---|---|---|
| פתוח עכשיו | `data/objections.json` בריפו `orimosenzon/derech-kitzur-data` | כל בוקר ב-07:15, `dereh_kitzur/watch_objections.py` (Xplan + דף כל תוכנית במבא"ת) |
| בדרך להתנגדות | Xplan, ישירות מהדפדפן | בכל טעינה |
| אושרו בשנה האחרונה | Xplan (`pl_date_8`, פרסום ברשומות), ישירות מהדפדפן | בכל טעינה |

את מבא"ת הדפדפן לא יכול לקרוא (אין CORS, ודרוש טוקן reCAPTCHA v3), ולכן הקרון של דרך קיצור
קורא אותו, והאתר רק מציג. ל-Xplan יש CORS ל-github.io ול-localhost.

## "בדרך"

תוכניות ב"החלטה בדיון", ותוכניות בשלב ההפקדה שהחלטת ההפקדה שלהן מהשנה האחרונה, שאינן פתוחות
עכשיו, ושלפי Xplan החלון שלהן לא נסגר (`pl_rejection_date` / `pl_last_deposit_date` בעבר, או
פרסום בעיתון לפני יותר מחודשיים ויומיים). תוכניות מקומיות שנסגרו בלי שום תאריך ב-Xplan עלולות
להופיע כאן בטעות. זה הפער שקובץ ההתנגדויות סוגר לרשימה הפתוחה, ועוד לא לרשימה הזו.

## על הנייר (`gaps.html`)

קרקע שתוכנית ייעדה לשביל, לדרך או לשצ"פ, מול הבעלות בטאבו ומול מה שאפשר ללכת בו היום. הנתונים:
`dereh_kitzur/web/data/gaps.json`, נבנים ב-`dereh_kitzur/build_gaps.py` (התיעוד המלא בראש הקובץ).
הדף קורא אותם בנתיב יחסי, ולכן מקומית צריך להגיש את כל `vibe_coding`:

    cd vibe_coding && python3 -m http.server 8766
    # http://localhost:8766/transparency/ma-bonim/gaps.html
