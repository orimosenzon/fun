# רוצים שקיפות

ניסיתם לברר מה הולכים לבנות לכם ליד הבית?
אילו עצים הולכים לכרות?
האם מתכננים להעביר את החוגים שלכם למתנ"ס?

איך הציבור ידע בזמן מה מתכננים לו?

היוזמה הזאת באה לקדם שקיפות בפרדס חנה-כרכור, בשתי דרכים:

1. **כלי טכנולוגי** שמנגיש את המידע לתושבים.
2. **מקורות הזנה ועדכון** למידע, כולל ממשק מול המועצה.

היוזמה נולדה בקבוצת וואטסאפ בשם "רוצים שקיפות".

## איפה מה

- **התיקייה הזו**: הידע על שקיפות. מקורות מידע, איך עובדים ההליכים, הממשק מול
  המועצה, תחקירים. התחקיר התכנוני הראשון: `memory/planning-research-2026-09-24.md`.
- **האפליקציה היא [דרך קיצור](../dereh_kitzur/).** שם נבנים הכלים לתושבים, ושם כבר
  רץ ניטור יומי של חלונות ההתנגדות (`../dereh_kitzur/watch_objections.py`).
