# סשן 2026-11-20

## מה נעשה
- **עמוד חדש באפליקציית התקציב:** `budget/web/tabar.html` ("תב"רים וקרנות הרשות"). כלי הבנייה הוא `budget/tools/build_tabar.py`. העמוד כולל:
  - מה זה תב"ר ומה זו קרן רשות
  - היקף התשלומים בתב"רים לאורך השנים, ומקורות המימון שלהם
  - יתרות הקרנות והיטל ההשבחה
  - התפלגות לפי תחום
  - השוואה ל-23 רשויות דומות
  - נוסחי בקשות לחופש מידע
- **פס הפניה מעמוד העוגה:** העוגה היא רק התקציב הרגיל, ולצידה עוברים כ-90 מיליון ₪ בשנה בתב"רים.
- **385 החלטות תב"ר** מ-33 ישיבות מליאה (1/2023–10/2026) נכנסו לעמוד, בטבלה עם חיפוש, סינון לפי קרנות ומיון.
- **בבדיקת השאלה אם הפרוטוקולים כוללים את כל התב"רים:**
  - נמצא שהם מכסים רק החלטות מ-2023 ואילך.
  - מ-11/2024 לא מצורפות לפרוטוקולים באתר רשימות תב"ר.
  - הוכנה רשימה של הישיבות שחסר בהן פירוט.
- **ישיבת 4.5.23:** הסכומים חולצו מטבלה סרוקה שעלתה לאתר המועצה בשם שגוי. 22.3 מיליון ₪ אושרו בישיבה, מתוכם 15.7 מיליון מהקרנות.
- **בדיקת כל 110 הנספחים של 2023–2024 מול התוכן שלהם** העלתה שבאתר יש הרבה שמות קבצים מבולבלים (פירוט ב-project-knowledge).
- **הוסרו שמות של חברי מועצה מההערות** בטבלת ההחלטות. נשארו רק מספרי קולות ותפקידים.

## מצב נוכחי
- הכל חי ב-Pages: https://orimosenzon.github.io/fun/vibe_coding/transparency/budget/web/tabar.html
- **2023:** ל-29 מתוך 81 החלטות אין סכום. כמעט כולן מ-8.6.23 ומ-13.7.23.
- **2025 ו-2026:** הסכומים מבוססים רק על ההקראה בישיבות. 46 שורות מסומנות כלא ודאיות.
- **יתרת הקרנות בסוף 2025:** בעמוד מוצג 13.4 מיליון (מהדוח המסכם) עם התווית "לפי הדוח הרבעוני", אבל בדוח הרבעוני כתוב 10.7 מיליון. ייתכן גם שהמספר כולל קרן פנסיה.

## צעדים הבאים
1. **רשימות מחברת המועצה:** אם היא תעביר מהמייל רשימות תב"ר, להכניס אותן ל-approvals.json. הסדר המועיל:
   - 6.2.25, 7.11.24, 8.10.26
   - 13.11.25
   - 5.9.24
   - 8.6.23 ו-13.7.23
2. **יתרת הקרנות לסוף 2025:** ליישר את המספר והתווית.
3. **הדוח המבוקר של 2025:** כשיעלה ל-data.gov.il, להוסיף את מזהה המשאב ל-`build_tabar.py` ולהריץ `--fetch`.
4. **אפשרות להמשך:** להצליב את ריכוז התב"רים המלא מהגזבר, אם יתקבל, מול ההחלטות. ההצלבה תראה תב"רים שלא עברו מליאה וחריגות בביצוע.
