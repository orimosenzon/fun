# לאן הולך הכסף: תקציב המועצה כעוגה

אפליקציה סטטית (בלי build) שמציגה את התקציב הרגיל של המועצה כעוגה. לחיצה על פלח
הופכת אותו לעוגה משלו: תחום ← מחלקה ← שורת תקציב, ובשורה עצמה כרטיס עם ההסבר
מהספר, ההשוואה לשנה הקודמת, גרף לאורך השנים וקישור לעמוד ב-PDF.

- `src/budget_<שנה>.pdf`: ספרי התקציב מאתר המועצה (WordPress, `/wp-content/uploads/`).
  רשימת כל ספרי התקציב באתר: `wp-json/wp/v2/media?search=תקציב`.
- `tools/parse_budget.py`: ספר אחד ← `web/data/budget_<שנה>.json`. קורא מילים עם
  קואורדינטות (pdfplumber), ובודק את עצמו מול שורות הסה"כ שבספר.
- `tools/build_years.py`: כל הספרים (2013–2026) ← קובץ לכל שנה, `years.json` ו-`series.json`
  (כל צומת לאורך השנים). מחבר בין שנים לפי טבלת כינויים שנבנתה מסמל הסעיף
  במבנה האחיד (ספרות 2–4 בקוד הכרטיס), כי השמות משתנים והסמל לא. `--fast` מדלג על קריאת הספרים.
- `web/`: הדף (`index.html`, `app.js`, `style.css`, D3 מ-cdnjs).

```
python3 tools/build_years.py
python3 -m http.server 8765 --directory web
```

כל מצב התצוגה בכתובת (`#y=2026&s=i&p=lnlo.5pex&i=<כרטיס>&v=cmp&u=pct`). `p` הוא גיבוב
קצר של המפתח הקבוע של כל רמה, ולכן קישור שורד מעבר בין שנים. כפתור השיתוף מקצר
דרך da.gd (יש לו CORS), ו-is.gd ב-JSONP כגיבוי.

## מלכודות בספר

- **ח/ז**: ח = חובה (הוצאה), ז = זכות (הכנסה). הסימן הוא מילה נפרדת מימין למספר.
- **שמות ארוכים גולשים לעמודת השנה הקודמת**, והאותיות והספרות מתערבבות למילה אחת.
  לכן באזור המספרים התווים מופרדים לזרמים (ספרות, אותיות סימן, כל השאר),
  ואת עמודת השנה הקודמת מחשבים מהצעת התקציב פחות עמודת ההפרש.
- **עמוד שמתחיל בכרטיס** הוא המשך של המחלקה הקודמת, ומצב הסעיף (הכנסות/הוצאות,
  פעולות/שכר) ממשיך ממנו.
- `סה"כ` יכול להופיע גם בטקסט ההסבר, ולכן הוא נחשב שורת סיכום רק בעמודת הכרטיס.
- **עמודות משתנות בין שנים**: יש שנים בלי "תחזית" או בלי "הפרש", ב-2013 המספרים
  מיושרים לשמאל, וב-2021 המשרות בקצה השמאלי. לכן העמודות מזוהות מהיסטוגרמה של
  המיקומים שהמספרים תופסים, ועמודת המשרות לפי זה שהמספרים בה קטנים.
- עמוד המשך יכול להתחיל ב"סה"כ שכר", לא רק בכרטיס.
- ל-2017 יש באתר רק דף סיכום. המספרים מעמודת השנה הקודמת בספר של 2018.
- ב-2022 הספר עצמו לא מאוזן (57 אלף ₪).
- **מים וביוב** נכנסו לתקציב רק ב-2016–2025 (ב-2026 עברו לתאגיד). באחוזים המכנה בלעדיהם.

כל 13 הספרים מסתכמים בדיוק לשורות הסיכום שלהם, ברמת המחלקה ובנפרד להכנסות ולהוצאות.
