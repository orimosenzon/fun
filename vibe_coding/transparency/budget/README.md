# לאן הולך הכסף: תקציב המועצה כעוגה

אפליקציה סטטית (בלי build) שמציגה את התקציב הרגיל של המועצה כעוגה. לחיצה על פלח
הופכת אותו לעוגה משלו: תחום ← מחלקה ← שורת תקציב, ובשורה עצמה כרטיס עם ההסבר
מהספר, ההשוואה ל-2025 וקישור לעמוד ב-PDF.

- `src/budget_2026.pdf`: ספר התקציב מאתר המועצה (WordPress, `/wp-content/uploads/2026/01/`).
  רשימת כל ספרי התקציב באתר: `wp-json/wp/v2/media?search=תקציב`.
- `tools/parse_budget.py`: הספר ← `web/data/budget_2026.json`. קורא מילים עם
  קואורדינטות (pdfplumber), ובודק את עצמו מול שורות הסה"כ שבספר.
- `web/`: הדף (`index.html`, `app.js`, `style.css`, D3 מ-cdnjs).

```
python3 tools/parse_budget.py src/budget_2026.pdf 2026 web/data/budget_2026.json
python3 -m http.server 8765 --directory web
```

## מלכודות בספר

- **ח/ז**: ח = חובה (הוצאה), ז = זכות (הכנסה). הסימן הוא מילה נפרדת מימין למספר.
- **שמות ארוכים גולשים לעמודת השנה הקודמת**, והאותיות והספרות מתערבבות למילה אחת.
  לכן באזור המספרים התווים מופרדים לזרמים (ספרות, אותיות סימן, כל השאר),
  ואת עמודת השנה הקודמת מחשבים מהצעת התקציב פחות עמודת ההפרש.
- **עמוד שמתחיל בכרטיס** הוא המשך של המחלקה הקודמת, ומצב הסעיף (הכנסות/הוצאות,
  פעולות/שכר) ממשיך ממנו.
- `סה"כ` יכול להופיע גם בטקסט ההסבר, ולכן הוא נחשב שורת סיכום רק בעמודת הכרטיס.
- ספר 2025 עוד לא נקרא נכון (אין בו עמודת הפרש, והטקסט מתערבב יותר). חמש מחלקות
  לא מסתכמות.

תוצאה ל-2026: 19 תחומים, 87 מחלקות, 982 שורות. הוצאות והכנסות 400,039,000 ₪,
ושלוש העמודות (תקציב 2025, ביצוע צפוי 2025, הצעה 2026) מסתכמות בדיוק לסיכום הספר.
