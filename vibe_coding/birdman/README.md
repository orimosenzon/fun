# איש-ציפור

משחק תלת-ממדי בדפדפן. יונה, הדוור של אי קטן, מוצא שורש שמחזק לו מאוד את שרירי הזרועות,
בונה לעצמו כנפיים מבמבוק ומפרשים ישנים, ועף.

בלי בנייה ובלי תלויות: ES modules ו-Three.js מקומי ב-`lib/`.

```
python3 -m http.server 8765      # ואז http://localhost:8765/
```

## איך משחקים

| מקש | פעולה |
|---|---|
| רווח | כנפיים: פרישה, ובהחזקה משק כנפיים. על הקרקע: ריצת המראה |
| חיצים או WASD | היגוי. על הקרקע ↑ זה ריצה |
| Shift | קיפול כנפיים וצלילה. שחרור פורש אותן |
| R / P / M | הפרק מהתחלה / הפסקה / השתקה |

במסך מגע: ג'ויסטיק משמאל, כפתורי "כנפיים" ו"קיפול" מימין. יש גם תמיכה בשלט.
`?ch=N` פותח ישר פרק, `?auto=1` נותן לטייס האוטומטי לטוס (הדגמה).

## הפיזיקה

כל כנף מחולקת לשש רצועות (`js/sim/aero.js`). כל רצועה מחשבת את האוויר שהיא עצמה פוגשת:
מהירות הגוף, סיבוב הגוף, תנועת המשק של הכנף, הרוח המקומית, והזרם שהכנפיים דוחפות מטה
(תורת התנע). מזה יוצאת זווית התקפה, ומעקומת עילוי וגרר מלאה (זרימה צמודה, הזדקרות, לוח שטוח)
יוצא כוח. שום דבר אחר לא מתוסרט: גלישה ביחס 13:1, הזדקרות, דחף ממשק הכנפיים, גרר מושרה,
אפקט קרקע, וכנף שמתרוממת כשהיא נכנסת לאוויר חם, כולם נובעים מאותו סכום.

השחקן נותן כוונה (למשוך, להטות, לנפנף, לקפל). שכבת ה"אינסטינקט" (`js/sim/bird.js`) מתרגמת אותה
למה שציפור באמת מזיזה: סחיפת הכנפיים קדימה ואחורה ומניפת הזנב לעלרוד, כיווץ כנף אחת לגלגול,
סנפיר שקשור לשוקיים לסבסוב.

האוויר (`js/sim/world.js`): בריזת ים ממערב, רוח שעולה כשהיא פוגשת מדרון (ולכן אפשר לרחף מול
המצוק), ועמודי אוויר חם מעל השדות והמדרונות, מסומנים בענן, בעיטים חגים ובאבק שעולה.

כוח השורש: ההספק המכני של משק הכנפיים מחושב מהכוחות האווירודינמיים עצמם (בסביבות 3.5 קילוואט
בטיפוס), והוא מה שמרוקן את המד.

## בדיקות

```
node tests/physics.mjs     # 12 בדיקות טיסה באוויר שקט
node tests/missions.mjs    # טייס אוטומטי מסיים את כל חמשת הפרקים
node tests/thermal.mjs     # חוגים באוויר חם
python3 tools/shot.py OUT "ch=1&auto=1" 10 40    # צילומי מסך מהמשחק עצמו
```
